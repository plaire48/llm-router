## 방법론과 실제 코드 근거

- 다운로드한 Claude 브라우저 1.0.94의 `mcpPermissions-tSjXinpi.js`에서 `processToolResults`를 재확인했다. 도구별 오류 반환, 권한 대기와 실행 분리, 승인 후 같은 작업 재개를 참고했다. 파일 SHA-256 `e240270612684e9108303513f4a5f0cacb83a5d6876fec4d05a4fd7d2d990ed9`. 비공개 배포 코드를 오픈소스로 간주하거나 복사하지 않았다. 출처 경로는 [기존 분석](CLAUDE-HARNESS-STATIC-2026-09-26.md)에 있다.
- [OpenCode compaction 실제 소스](https://github.com/anomalyco/opencode/blob/b471c2b4495747353af768fbf2e0790c9d820ce2/packages/opencode/src/session/compaction.ts)의 `select`/`prune`: 최근 문맥 보존과 완료 도구 출력 정리를 분리한다. 누비에서는 원문 참조와 현재 행동용 ref의 수명을 분리해 적용했다. MIT.
- [Codex compact.rs 실제 소스](https://github.com/openai/codex/blob/814de47b69dd63a2660fd14f9af66690888d183e/codex-rs/core/src/compact.rs): 원래 사용자 요청을 압축 요약과 분리해 재구성한다. 누비도 기존 요구와 원문을 유지하고 초안 전달 누락을 수정했다. Apache-2.0.
- [Anthropic 결과 중심 평가](https://www.anthropic.com/engineering/demystifying-evals-for-ai-agents): 모델의 완료 선언과 실제 결과를 구분한다. 이번 채점은 입력/제출 횟수, 페이지 원문, 최종 UI 전달을 대조한다.
- [Claude Code 하위 에이전트](https://code.claude.com/docs/en/sub-agents): 역할별 독립 문맥과 결과 수집은 유지한다. 비공개 Claude Code 핵심 소스와 동일한 구현을 확보했다고 주장하지 않는다.

새 패키지는 추가하지 않았다. 기존 Pi, Playwright CRX, Readability/Turndown, LangChain/MiniSearch 위에서 재현된 연결 오류를 수정하는 편이 의존성/용량/추가 모델 비용을 늘리는 것보다 직접적이다. 검토 모델 교정은 기존 최대 2회 형식 복구 안에서 처리한다. 무제한 재시도나 승인 우회는 도입하지 않는다.
