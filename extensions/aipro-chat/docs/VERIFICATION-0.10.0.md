# 0.10.0 검증 기록

## 변경

- AI Pro, ChatGPT, FabriX 로고를 같은 시작점에 두고 이름을 왼쪽 정렬했습니다. 고정 너비 대신 가장 긴 이름의 실제 너비로 묶음을 가운데 배치해 양쪽 여백을 맞춥니다. 로딩 표시는 오른쪽에 고정합니다. FabriX는 사용자가 제공한 SVG 경로, 청록색과 투명 배경을 유지합니다.
- FabriX 연결 모달에서 Endpoint, 모델 ID, Client Key와 API Token을 입력하고 연결 테스트 후 채팅으로 이동합니다. HTTP 응답과 도구 호출/결과 왕복을 함께 확인합니다.
- 기존 라우터의 FabriX messages 계약을 확장 내부 OpenAI Chat Completions 응답으로 변환합니다. 같은 Pi 실행기, 스킬, Playwright, 컨텍스트 압축, 제공자별 대화와 실제 usage 집계를 사용합니다.
- 첫 채팅의 입력창 하단 배치, CX 배경/카드, AI Agent 소개, 한 번 재생하는 인사/로고 모션을 포함합니다. UI 전용 검증은 이전 로컬 체크포인트 [0.9.3 기록](VERIFICATION-0.9.3.md)에 있습니다. 공개 설치본은 0.10.0입니다.

`npm test`: 145개 통과. FabriX 요청/헤더/모델, JSON과 분할 SSE, 한국어/CRLF, THINK 제외, 필터/HTTP 오류/중단, 응답 계약 검증, Pi 도구 실행과 잘못된 인자 피드백, 사용량 중복 방지, 이전 ledger 호환, 컨텍스트 압축을 검사했습니다. 연결 테스트의 소유권, 호스트 권한, 만료/취소/로그아웃, worker 재생성, 제공자별 대화 분리와 키의 session 한정 보관도 검사했습니다.

## 확인 범위

FabriX의 native function calling 계약은 확인되지 않았습니다. 이 버전은 선언한 도구와 요청별 nonce를 포함한 모델 JSON을 검증한 뒤 tool_calls로 바꾸며, 실행은 기존 도구 권한과 인자 검사에 따릅니다. 응답 전체 검증 후 표시하므로 실시간 글자 단위 스트리밍은 아닙니다. 확인된 입력 계약은 텍스트여서 FabriX 화면 이미지 입력/좌표 클릭은 제외합니다.

실제 회사망 FabriX, AI Pro SSO와 실계정 ChatGPT 로그인/한도는 미검증입니다. 테스트 페이지의 저장 상태 확인을 회사 메일의 서버 저장 성공으로 간주하지 않습니다. 브라우저 fixture는 임시 복사본에서 사이트 권한을 미리 부여합니다. 네이티브 권한 팝업의 사용자 허용과 회사 정책은 별도 확인 대상입니다. 미확인 모델 한도나 계정 잔여량은 만들지 않습니다.

기존 `sinternet is not defined` 신고는 원인이 확인되지 않았고, 이 버전에서 해결했다고 주장하지 않습니다. 이번 Chrome 검증에서는 페이지 JavaScript 오류가 없었습니다.
