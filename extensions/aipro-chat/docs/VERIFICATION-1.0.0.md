# 누비 1.0.0 검증

제공된 `agentfactorysdkdeck.html`을 색감, 글꼴, 컴포넌트와 움직임의 기준으로 유지한다. Chrome에 설치한 실제 확장으로 기능 회귀를 검사하고, 검사한 ZIP을 그대로 배포한다.

## 반영한 변경

- **공통 UI:** 옅은 블루/보라/민트 색면, 로컬 Noto Sans KR, 제목 16/24px와 본문 14/22px, 버튼 12px 반경을 공유한다. 입력란에 카드 그림자가 번지던 문제를 수정했다.
- **간단한 조작:** 초안 편집의 취소/반영은 아이콘으로 표시하고 접근 가능한 이름과 툴팁을 유지한다. 최종 등록/발송 승인에는 동작을 구분할 짧은 문구를 유지한다.
- **일관된 움직임:** 승인 카드도 같은 등장 곡선과 시간 토큰을 사용한다. 누비의 부유/표정과 감소된 모션 설정을 유지한다. 모달은 등장 중에도 배경과 글자가 투명해지지 않는다.
- **로그인:** ChatGPT에 남아 있던 debugger 콜백을 제거했다. AI Pro와 ChatGPT는 로그인 탭의 정확한 localhost 콜백만 확장으로 전환한다. FabriX 연결도 debugger를 사용하지 않는다. 대기 중 worker가 재시작되어도 콜백/PKCE를 복원하고 인증 코드를 중복 교환하지 않는다.
- **페이지 관찰:** 커스텀 ARIA 입력의 필수/읽기 전용/오류 상태를 전달한다. 지연 목록, 노드 교체, 가림 요소, 중복 행, 저장 실패의 회귀 검사를 추가했다.

## 실행 결과

**단위 245개, 디자인 검사, 브라우저 34종 54회 모두 통과.** 나누어 실행한 모든 검사의 배포 빌드 해시가 동일함을 확인했다. 핵심 10종의 3회 반복도 모두 통과했다.

환경은 macOS arm64와 Chrome for Testing 149.0.7827.55다. 사이트와 모델/인증 응답은 합성 데이터이며 실제 Chrome 확장, DOM, 입력 이벤트와 저장 요청을 검사했다. 핵심 10개 스위트는 각각 새로운 프로필에서 3회 실행했다.

| 범위 | 검사 내용 |
| --- | --- |
| 연결 | AI Pro CLI 콜백과 교환, ChatGPT PKCE/갱신, FabriX 모델/도구 형식, 제공자 전환과 로그아웃 |
| Agent | 관찰과 실행, 계획/결과 검토, 잘못된 완료 보류, 부분 실패 후 복구, 출력 한도 복구 |
| 브라우저 | 입력/클릭, 새 창/탭/팝업, iframe, 동적 DOM, 스크립트, 실제 동작 결과와 중복 실행 여부 |
| 사람의 승인 | 검증한 초안의 최종 반영, 연필 편집과 재승인, 취소, 변경된 대상 거절 |
| 채팅 | 스트리밍, 실제 사이드 패널, 세션 선택/복원, 코드 강조, 컨텍스트 요약/복구 |
| 결과물 | 페이지 이미지 선택, 캡처, 미리보기와 파일 다운로드, 사용자의 선택 질문 |
| 사용량 | API 응답 토큰 집계, ChatGPT 계정 한도와 오류 처리, 제공자별 표시 |
| UI | 320/360/1100px의 27개 모달 상태, 키보드/초점, 토스트/복사, 모델/스킬 선택, 캐릭터 표정과 모션 감소 |

27개 모달 상태에서 제목/입력 글꼴, 불투명도, 배경, 화면 넘침, 아이콘 버튼 이름, 공통 반경과 입력 그림자를 실제 계산 스타일로 확인했다. 원본 HTML과 로그인/연결/편집/사용량 화면도 시각적으로 대조했다.

[전체 결과와 검사 소스 해시](evidence/1.0.0-report.json)에 실행별 상태와 시간을 남겼다.

통합 실행은 이어쓰기 보조 검사에서 한 번 중단됐다. 열린 채팅창의 상태 조회가 채팅 소유권 없이 직접 호출한 테스트 작업을 고아 작업으로 정리하고 있었다. 테스트 창을 닫고 메시지 큐를 비운 뒤 보조 검사를 실행하도록 고쳤으며, 실제 채팅의 두 번째 요청도 추가로 검증했다. 제품의 실행/검증 조건은 완화하지 않았다. 모델 검사도 이전 캐시 버전/마크업을 기대해 중단되어 현재 모델 이름, 접힌 상세와 오류 복구 UI 기준으로 수정했다. 채팅은 자동 이어쓰기, 스킬은 공유/입력 검증과 실제 미허용 출처의 Chrome 주입 거절을 확인하도록 갱신했다. 추가한 미허용 출처 검사도 서비스 worker에서 동적 import를 지원하지 않아 확장 페이지에서 같은 배포 모듈을 검사하도록 수정했다. 실패 로그는 로컬 검증 폴더에 보존했고, 앞서 통과한 검사 파일과 배포 빌드가 바뀌지 않았음을 확인해 결과를 합쳤다. 한 번의 중단 없는 통과로 표시하지 않는다.

## 검증 경계

- 회사망 AI Pro/FabriX API와 실제 SSO, ChatGPT 실계정은 이 환경에서 확인하지 않았다. 로그인 검사에서 debugger 호출은 0회다. 실제 Playwright 브라우저 자동화에는 Chrome 표시줄이 나타나며 종료/취소 시 연결 해제를 검사했다.
- 모델 응답을 합성했으므로 실제 모델의 자율적인 코드 작성/도구 선택 성공률을 측정한 결과는 아니다.
- Windows/Edge와 기본 배포본의 네이티브 사이트 권한 창 허용은 확인하지 않았다. 자동 패널 검사에는 사이트 권한을 부여한 테스트 복사본을 썼다. 별도 headed 권한 검사는 첫 전송 후 대기해 종료했으며 성공으로 세지 않는다.
- 외부 MCP/OpenWiki 연결, 로컬 Python/터미널과 프로젝트 빌드는 1.0.0의 구현 기능에 포함하지 않는다. 현재 등록형 스킬과 확장 내부 브라우저 도구를 사용한다.

## 설치와 배포

[1.0.0 릴리스](https://github.com/plaire48/ai_workspace/releases/tag/aipro-chat-v1.0.0)에서 `aipro-chat-extension-1.0.0.zip`을 받는다. 압축을 푼 뒤 확장 관리에서 해당 폴더를 로드한다. 기존 설치는 같은 폴더에 덮어쓰고 새로고침하며 설정 하단의 `1.0.0`을 확인한다. 브라우저 스토어 등록/자동 업데이트 배포는 아니다.

- ZIP SHA-256: `1c44d8885e5caf3854eb45038d58cc9454f5bb5398aa07cdc663f3aedcee4a99`
- 빌드 SHA-256: `528ce5737b5382ead8fc963a6f752d84b39c44bc0d44815cfea3fb5166433c70`
- ZIP의 193개 파일이 검사한 dist와 바이트 단위로 일치한다. 버전과 패키지 메타데이터는 모두 `1.0.0`이다.
- 검사한 후보 ZIP을 재빌드하지 않고 배포 파일로 복사했다. 테스트 파일/인증값/소스맵은 배포 ZIP에 넣지 않았다.
