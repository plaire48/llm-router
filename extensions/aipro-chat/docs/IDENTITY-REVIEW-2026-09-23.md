# HTML 아이덴티티 적용 점검

기준은 사용자 제공 `agentfactorysdkdeck.html`이다. 파일 해시가 기존 시각 기준과 동일함을 확인하고 원본을 렌더링해 대조했다. 프레젠테이션 제목의 크기를 그대로 가져오지 않고, 원본 색감/깊이/형태를 사이드 패널의 역할별 글자 크기로 적용한다.

## 반영

- 서버 연결, MCP 헤더와 스킬 참고 자료의 중첩 펼침을 공통 `deck-subsection`으로 통일했다. 본문 14/22px, Noto Sans KR, 진한 잉크, 같은 화살표/초점/열림 동작을 사용한다.
- OpenWiki의 반복 설명을 한 문장으로 합치고 작업 위치 안내를 줄였다. 로그인 전의 중복 응답 상태는 표시하지 않는다. MCP 기술 규격은 기존 도움말에 두며 연결 정보 삭제 안내는 유지한다.
- 스킬 폴더 아이콘의 불필요한 테두리를 제거해 주변 조작과 맞췄다. 이름/툴팁은 유지하며 등록/발송/삭제의 결과를 구분하는 글자는 제거하지 않았다.
- 공통 브라우저 검사에 아이콘 이름/툴팁과 중첩 펼침의 폰트/색/모션 감소 검사를 추가했다.
- `npm run verify:identity`로 전체 단위 검사, 디자인 검사, 후보 빌드와 17개 UI 시나리오를 실행한다. 이후 UI 변경에도 적용하도록 AGENTS.md, DESIGN-SYSTEM.md와 시각 기준에 기록했다.

## 검증 범위

모달의 접힌/펼친 내용과 오류, 설정, 제공자 전환, 스킬 등록, 사용량, 컨텍스트, 이력, 질문/승인, 첨부/캡처, 코드, 토스트, 첫 화면과 캐릭터를 실제 Chrome에서 검사한다. 좁은 320/360px와 넓은 화면, 키보드 이동과 모션 감소를 해당 시나리오에서 확인한다. UI 검사는 합성 데이터로 수행하며 회사 로그인이나 실제 서비스 성공을 보증하지 않는다.

모션 감소에서 CX의 전역 규칙은 전환을 0.01ms로 줄인다. 0초 문자열 일치 대신 기존 검사와 동일하게 1ms 이하를 허용하고, 펼침 콘텐츠 애니메이션은 없어야 한다. 이 조건을 중첩 펼침의 실제 키보드 검사에 포함했다.

기존 Beta 13 배포 ZIP은 변경하지 않는다. 이번 결과물은 수정 코드와 검증 후보이며 새 릴리스는 발행하지 않는다.

## 최종 결과

단위 검사 497개, 디자인 검사, 후보 빌드와 UI 시나리오 17개가 통과했다. 중첩 펼침의 모션 감소/키보드 검사도 포함한다. [실행 기록](verification/beta14-prior-identity.json). 전체 브라우저 실행 회귀나 실계정 검증이 아닌 UI 범위의 검사다.

## 핵심 문장과 강조 정리

페이지 자동화, 첨부, 도구 연결 도움말을 핵심 문장과 짧은 소제목/설명으로 나눴다. 핵심 문장은 잉크색/600, 소제목은 진한 블루/600, 상세는 보조색/400이며 14px/22px를 유지한다. 승인, 전송, 보관, 지원 범위는 남기고 반복 설명을 줄였다. 화면과 배포 GUIDE.md는 같은 원본을 사용한다.

좁은 320/360px와 넓은 1100px에서 실제 강조 스타일과 화면을 확인했다. 단위 검사 497개, 디자인 검사, 후보 빌드와 UI 시나리오 17개가 다시 통과했다. [가독성 검사 기록](verification/beta14-prior-readability.json). 실제 제공자 호출이나 신규 배포는 포함하지 않는다.

마지막 첨부 안내 문장을 자연스럽게 다듬은 뒤 후보를 재빌드하고 `ui-simplicity-browser`를 다시 통과했다. 생성된 GUIDE.md에도 핵심 소제목과 최종 문구가 포함됨을 확인했다.

후속 배포: 이 점검의 수정은 전체 회귀를 통과한 [beta14](RELEASE-BETA14.md)에 포함했습니다.
