# 0.16.1 연결과 화면 정리

검증일: 2026-09-21

## 확인한 문제

기존 사용량 창은 제공자 세 개의 큰 토큰 카드 뒤에 잔여 한도를 배치했다. ChatGPT 선택과 GET 200 상태에서도 360×640 화면에서 제목의 y 좌표가 652px로 측정되어 화면 밖에 있었다. 360×800에서는 제목과 일부만 보였다. 사용자 설치본의 모든 원인을 확정한 것은 아니며, 이 배치 문제는 실제 Chrome에서 재현했다.

호출 주소는 기존 라우터와 같은 `GET https://chatgpt.com/backend-api/wham/usage`다. `Authorization: Bearer`와 `ChatGPT-Account-Id`를 사용한다. 쿠키나 임의 User-Agent를 추가하지 않았다. 라우터에 있는 크레딧/개인 한도를 확장이 읽지 못하고, 오류도 5분 캐시하는 차이가 있었다.

모달이 연하게 보인 캡처는 400ms 등장 애니메이션 중 전체 opacity가 낮아진 시점이었다. 열린 뒤에는 불투명했지만, 등장 중에도 배경과 글자를 선명하게 유지하도록 크기/위치 이동만 남겼다.

## 변경

- AI Pro 로그인 경로를 `/auth/cli/login?port=...`로 변경했다. 저장된 VS Code 설정도 CLI로 전환하며 localhost 콜백과 URL-encoded 코드 교환은 유지한다.
- FabriX 연결은 주소, Client Key, API Token 세 필드만 받는다. GET `{base}/chat/v1/models`로 목록을 검증한 뒤 등록하고, 기존 입력창 아래에서 모델을 선택한다. `name`의 `ko` 값을 우선 표시하며 `modelId`는 요청에만 사용한다.
- 연결 테스트는 추론하지 않는다. 서버 목록을 필터링하지 않으며, 기존 선택이 사라지면 첫 모델로 전환한다. 설명의 `[Context]`만 용량으로 추출하고 없는 수치는 미제공으로 둔다.

- 잔여 한도와 조회 상태는 사용량 창 맨 위에 항상 표시한다. 연결된 ChatGPT 계정은 다른 제공자를 사용 중이어도 조회할 수 있다.
- API가 제공한 기간별 비율, 크레딧과 개인 한도를 표시한다. 없는 수치는 만들지 않으며 실제 0과 미제공을 구분한다.
- 성공한 최신 형식만 5분 캐시한다. 오류/초기화/구버전 캐시는 다시 조회하며, 401은 한 번 토큰 갱신 후 재시도한다. 늦은 응답으로 로그아웃한 계정을 복원하지 않는다.
- 제공자 토큰은 로고와 한 줄 합계로 모았다. 행을 펼치면 입력/출력, 호출 수와 미집계를 확인한다. 조회 시각은 새로고침 툴팁에 둔다.
- 모델 선택의 로그인은 아이콘으로 표시하고 연결 전 모달은 내용 높이에 맞춘다. 스킬 목록의 설명은 툴팁으로, 컨텍스트 상세와 도움말은 접힌 항목으로 정리했다. 이력의 제공자는 로고로 구분한다.
- 입력 라벨, 연결 테스트, 페이지 입력과 삭제 확인은 짧은 텍스트를 유지했다. 오류 복구, 접근 가능한 이름, 키보드 설명과 초점 복귀를 유지한다.
- 사용자 HTML의 밝은 블루/민트, 흰 모달, Noto Sans KR, 캐릭터와 모션 감소 동작을 유지한다. 메인의 이야기 문구는 보존했다.

## 검증

- 단위 테스트 202개, CX 디자인 검사와 배포 빌드 통과.
- 실제 설치한 격리 Chrome에서 사용량 8개, 토큰 집계 5개, 기존 채팅/로그인/이력 31개, FabriX 7개, 이미지 11개, 제공자 전환 7개 흐름 통과.
- CLI 로그인 8개 흐름에서 리디렉션, SSO 경유, IPv6, 워커 재시작, 취소/재시도, 코드 교환을 확인했다. 로그인 중 debugger 호출과 localhost 서버 요청은 0회다.
- 제공한 FabriX 모델 8개 응답을 계약 테스트에 사용했다. 브라우저에서는 3필드 등록, 한국어 이름 선택, 선택한 ID의 실제 요청 매핑, 새로고침 복원, 도구 실행과 502/형식 오류 구분을 검증했다. 연결 테스트는 GET만 호출하고 추론 사용량을 추가하지 않았다.
- 320×640, 360×800, 1100×850에서 FabriX 연결, 설정, 도움말, 모델 선택, 스킬 목록/편집, 컨텍스트, 사용량, 대화 이력을 확인했다. 가로 넘침 없이 모달 내부 스크롤과 키보드 펼치기/닫기가 동작한다.
- 모달 애니메이션 중간 프레임도 opacity 1과 흰 배경을 유지한다. 모션 감소에서는 등장 애니메이션을 끈다.
- 360/1100px 접근성 검증에서 진단 복사, 초점 복귀와 재진입을 확인했으며 aria-hidden 경고와 페이지 오류가 없었다.

모델/인증/한도 API는 합성 응답이다. 실제 계정의 잔여 한도 조회, 회사망 SSO와 모델 응답은 별도 확인이 필요하다. 화면에 나온 75%/40%는 테스트 값이다. 웹 스토어 배포가 아닌 개발자 모드 설치 ZIP이다.
