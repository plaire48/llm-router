## 선택과 실제 변경

기존 [첫 원리 점검](../../../docs/plans/2026-09-28-nubi-browser-first-principles-audit.md), [agent-browser 적용 기록](AGENT-BROWSER-REFERENCE-2026-09-28.md), [본문 창 수정](CONTENT-WINDOW-REPAIR-2026-09-28.md)을 이어갔다. agent-browser의 Apache-2.0 고정 소스는 문서 식별과 관찰 수명 참고이며 이번에 새 패키지를 추가하지 않았다. Claude 배포 코드/프롬프트는 복사하지 않았다.

[Anthropic의 에이전트 평가 방법](https://www.anthropic.com/engineering/demystifying-evals-for-ai-agents)의 과제/시도/결과 구분과 실행 기록 기반 독립 평가를 적용한다. 모델의 완료 선언과 실제 사실 정확도를 별도로 채점하고, 이전 성공 과제도 같은 후보로 다시 실행한다. 별도 평가 프레임워크나 추가 검토 모델 호출은 도입하지 않았다.

- `goal-review.js`: 원문을 충실하게 옮겼는지와 주장 자체의 적용 범위를 구분한다. 요약이나 읽지 않은 도표만으로 전부/항상이라는 결론을 통과시키지 않고 조건/제외 범위 확인 또는 근거가 있는 좁은 표현을 요구한다. 특정 펜싱 정답이나 PDF 의무를 코드에 넣지 않았다.
- `browser-script-api.js`: 조사 안내에도 같은 조건/예외 확인을 짧게 반영했다. 기존 최종 검토 계약, 출처 수 비강제, 허용된 검색 요약과 시점 불명 소속의 한정적 답변을 유지한다.
- `browser-public-url.js`: 실제 관찰한 대전일보 기사 경로에만 숫자 `idxno`를 보존한다. 정확한 호스트/경로, 단일 값과 길이를 검사하고 추적/인증 쿼리와 fragment는 계속 제거한다. 다른 사이트의 임의 쿼리는 허용하지 않는다. 해당 기사 재접속은 HTTP 403이어서 이번에 기사 본문 접근 성공을 확인한 것은 아니다.

검토 안내는 확률적 모델 판단을 개선하는 변경이다. 모든 규칙 예외 누락을 결정적으로 차단하거나 새로운 사실을 검증해 주는 장치는 아니다. 실측으로 효과와 회귀를 확인해야 한다.

## 로그인 재시도와 평가 창 연결

사용자 재시도 시 이전 Chrome 프로세스에 열린 탭이 없음을 확인했다. 해당 평가 프로세스만 종료하고 같은 격리 프로필/동일 후보를 다시 열었다. Google 패스키 화면에서 Bluetooth/기기 근접 오류가 발생했고 제공된 다른 로그인 방법 선택을 열었다. 평가기의 대기 시간을 늘려도 확장 인증 세션 자체는 5분 후 만료되므로 실제 로그인 실패를 모델 실패로 계산하지 않는다.

평가기에 미실행 로그인 실패 보고서와 같은 격리 프로필의 살아 있는 Chrome을 다시 연결하는 경로를 추가했다. 읽기 전용 공개 과제만 허용하고, 후보 해시/과제 목록/공개 원문 수집 범위/기존 평가 모듈 해시를 비교한다. 지정 PID의 실제 프로필/확장 경로를 확인한 뒤 localhost 디버그 포트로 연결한다. 실행 중인 코드 해시도 다시 확인한다. 기존 확장 파일을 교체하거나 브라우저/로그인 탭을 닫지 않으며 인증값을 복사하지 않는다. 진행 중 인증이 있으면 중복 로그인을 시작하지 않는다. 작업이 실행된 보고서의 재개나 쓰기 재실행은 지원하지 않는다.

기존 Chrome 연결 및 로드된 코드 일치는 실제 확인했다. 기존 평가 입력/초기화/근거/채점 관련 검사 30개가 통과했다. 이 검사 수를 새 연결 경로의 모든 실패 조건 검증이나 실모델 성능으로 확대하지 않는다. 후보 제품은 바뀌지 않았고, 보고서는 계측 코드 해시와 평가 실행기 해시를 따로 남긴다. 인증 오류에는 계정 식별값을 저장하지 않았다. 이후 사용자의 재시도에서 새 Chrome 로그인에 성공해 5개를 완료했으며, 모델 호출은 총 170회였다. 최종 실측 묶음은 새 프로세스 실행 경로이며 기존 Chrome 연결 경로의 실모델 성공 증거로 바꾸지 않는다.
