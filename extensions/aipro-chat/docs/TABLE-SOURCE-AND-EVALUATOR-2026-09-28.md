# 표 출처 보존과 평가기 대화상자 처리

2026-09-28. 이전 5개 과제의 실측과 실패 기록을 이어서 확인했다. 모델은 GPT-5.6 Luna를 유지했다. 배포나 외부 런타임 도입은 하지 않았다.

## 실제 원인과 변경

E-07의 새 공개 표 기록과 같은 문서의 DOM을 대조했다. 네이버의 현재 날씨 카드 아래에 서울다누림관광 검색 결과의 표가 함께 있었다. 이 표는 숨겨진 요소가 아니라 화면 아래에 렌더링된 링크 미리보기였다. 표 안의 오늘 날짜/기온이 위 카드와 달랐고 이전 오답과 일치하는 값이 있었다. 기존 수집기는 표를 감싼 실제 링크를 버려 서로 다른 출처를 구별하기 어려웠다. 이전 실행의 전체 모델 입력은 없어 과거 오답의 유일한 원인으로 확정하지 않는다.

`browser-information.js`가 실제 조상 `a[href]`의 안전한 URL을 `enclosingLink`로 보존한다. 현재 viewport 포함 여부도 함께 준다. 근처 형제 링크를 출처로 추정하지 않고 링크 목적지를 읽었다고 표시하지 않는다. 열린 shadow root에서도 실제 조상만 추적한다. 값과 표 행, 기존 문서/프레임 정체성, 수집 한도는 유지한다. 인증정보가 든 URL과 실행 URL은 제외한다. 평가 기록도 같은 메타데이터를 제한된 공개 페이지에서만 저장한다.

E-08 측정 도중 Playwright의 `Page.handleJavaScriptDialog: No dialog is showing` 미처리 오류로 평가 프로세스가 중단됐다. 추가 관찰 연결과 제품의 대화상자 처리 중 어느 쪽이 먼저 닫았는지는 입증되지 않았다. [Playwright 공식 문서](https://playwright.dev/docs/dialogs)와 설치된 실행 경로를 확인하고, 평가기에 명시적인 관찰 리스너를 설치해 기본 자동 닫기를 끈다. 제품과 사용자가 대화상자를 처리하며 평가기는 종류와 시각만 기록한다. 자동 승인/거절이나 전역 예외 무시는 도입하지 않았다.

두 CDP 관찰자가 있는 실제 Chrome fixture에서 prompt가 그대로 대기하고, 시험 소유자가 승인/취소한 뒤에만 진행됨을 검증했다. 프롬프트 본문과 입력값은 로그에 남기지 않는다. 해결되지 않은 실제 대화상자는 제품 HITL 또는 평가 시간 제한으로 남으며 임의로 처리하지 않는다.

## 실측과 후속 과제

원래 A 실행 `63a99772-9493-4b36-9e14-287cfa698c73`은 E-08 도중 평가기가 중단됐다. 완료한 네 과제의 독립 채점은 E-03/E-07 통과, E-01/E-04 미통과다. E-01은 실제 검색 결과 제목 대신 사이트명을 썼고 E-04는 사브르 손 제외 조건을 빠뜨렸다. 다섯 과제 전체 성공률은 미확정으로 남긴다.

재확인 시 평가 Chrome 프로세스와 CDP가 종료돼 있었다. 종료 원인은 미확인이다. 같은 프로필과 변경하지 않은 후보 A를 다시 열었으며 저장된 E-08 대화는 `awaiting_user`, 계획 3/3, 마지막 검토 `revise`, 최종 답변 공백이었다. 원래 질문을 재실행하지 않았다. 이 복구 상태로 사라진 네트워크 시간이나 최종 답변을 재구성하지 않는다.

같은 후보 A의 E-08 재시험을 별도 실행 `2133e37a-884e-4f9e-adbb-5787cebc4f4a`로 준비했다. 창 종료로 세션 인증이 없어 정상 ChatGPT 로그인 대기가 필요했다. 다른 프로필이나 앱의 인증값을 복사하지 않았다. 재시험의 최신 상태는 `verification/naver-sso-luna-2026-09-28T04-25-18-821Z.json`을 따른다. 집중 재시험을 원래 5개 실행의 누락값에 덮어쓰지 않는다.

재시험 준비 결과는 `login_not_completed`, `loginStage: login_closed`, 실행 과제 0개다. 후보 파일 확인은 성공했고 평가 브라우저는 보존했다. 사용자에게 정상 로그인을 요청했다. 로그인 미완료를 모델 성능 실패로 계산하지 않으며 E-08 재시험은 여전히 남아 있다.
