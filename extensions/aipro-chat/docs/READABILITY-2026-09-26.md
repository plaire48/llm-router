# 가독성 재점검

사용자 HTML의 블루/잉크/보조색과 누비 배경, 로컬 Noto Sans KR를 유지했다. 본문은 14/22px, 제목은 16/24px, 메타데이터만 12/16px다.

| 발견 | 반영 |
| --- | --- |
| 채팅의 반영 대기가 메타데이터 크기 12px | 상태를 본문 14/22px로 변경하고 파랑 600 강조 유지 |
| 한글 답변이 단어 중간에서 줄바꿈 | 단어 단위 줄바꿈. 긴 URL과 식별자는 영역 안에서 줄바꿈 |
| 녹화 안내의 행동과 보관 조건이 한 문단 | DeckGuidance의 핵심/상세로 분리. 녹화 시작만 강조하고 입력값 미보관 유지 |
| 프로젝트 연결의 전달 범위와 수신 모델이 모두 보조색 | 본문 잉크색으로 표시하고 선택한 모델만 파랑 600. 사용하지 않는 CSS 제거 |
| 모델 답변은 간결함만 안내 | 결과/다음 행동 우선, 핵심 구절 볼드, 대상/조건/근거/한계 보존을 지시 |

## 선택 근거

기존 [가독성 검토](IDENTITY-READABILITY-2026-09-25.md)의 W3C 작성/버튼/입력 안내 원칙을 재사용한다. 설치된 CX 0.5.4의 Icon/ActionButton/DeckGuidance와 react-markdown을 유지하며 새 라이브러리나 렌더러를 추가하지 않는다. 중요한 조건이나 승인 동작을 아이콘만으로 대체하지 않고 중복 장식 이미지를 추가하지 않는다. 기존 캡처 표시, 아이콘의 접근성 이름과 툴팁을 유지한다.

이번 변경은 화면 스타일/문구와 답변 지침이다. 실제 모델이 모든 문장을 적절히 요약한다는 검증은 아니다. 단어 줄바꿈은 표/코드/긴 문자열이 있는 실제 Chrome 화면에서 확인한다. 큐의 입력창 외부 배치와 8px 간격을 유지한다.

## 검증

최종 `verification/pre-release-2026-09-26T05-49-05-564Z/report.json` 통과: 단위 909개, 디자인 검사, 후보 빌드, Chrome 화면 30회. 검증 전후 입력과 빌드 해시가 일치한다. 문서 조회 회귀 7개도 통과해 수정한 답변 지침의 초기 문맥 크기와 원문 조회/취소 계약을 확인했다.

추가 Chrome 측정에서 반영 대기는 14/22px 및 파랑 600, 큐와 입력창 간격은 8px, 360/1100px 양쪽 정렬 차이는 0px였다. 녹화 안내는 실제 모달에서 핵심/상세/아이콘 접근성과 글꼴 규격을 확인했다. 320/360/1100px 본문/모달/표 화면과 프로젝트 연결 캡처를 검토했다. 실제 계정 호출과 배포는 하지 않았다. 답변 지침의 실모델 문장 품질은 별도 평가 대상이다.

## 후속 요청: 아이콘 우선 표현

글자를 다듬는 데서 끝내지 않고 조작 표현을 변경했다.

| 표현 | 적용 |
| --- | --- |
| 아이콘만 | 녹화 초안 저장, 다시 녹화를 한 줄의 ActionButton으로 구성. 마우스/키보드 툴팁과 접근성 이름 유지 |
| 아이콘 + 짧은 이름 | 녹화 시작(workflow), 녹화 종료 후 확인(check), 저장한 작업 실행(play), 예약(clock) |
| 텍스트 유지 | 입력 이름, 입력값 미보관, 초안 유지/버리기 확인과 승인 조건 |

안내와 버튼에 의미가 겹치던 목록 장식 아이콘은 제거했다. 영상 촬영으로 오인할 수 있는 카메라 아이콘은 쓰지 않고 절차 녹화에 workflow 아이콘을 사용했다. 이미지가 실제 상태나 결과를 보여주는 캡처는 기존 표시를 유지한다. 텍스트를 이미지로 굽거나 의미 없는 장식 이미지를 추가하지 않는다.

CX의 실제 Icon 사전과 ActionButton API를 확인해 기존 구성으로 반영했다. 비공개 UI 복제나 새로운 의존성 도입은 없다. 아이콘 전환 뒤 블루/모션과 녹화 배치 후속 요청까지 반영한 최종 gate는 [블루와 모션 검증 기록](BLUE-MOTION-2026-09-26.md)에 기록한다.
