# 0.13.0 대화 이력

검증일: 2026-09-21

새 대화는 기존 대화를 보관한다. 상단 이력 아이콘에서 제목 검색, 선택, 이름 변경과 삭제를 할 수 있다. 마지막 대화와 초안은 다시 열 때 복원된다. 로그인 없이 보관된 대화를 읽을 수 있고, 계속 보내려면 해당 제공자로 연결한다. 기존 CX 모달, 아이콘과 옅은 선택 색상을 사용한다.

## 저장과 전환

- 기존 제공자별 대화를 세션 ID가 있는 저장 형식으로 전환한다. 메시지, 초안, 모델/스킬, 요약, 중단된 작업과 이미지 참조를 유지한다.
- 활성 대화와 이력은 한 번의 local 저장으로 바꾼다. 저장 한도 오류 시 이전 대화와 이력을 유지한다.
- 전환 전에 초안을 저장하고 대화 ID가 다른 늦은 초안/전송 요청을 거절한다. 실행 중인 응답과 로그인 중에는 전환/삭제를 막는다.
- 다른 제공자의 대화를 선택하면 현재 인증과 페이지 연결을 해제한다. 이전 브라우저 작업을 자동 재실행하지 않는다.
- 삭제는 해당 대화와 다른 대화에서 참조하지 않는 이미지에만 적용한다. 사용량 누적 기록은 유지한다. 이미지 정리는 전체 대화 이력의 참조를 검사한다.

## 검증

- `npm test`: 175개 통과. 이력 마이그레이션, 전환, 모델/초안/요약 복원, 제공자 격리, 지연 요청 거절, 실행 중 전환 차단과 저장 실패 후 재시도를 포함한다.
- `npm run design:check`, `npm run build`: 통과. 설치 ZIP 생성.
- `tests/conversations-browser.mjs`: 실제 Chrome 확장에서 생성, 선택, 이어서 전송, 검색, 이름 변경, 삭제 취소/확정, 새로고침과 브라우저 종료/재시작 후 복원 확인. 360px/1100px 배치와 긴 제목/다수 이력의 스크롤 확인.
- `tests/captures-browser.mjs`: 실제 브라우저 캡처, 확대와 다운로드, 이력에 보관한 이미지의 브라우저 재시작 후 복원, 선택한 대화의 이미지만 삭제되는지 확인.
- `tests/context-browser.mjs`: 자동/수동 압축, 초안과 기억 복원, 실제 Playwright 입력, 중단 후 새 관찰과 이어가기 확인.
- `tests/chatgpt-browser.mjs`, `tests/fabrix-browser.mjs`: 합성 인증/API를 사용한 기존 제공자 연결, 사용량, 도구 왕복과 제공자별 대화 격리 확인.
- `tests/browser.mjs`: 설치, 인증 콜백, 인증 거절 후 재로그인, 모델 목록, SSE/사용량, 이력 전환과 브라우저 재시작의 통합 회귀 검증 통과. 오래된 첫 화면/컨텍스트 텍스트 단언을 현재 아이콘 UI에 맞췄다.
- `tests/welcome-browser.mjs`: 320/360/1100px 로그인 배치, 480px 높이, 입력창 하단 유지, 새 대화와 재진입, 모션 감소 확인.

브라우저 검증은 격리한 테스트 프로필과 합성 모델/인증 응답을 사용했다. 사이트 권한은 테스트 복사본에만 미리 부여했다. 실제 계정 SSO, 회사망 API, 모델 성능과 생산 환경의 권한 허용 화면을 새로 검증한 것은 아니다. 이력은 현재 브라우저에만 저장되며 계정/기기 간 동기화는 제공하지 않는다.
