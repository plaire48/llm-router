# 브라우저 작업 배포 전 검증

2026-09-21, 0.17.0 기반 후보. **동일 빌드의 자동 회귀 검증을 완료했다. 이번 변경은 업로드하지 않았다.**

## 반영한 변경

- 커스텀 ARIA 선택창에서 필수 입력/오류 상태가 관찰 결과에 빠지는 문제를 재현하고 수정했다. 기본 입력 요소와 동일하게 입력 제약을 전달한다.
- 지연 선택 목록, 입력 중 노드 교체, 가림 요소, 동명이인 행 버튼, 비활성 버튼의 지연 활성화, 저장 서버 실패를 실제 Chrome 검사로 추가했다. 앱의 값, 입력/클릭 횟수와 저장 요청 payload로 판정한다.
- `npm run verify:browser`로 후보 빌드와 반복 검사를 묶었다. 실패하면 중단하고 로그를 보존한다. 후보 ZIP은 기존 배포 파일과 분리한다.

## 결과

환경: macOS arm64, Chrome for Testing 149.0.7827.55, 격리 프로필과 합성 사이트/모델 응답.

| 단위 검사 | 243개 통과 |
| 디자인 검사 | 통과 |
| 브라우저 핵심 7개 스위트 | 새 프로필에서 각각 3회 통과 |

핵심 반복은 새 창/탭, 실제 입력과 결과 확인, 승인, 부분 실패 복구, 오래된 ref 거절, 잘못된 완료 보류를 포함한다. 추가 검사는 로그인, 디버거 연결 종료, 긴 출력 복구, 컨텍스트, 실제 사이드 패널, 제공자 전환, FabriX, 계정 사용량, 이미지/캡처/다운로드, 대화 이력과 코드 표시를 포함한다.

통합 실행 중 오래된 테스트 설정 3건을 찾아 수정했다. 제품의 검증/승인 조건을 완화하지 않았다.

1. **AI Pro 사이드 패널:** headless Chrome에서 네이티브 사이트 권한 창이 대기했다. 자동 회귀는 권한을 부여한 테스트 복사본으로 실행하고, 실제 권한 창은 별도의 수동 검사로 분리했다.
2. **ChatGPT 사이드 패널:** 인증 정보만 바꾸고 이전 제공자의 대화를 유지하던 테스트를 실제 `SELECT_PROVIDER` 경로로 수정했다.
3. **이미지 선택 후 재개:** 새 관찰과 독립 결과 검토 요청을 처리하지 못하던 합성 모델 응답을 현재 프로토콜에 맞췄다. 실제 이미지 파일/선택 저장/초안 유지 검사는 유지했다.

실패 기록은 보존했다. 수정한 검사와 남은 검사를 이어서 실행했으며, 모든 실행의 빌드 해시가 동일하고 앞서 통과한 테스트를 변경하지 않았음을 확인한 뒤 결과를 합쳤다. 한 번의 중단 없는 통합 실행으로 표시하지 않는다.

## 남은 검증

실제 AI Pro/ChatGPT/FabriX 모델의 자율적인 도구 선택과 코드 생성 성공률, 사내 사이트/실계정 동작, Windows/Edge, 네이티브 권한 창의 사용자 허용은 이번 결과에 포함하지 않는다. 실제 모델 평가와 미구현 항목은 [품질 개선안](PLAYWRIGHT-QUALITY-PLAN.md)에 구분했다. 자동 회귀 통과를 이 항목들의 검증 완료로 해석하지 않는다.
