# 0.9.0 검증 기록

2026-09-21, macOS와 Chrome for Testing 149.0.7827.55의 임시 프로필에 설치한 확장으로 검증했습니다.

| 검증 | 통과 |
| --- | ---: |
| 단위 테스트 | 125 |
| 대화 압축과 브라우저 작업 이어가기 | 5 |
| 브라우저 코드 실행과 스킬 등록 | 10 |
| 두 제공자 사용량과 한도 표시 | 5 |
| AI Pro 채팅과 중단 | 5 |
| 접근성 | 3 |
| 실제 Chrome 사이드 패널의 ChatGPT 경로 | 4 |

대화 압축은 원본 보존, 최근 지시 유지, 저장 경계와 재진입, 제공자 분리, 토큰 집계, 수동 정리와 초안 보존을 확인했습니다. 여러 요약 요청이 필요한 구간도 각 요청의 usage를 한 번씩 집계했습니다. 단위 테스트에서 잘못된 요약, 취소 후 늦은 응답, 거대한 최신 입력, 오래된/다른 소유자의 저장, 도구 호출/결과 쌍 보존, context overflow 후 모델 요청만 재시도하는 경로를 확인했습니다.

실제 Playwright가 메일 예제 페이지의 제목을 입력한 뒤 모델 응답 대기 중 확장 페이지를 새로고침했습니다. 작업 계획과 완료한 도구 기록은 유지됐습니다. 재진입만으로는 동작하지 않았고, 이어가기 클릭 후 새 페이지 관찰과 입력값 읽기를 거쳐 완료했습니다. 제목 입력 이벤트는 한 번으로 유지됐습니다. 이는 해당 예제의 결과이며 임의 사이트에서 정확히 한 번 실행됨을 보증하지 않습니다. 동작과 기록 사이에 중단되면 결과는 unknown으로 남고 확인이 필요합니다.

기존 브라우저 검증은 관찰한 링크로 새 탭 열기, shadow DOM 제목과 다른 origin iframe 본문 입력, 실제 입력 이벤트, 초안 상태와 비발송, 잘못된 locator의 수정, Qwen용 PNG 전송과 캡처에 묶인 좌표 클릭, 중지 후 후속 동작 차단을 확인했습니다. Qwen의 실제 이미지 판단을 검증한 결과는 아닙니다.

CX 검사에 명시 색상/서체 위반이 없었고 컨텍스트 모달을 360px/1100px에서 확인했습니다. 기존 접근성 경고 회귀도 없었습니다.

## 검증 경계

모델, 인증과 계정 한도 응답은 합성입니다. 실제 회사 SSO/API, ChatGPT 계정 로그인/한도, 실제 모델의 요약 정확도와 장기 작업 성능, 회사 메일 저장은 미검증입니다. ChatGPT 계정 OAuth는 Pi 공개 구현을 적용한 경로이며 범용 OAuth 지원을 보증하지 않습니다.

자동화와 컨텍스트 브라우저 테스트는 격리된 확장 복사본에 예제 사이트 접근 권한을 미리 부여했습니다. 배포본의 최초 네이티브 권한 허용 창을 검증한 결과가 아닙니다. 다른 채팅/사용량/접근성/사이드 패널 테스트는 배포 manifest를 사용했습니다. 라우터나 Node 보조 서버를 실행하지 않았습니다.

배포 소스의 `npm ci` 후 재빌드 결과, 160개 배포 파일이 개발 폴더 빌드와 바이트 단위로 일치했습니다. ZIP 무결성, 버전과 라이선스를 확인했으며 테스트 전용 사이트 권한은 포함하지 않았습니다.
