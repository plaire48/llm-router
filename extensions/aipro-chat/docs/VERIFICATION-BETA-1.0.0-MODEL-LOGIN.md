# Beta 1.0.0 모델 선택창 로그인 버튼

표시 버전은 **Beta 1.0.0**, Chrome 업데이트 번호는 **1.4.6**이다.

## 변경

모델 선택창은 120px 공간 안에 32px 로그인 버튼이 있어 클릭 영역이 작고 여백과 비율이 맞지 않았다. 사용자 HTML의 `head-icon`을 기준으로 버튼을 **64×64px**, 아이콘을 **32px**로 키웠다. 반경은 28%, 위아래 여백은 24px로 맞췄다.

AI Pro는 옅은 블루/보라, ChatGPT는 밝은 회색, FabriX는 옅은 청록색을 사용한다. 아이콘만 표시하며 공통 ActionButton의 툴팁, 키보드 초점과 로그인 동작을 유지한다. 모션 감소에서는 이동 효과를 끈다. 공통 패키지를 수정하지 않고 서비스 토큰과 범위를 제한한 스타일로 적용했다.

## 검증

세 제공자를 320×480, 360×800, 1100×850 화면에서 확인했다. 9개 화면 모두 버튼 64px, 아이콘 32px, 반경 28%이며 가로 넘침이 없다. 키보드 툴팁과 모션 감소도 확인했다.

단위 검사 **285개**, 디자인 검사, 빌드와 관련 브라우저 **8개 스위트 10회**가 통과했다. 제공자 전환은 새 프로필에서 3회 검사하며 취소, 실패, 재로그인, 연결 복원과 제공자별 초안 분리를 확인했다. FabriX 연결, 실제 사이드 패널, 접근성, 공통 모달, 피드백, 첫 화면과 CSP 검사도 포함한다. 합성 계정과 모델 응답을 사용한 검사이며 실제 계정 인증이나 전체 기능 재검증으로 표시하지 않는다.

[검증 보고서](evidence/beta-1.0.0-model-login/report.json), [실제 화면 측정](evidence/beta-1.0.0-model-login/visual.json), [변경 전 크기](evidence/beta-1.0.0-model-login/before.json).

기존 UI 검사의 모든 버튼 반경 12px 조건은 이번 HTML 타일에 맞지 않아 첫 실행에서 실패했다. 연결 타일은 28%, 나머지 조작은 12px를 검사하도록 갱신한 뒤 다시 실행했다. 공통 아이콘 스타일이 크기를 20px로 유지하는 문제도 실제 화면 측정으로 발견해 수정했다. [첫 검사](evidence/beta-1.0.0-model-login/initial-report.json)와 [로그](evidence/beta-1.0.0-model-login/initial-ui.log)는 보존한다.
