# 0.14.1 모델 선택 간소화

검증일: 2026-09-21

- 모델 선택창을 최대 420×440px로 줄였다. 탭 색감, 이동 효과와 키보드 동작은 유지한다.
- 제공자 이름의 반복 행, 계정별 상시 안내, 모델마다 붙던 컨텍스트 설명을 제거했다. 모델 이름과 선택 표시를 남기고 상세 한도는 툴팁/컨텍스트 화면에서 확인한다.
- 검색은 모델이 7개 이상일 때만 표시한다. 새로고침은 목록 오류/빈 결과에서만 제공한다. 로그아웃/연결 편집은 탭 옆 아이콘으로 모았다.
- 로그인 화면의 중복 설명을 제거했다. 만료, 실패와 복구 안내 및 접근 가능한 이름은 유지한다.

검증: `npm run design:check`, `npm run build` 통과. `tests/provider-switch-browser.mjs`의 7개 흐름과 `tests/browser.mjs`의 37개 검증을 통과했다. 페이지 오류는 없었다.

브라우저 검증은 격리 Chrome과 합성 인증/모델 응답을 사용했다. 320/360/1100px, 짧은 목록과 긴 목록 검색, 좁은 창에서 긴 모델명, 선택/키보드/초점 복귀, 탭 모션과 모션 감소, 제공자 연결/전환/로그아웃/초안 복원 및 오류 복구를 확인했다. 인증 프로토콜과 제공자 API는 변경하지 않았다. 실제 사내 SSO와 제공자 계정 검증은 포함하지 않는다.
