# 완료 판단과 실제 작업 평가 개선

2026-09-23. 확장 단독 실행과 기존 CX 화면을 유지한다.

## 발견한 부족점

| 문제 | 수정 전 재현 | 적용 |
| --- | --- | --- |
| 행동 없는 완료 답변 | 본문 값은 비어 있고 입력 0회인데 완료로 종료 | 도구 근거가 없는 답변은 노출 전에 요청 유형 검토 |
| 잘못된 평가 대상 | 초안이 있는 작업 창 대신 원래 탭 검사 | 대화, 제공자, 인증 시점에 묶인 실제 작업 탭 검사 |
| 복구와 질문 구분 | 위 경로에서는 복구 판단 자체가 생략됨 | 명확한 작업은 관찰부터 이어가고 필요한 선택은 기존 질문 폼으로 받음 |

수정 전 실제 Chrome 재현: `verification/completion-quality/probes.json`. 합성 모델 응답으로 결함을 유발했으며 실제 Qwen 성공률 측정은 아니다.

## 실행 흐름

도구를 쓰지 않고 끝내려는 답변만 별도 의도 검토를 거친다. 같은 제공자와 선택 모델을 도구 없이 호출하며 현재 요청과 이전 사용자 제한을 보존한다.

- 일반 대화: 답변을 반환한다. 페이지를 읽거나 계획을 만들지 않는다.
- 브라우저/프로젝트 작업: Pi `Agent.followUp()`으로 관찰과 누락 작업을 이어간다. 기존 행동 후 검증과 최종 요구사항 검토를 유지한다.
- 필요한 사용자 정보가 없음: 기존 객관식/주관식 질문 카드로 기다린다. 최종 거래 승인은 기존 HITL을 사용한다.
- 보완 후에도 근거가 없음: 같은 완료 답변을 반복하지 않고 대상/막힌 부분을 질문한다. 전체 작업 횟수 상한을 새로 두지 않는다.
- 검토 응답 형식 오류: 페이지 작업을 반복하지 않고 검토만 한 번 재요청한다. 이후 실패하면 미검증 답변을 노출하지 않는다.

계획 갱신, 도구 선택, 스킬 조회는 페이지 작업 근거로 세지 않는다. 의도 검토를 최종 검증 통과 기록으로 저장하지 않는다. 검토 사용량은 기존 ledger에 포함하며 사용자 선택 모델을 바꾸지 않는다. 일반 대화도 브라우저 도구가 제공된 상태라면 검토 1회의 지연과 토큰이 추가된다.

읽기 전용 스킬의 기존 응답 경로는 유지한다. 도구 실행 이후 모든 요구를 독립 검토하는 범위는 기존 자동화 하네스 범위와 같다. 모든 스킬의 검증 수준을 동일하게 만드는 변경은 아니다.

## 평가 대상

원본 탭 ID를 생성 시 확정한다. 같은 URL인 오래된 작업 탭을 검색해서 재사용하지 않는다. 종료 후 `browserContexts`와 `browserWorkspaces`의 현재 대화 소유권을 확인하고 실제 탭의 값, 입력 횟수와 제출 횟수를 읽는다. 새 창/자식 탭과 현재 탭 모드를 구분한다. 별도 창에서는 원본 페이지가 바뀌지 않았는지도 검사한다. 닫힌 창이나 인증 시점이 다른 기록을 원본 탭으로 대체하지 않는다.

## 남은 부족점

1. **실제 Qwen 정확도와 비용**: 평가용 인증이 없어 합성 응답으로 검증했다. 같은 모델이 실행과 검토를 맡으므로 오판이 함께 발생할 수 있다. 잘못된 완료율, 중복 입력, 요청 수, 지연을 실모델로 비교해야 한다.
2. **채팅 창 종료 후 지속 실행**: 이후 worker 소유 실행기로 개선했다. 채팅 화면 종료 후 지속 실행과 강제 worker 종료 시 일시 중지의 검증 범위는 [백그라운드 실행](BACKGROUND-EXECUTION-DESIGN.md)을 따른다. Chrome 종료까지 무중단 실행을 보장하지 않는다.
3. **고객 인수 테스트 문서화**: 코드 변경 근거, 각 화면의 실행/캡처 근거와 Office 문서의 왕복 연결은 별도 구현 과제다. 캡처와 이번 검증 개선만으로 전체 연결이 완성된 것은 아니다.

## 검증

`tests/completion-review.test.mjs`: 파서, 제한 보존, 후속 복구, 메타데이터 구분, 질문/취소, 검토 오류와 평가 소유권.

`tests/completion-review-browser.mjs`: 자동 복구, 일반 대화, 정보 질문, 진행 없는 반복, 검토 형식 실패, 현재 탭 입력, 자식 창 입력의 7개 실제 Chrome 흐름. 모델 응답과 업무 사이트는 합성이다. 후보 패키지와 최종 회귀 결과는 이번 검증 보고서를 따른다.

검증 완료: 단위 검사 448개, 디자인 검사, 후보 빌드, 실제 Chrome 검증 24회 통과. 핵심 7개 묶음을 새 프로필에서 3회씩 검사했고 ChatGPT/FabriX/네이티브 사이드 패널을 추가 확인했다. 전체 기능 행렬이나 실계정 검증을 뜻하지 않는다.

- [통합 보고서](../verification/completion-quality/report.json): 동일 빌드 해시의 핵심 21회와 제공자 3회 결과를 연결했다. 초기 제공자 테스트 실패 기록은 원본 보고서에 보존하고 수정한 합성 응답/현재 탭 설정을 명시했다.
- [설치용 후보 ZIP](../verification/completion-quality/nubi-beta-1.0.0-harness-quality.zip): ZIP 무결성과 전체 437개 파일의 dist 일치 확인. 공개 업로드나 자동 설치는 하지 않았다.
- [실제 모델 평가](../verification/agent-live-evaluation.json): `QWEN3.8-27B-FP8-256K`, `not_configured`. 환경변수와 프로젝트 `.env` 위치를 확인했으며 평가용 인증이 없어 API 호출을 실행하지 않았다.
