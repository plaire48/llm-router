# 모델 목록과 이미지 자동 전환

수신 모델의 분류/이름으로 목록을 줄이지 않는다. 모델 선택창은 AI Pro의 최신 목록을 조회하며, 이미지가 필요한 요청은 같은 제공자의 이미지 지원 모델로 보낸다.

## 확인한 원인

사용자 진단의 수신 5 / 표시 5는 마지막 `modelList` 응답의 5개를 모두 표시했다는 뜻이다. `_CLI`, `_rag`, `_general`, 하이픈 유무로 필터링하는 코드는 없다. 제공한 10개 예시는 이전 배포 ZIP의 파서에서도 10개 모두 통과했다. 실제 사내 API가 5개를 반환한 원인은 여기서 확인하지 못했다.

별도로, 기존 배포에서는 캐시에 모델이 있으면 모델 선택창을 열어도 다시 조회하지 않고 새로고침도 숨기는 문제를 재현했다. 해당 실패 기록을 보관했다.

## 변경

- AI Pro 모델 선택창을 열 때 최신 목록을 한 번 조회한다. 기존 목록과 사용자 선택은 조회가 끝날 때까지 유지한다. 오류에도 이전 목록을 보관한다.
- 연결된 모델 선택창에 새로고침 아이콘을 유지한다. 자동 조회에는 완료 토스트를 띄우지 않으며 키보드 초점을 복구한다. 이전 캐시는 목록 버전 6으로 갱신한다.
- 이미지 첨부, 캡처 또는 이미지 비교 결과가 실제 입력에 포함되면 이미지 지원 모델로 요청한다. AI Pro는 반환된 Qwen 3.8 모델을 사용하며 `QWEN3.8-27B-FP8-256K`를 우선한다. 해당 이름이 없으면 반환된 같은 계열 모델을 사용한다. 목록에 없는 모델은 만들지 않는다.
- 같은 Pi 대화, 계획, 도구 결과와 검증을 이어간다. 모델 전환으로 페이지 작업을 재실행하지 않는다. 저장된 모델 선택은 유지하고 실제 응답 모델과 전환 진행을 표시한다.
- 공유 컨텍스트는 두 모델 중 작은 입력/출력 한도를 따른다. 두 모델 응답의 실측 토큰은 기존 제공자 사용량에 함께 집계한다.
- 계정이나 제공자를 자동 변경하지 않는다. 이미지 모델이 없으면 기존 안내/질문 경로를 사용한다. FabriX 이미지 전송은 현재 어댑터에서 지원하지 않는다.

## 검증 범위

Chrome의 격리된 프로필과 합성 API 응답으로 검증한다. 브라우저 캡처, 스크립트 실행, 다운로드 파일, 저장소와 화면은 실제로 확인한다. 사내 SSO/AI Pro 실계정 및 실제 Qwen의 이미지 해석 정확도는 별도 검증이 필요하다.

검증 보고서와 화면은 `docs/evidence/beta-1.0.0-model-routing/`에 보관한다. ZIP은 검증한 후보를 재빌드 없이 승격한다.

단위 313개와 Chrome 22회 실행을 통과했다. 핵심 5개 스위트는 각 3회 반복했다. 두 검증 보고서의 빌드 SHA-256은 동일하다. FabriX 테스트는 저장 완료와 화면 갱신 사이를 기다리도록 보정했으며 이전 실패 기록과 최종 통과 기록을 모두 보관한다.
