# 0.13.1 아이콘 중심 조작

검증일: 2026-09-21

의미가 명확한 조작은 아이콘만 표시하고, 호버와 키보드 포커스의 툴팁 및 접근 가능한 이름을 유지한다. 이 사용자 기준을 AGENTS.md와 DESIGN-SYSTEM.md에 명시했다.

- 대화 이름과 스킬 편집의 저장/취소를 CX ActionButton 아이콘으로 변경했다.
- 페이지 입력 검토의 취소, 대화 재연결과 FabriX 연결을 아이콘으로 정리했다.
- 대화 이력의 중복된 ‘현재’ 문구를 제거하고 선택 배경/테두리와 aria-current를 유지했다.
- 대화 재연결 안내를 제공자 이름과 ‘연결 필요’로 줄였다.
- 작업 목록의 완료/진행은 체크/스피너로 표시하고 스크린 리더 설명을 유지한다. 오류와 취소 상태는 짧은 문구를 남긴다.
- 제공자/모델 식별, 연결 테스트, 페이지 입력 적용과 삭제 확인은 의미를 판단하는 데 필요한 텍스트를 유지한다.

`npm run design:check`와 빌드가 통과했다. 기존 conversations-browser와 fabrix-browser에서 저장, 선택, 삭제, 연결 테스트와 연결, 키보드 초점 복귀 및 360px/1100px 화면을 확인했다. 실행/인증/저장 계약은 변경하지 않았다. 실제 회사 API는 재검증하지 않았으며 기존 0.13.0 기능 검증 범위를 따른다.
