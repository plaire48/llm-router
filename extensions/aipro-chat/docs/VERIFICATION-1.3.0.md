# 누비 1.3.0 승인과 질문 폼

2026-09-22. 기준 HTML의 흰 카드와 옅은 입력 영역, CX 글꼴과 버튼을 승인·질문·편집 폼에 함께 적용했다.

## 반영한 흐름

- 최종 반영 카드는 초안 미리보기, 연필 수정과 실제 작업명 승인 버튼을 제공한다. 페이지 입력 확인 모달도 같은 표면과 하단 동작을 사용한다.
- 초안 수정은 전체 필드 값을 읽어 편집한다. 닫았다 다시 열면 해당 화면의 수정 내용이 유지된다. 미반영 수정이 있으면 등록 대신 수정 계속을 표시한다. 수정 전으로 되돌리기와 반영은 아이콘이다.
- 질문은 2~4개 텍스트 선택지, 실제 이미지 선택지, 한 줄 주관식과 긴 서술형을 지원한다. 선택지 밖의 답변도 연필로 작성한다.
- 짧은 답변은 Enter, 서술형은 Ctrl/Command+Enter로 전송한다. 서술형의 Enter는 줄바꿈이며 한글 조합 Enter로 전송하지 않는다. 여러 줄 붙여넣기는 입력란을 펼치고 줄바꿈을 보존한다.
- 답변 초안은 해당 질문에 저장해 새로고침과 대화 전환 후 복원한다. 일반 채팅 초안과 첨부 파일은 따로 유지한다. 전송 실패 시 답변 입력을 유지한다.
- 실행 승인은 기존의 계정·대화·질문·실제 DOM·초안 해시·만료 검사와 1회 실행 제한을 유지한다. 주관식 답변은 최종 실행 권한이 되지 않는다. 수정은 페이지에 반영·검증한 뒤 새 승인을 요청한다.

선택지는 모델이 질문 도구를 호출할 때 실제 근거나 필요한 선호에 맞게 구성한다. 입력 길이는 16,000자다. HITL 편집 중인 값은 편집창을 닫아도 같은 화면에서 유지되지만, 새로고침을 넘는 편집 초안 저장은 포함하지 않는다. 질문 답변 초안의 영속 저장과 구분한다.

## 검증

단위 테스트 **278개**, CX 디자인 검사와 빌드가 통과했다. 최종 후보에서 Chrome 스위트 **14개의 22회 실행**을 완료했다. 질문 폼, 첨부, 새 창 승인, 제공자 전환 4개 스위트는 새 프로필로 3회씩 검사했다. [전체 기록](evidence/1.3.0-report.json).

- 320/360/1100px 폼, 모달 글꼴, 줄바꿈, 직접 입력 초점과 키보드 전송.
- 답변/파일 초안 분리, 새로고침/대화 전환 복원, 전송 실패/재시도, 오래된 질문과 다른 제공자/대화 쓰기 거부.
- 실제 페이지 초안 수정/취소/1회 승인 실행, DOM 변경과 만료 거부, 새 창 작업, 기존 이미지 선택과 다운로드.
- 사이드 패널, ChatGPT와 FabriX 합성 통신, 대화 이력, 첨부, 설정 접근성, 기존 입력 제안/스킬 흐름.

수정 전 초점 타이밍 실패와 오래된 테스트 기준으로 실패하거나 의도적으로 중단한 검사는 위 횟수에 포함하지 않았다. 제외 기록과 사유를 증거 파일에 남겼다. 변경 범위의 선택 회귀이며 전체 제품/실계정 전수 검사로 표현하지 않는다.

## 확인 범위

Chrome에 실제 확장을 로드해 폼, 저장, 키보드, 새로고침, 페이지 입력과 승인 실행을 검증한다. 모델과 계정 응답은 합성이며 실제 AI Pro/ChatGPT/FabriX 계정 또는 모델의 질문 판단 성능을 검증한 것은 아니다. 한국어 조합 상태와 붙여넣기는 DOM 이벤트로 검사하며 실제 OS IME 사용 검증과 구분한다. 사이트 권한은 테스트 복사본에 미리 부여한다.

GitHub와 웹 스토어에는 게시하지 않았다.
