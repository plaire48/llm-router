# 질문을 통한 요구사항 확인

질문 전에 현재 대화의 사용자 발언과 답변, 관련 화면 정보·첨부 자료·검토한 사이트 위키·스킬을 먼저 확인한다. 최신 정정을 우선하며, 이미 해결된 내용을 다시 묻지 않는다. 필요한 자료만 조회하고 검색이 막히면 반복하지 않는다. 사용자만 정할 수 있는 대상, 필수 값이나 결과가 불명확하면 `ask_user` 폼으로 확인한다. 한 카드에는 다음 행동에 필요한 한 항목만 묻는다. 답변에 따라 다음 항목을 정하고, 이미 받은 답변은 다시 묻지 않는다.

## 적용

- 근거가 있는 선택지 2~4개를 우선 제시한다. 사용자 선호에 대한 대안은 제안할 수 있지만, 수신자나 페이지에 없는 대상을 만들어내지 않는다.
- 직접 입력란은 선택지 아래에 항상 보인다. 작은 연필 버튼을 찾아야 했던 흐름을 제거했다. 이미지 선택 질문에도 같은 규칙을 적용한다.
- 짧은 답변을 기본으로 하고, 본문 자체가 필요한 질문만 여러 줄을 사용한다. `input_placeholder`는 최대 100자의 한 줄 입력 안내다. 안내는 답변이나 기본값으로 처리하지 않는다.
- 일반 실행, 계획 수립, 완료 판단, 결과 검토, 오류 복구가 같은 질문 지침을 사용한다. 정보 부족을 안내 문장으로만 남기지 않고 질문 도구로 전환하도록 지시한다.
- 영속 질문/답변과 기존 Pi 실행 중단/재개 경로를 유지한다. 미응답 질문 이후 도구 실행을 차단하고, 원래 목표와 이전 답변을 보존한다. 오래된 질문에 대한 답변은 거절한다.
- 게시, 발송 등 최종 동작 승인은 `request_approval`로 별도 처리한다. 질문 답변은 실행 승인이 아니다.

좁은 사이드 패널에서 여러 질문을 한꺼번에 늘어놓는 대신 순차 폼을 사용한다. 누비가 첫 답변을 읽고 남은 질문의 필요성을 판단하므로 불필요한 항목도 줄일 수 있다. 한 번에 여러 질문을 제출하는 설문 기능은 추가하지 않았다.

## 공식 사례와 오픈소스 판단

- [Anthropic Agent SDK 사용자 입력](https://code.claude.com/docs/en/agent-sdk/user-input): 선택형 질문과 자유 입력을 제공하고 실행을 멈췄다가 답변으로 이어가는 패턴을 참고했다. 이 SDK의 호스트 런타임을 브라우저 확장에 추가하지 않았다.
- [OpenAI Codex 질문 처리 구현](https://github.com/openai/codex/blob/main/codex-rs/core/src/tools/handlers/request_user_input.rs): 질문별 응답 연결, 빈 응답 제외, 질문/답변의 문맥 보존을 참고했다. Apache-2.0 저장소의 설계 참고이며 코드를 복사하거나 Rust 런타임을 번들하지 않았다.
- 이미 사용하는 MIT Pi Agent Core와 React, 기존 TypeBox 도구 검증 및 CX 폼을 재사용한다. 별도의 설문 라이브러리는 현재 단일 항목 질문에 불필요한 상태 관리와 번들 비용을 추가하므로 도입하지 않았다.

## 검증 경계

단위 검사는 입력 안내 검증, 질문/승인의 분리, 저장 실패와 실행 중단을 다룬다. 실제 Chrome의 합성 모델 응답으로 선택지/직접 입력, 키보드와 한글 조합, 320/360/1100px, 새로고침과 대화 복원, 두 번의 순차 질문, 오래된 답변 거절, 원래 목표/두 답변 보존을 검사한다. 명확한 작업 진행 및 모호한 작업의 실제 LLM 질문 품질은 사내 계정 기반 평가가 별도로 필요하다.

## 세션 기록과 저장 지식

작업 기록과 질문/답변은 현재 대화에 속한다. 스킬·위키 초안의 실행 근거는 해당 대화에서 선택한 완료 작업이다. 다른 대화의 기록을 자동 합치지 않는다. 저장한 사이트 위키는 같은 사이트/제공자 범위에서 다른 대화도 참고하는 별도 지식이며 현재 실행이나 승인 근거가 아니다.

생성기에 앞서 현재 세션의 사용자 발언을 최대 12개, 본문 합계 6,000자까지 전달한다. 최신 발언부터 선택한 뒤 원래 순서로 제공하며, 긴 문장을 잘라 금지 조건을 잃지 않도록 완전한 문장만 남기고 생략 수를 표시한다. 일반적인 인증값을 가리고, 모델이 생성한 주장이나 다른 세션 이력, 첨부 원문은 포함하지 않는다. 생략은 사용자가 정보를 주지 않았다는 뜻이 아니다. 선택지와 자유 입력의 기존 CX 폼을 그대로 사용한다.

[Anthropic의 필요한 문맥 검색](https://www.anthropic.com/engineering/effective-context-engineering-for-ai-agents)과 [OpenAI Agents SDK의 중단·재개](https://openai.github.io/openai-agents-js/guides/human-in-the-loop/)를 참고했다. 이미 사용 중인 Pi/React/검증 스키마를 재사용하며 별도 설문 런타임은 추가하지 않았다. 프롬프트와 자료 전달 검증은 실모델의 질문 적절성 평가와 구분한다.
