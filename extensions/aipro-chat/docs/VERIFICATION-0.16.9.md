# 0.16.9 코드 구문 강조

답변의 코드 블록을 단색 텍스트로 표시하던 부분에 구문 색상과 줄 번호를 추가했다. 가리킨 줄은 옅게 강조하고 복사 아이콘은 원문만 복사한다. 버튼과 설정을 추가하지 않는다.

- 기존 사용자 HTML의 밝은 코드 표면, 블루, 청록, 보라와 시스템 모노스페이스를 사용한다. 코드 글자는 13px이며 긴 줄은 코드 블록 안에서만 가로 스크롤한다. 키보드로도 스크롤할 수 있다.
- lowlight 3.3.0의 공통 언어 문법을 로컬 번들로 사용한다. 구문 트리를 React 텍스트와 span으로 렌더링하며 HTML 코드도 실행하지 않는다. 코드 원문을 외부 강조 서비스로 보내지 않는다.
- 언어가 있으면 해당 문법을 사용하고, 언어가 없는 짧은 코드는 제한한 후보에서 추정한다. 알 수 없는 언어는 평문으로 표시한다. 작성 중 닫히지 않은 코드 블록도 계속 표시한다.
- 빈 줄과 들여쓰기를 보존한다. 줄 번호는 보조기술에서 숨기고 텍스트 선택과 복사에 넣지 않는다. 60,000자나 2,000줄을 초과하면 강조와 줄별 DOM 생성을 생략하지만 원문과 복사 내용은 유지한다.

## 검증

- 단위 테스트 242개 통과. JavaScript, Python, JSON, HTML, SQL, 별칭, 여러 줄 주석, 작성 중인 코드, 미지원 언어와 큰 코드의 처리를 확인했다.
- `code-browser` 6개 통과. 실제 확장에서 구문별 색상, 줄 높이와 강조, 빈 줄, 360px/1100px 레이아웃, 키보드 가로 스크롤, HTML 비실행, 실제 Chrome 클립보드 원문 복사, 대화 새로고침과 큰 코드 복사를 확인했다.
- 기존 `feedback-browser`의 복사 성공, 지연, 실패, 재시도, 토스트와 모달 초점 검증 통과.
- `npm run design:check`, `npm run build` 통과. 강조 라이브러리 라이선스를 설치 ZIP에 포함했다.

대화 본문과 모델 응답은 합성 fixture다. 이번 변경은 표시 방식이며 인증, 모델 호출과 페이지 자동화 동작은 변경하지 않았다.
