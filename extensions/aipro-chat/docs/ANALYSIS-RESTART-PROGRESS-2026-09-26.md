# 하위 분석 재개와 완료율 집계

## 현재 집계

등록 항목은 56개다. 구현 45개, 개발 대기 1개, 외부 검증 5개, 비채택 5개다. **45/51 = 88.2%**는 비채택을 제외한 항목 수로 계산한 구현율이다. 작업량 가중치, 전체 제품 준비도, 실계정 성공률이 아니다. `quality:status`와 `quality:report`에서 자동 계산한다. 현재 소스와 일치하는 핵심 gate가 없으면 검증한 구현 개수는 미확인으로 둔다.

이전 44/48 = 91.7%에는 문서에만 남은 전체 워커 복원과 사용자 선택 모델의 네이버 재평가가 빠져 있었다. 각각 NQ-49, NQ-50으로 추가했다. 이번 제한된 재개 보완은 NQ-48이다. 비채택 기술은 미완료 기능이나 구현 완료로 계산하지 않는다.

## 확인한 문제와 적용

이전 START_CHAT 재개는 목표/계획/영수증/요약을 전달했지만 실패한 응답의 trace에 남은 하위 분석 상태는 전달하지 않았다. collect_analysis의 작업 ID도 새 실행기의 메모리에 존재하지 않는다. 같은 실행의 압축 후 재조회와 프로세스 종료 후 복원은 다른 경로다.

재개 시 같은 작업의 assistant trace에서 하위 분석 힌트를 뽑아 다음 작업 체크포인트와 모델 문맥에 전달한다. 작업 목적, 완료 기준의 표시 내용, 부분 결과, 미해결 사항, 다음 행동과 취소 상태를 최대 12개 유지한다. 완료 보고보다 미해결/취소 기록을 우선한다. 기존 요약 없이도 작동하고 반복 재개 시 독립 사본으로 이어진다.

이 기록은 **부분적인 표시 힌트**다. 원래 assignment 전체, 제약, 인용 원문, 문서 해시, 모든 읽은 범위를 복원하지 않는다. trace 자체가 제한된 최근 기록이므로 omittedAtLeast가 0이어도 누락이 없다는 뜻이 아니다. 생략 개수는 하한이며 모델에 이 한계를 명시한다.

실행 메모리, 이전 coordinator ID, evidence ID, 소스 본문과 권한을 저장하지 않는다. 이전 결과는 미검증 조언이며 원래 사용자 요구와 현재 허용된 출처를 다시 확인하도록 한다. 취소 자동 재개와 미확정 쓰기 재전송은 추가하지 않는다. 전체 복원 NQ-49는 여전히 개발 대기다.

## 검증

단위 검사는 상한, 미완료 우선, 취소/부분 상태, 반복 재개, 독립 사본, 인증/소스 ID 제거와 완료율 분모를 검증한다. 실제 Chrome의 START_CHAT/CONNECT_PAGE에서 연결 없는 재개 거부 후 소유 응답의 분석 힌트를 전달하고 다음 체크포인트에 저장하는지 검사한다. 모델 응답과 실제 서버 저장은 검증하지 않는다.

첫 통합 검사에서 새 모듈의 패키징 목록과 단위 검사 로더 누락을 발견해 수정했다. 브라우저 시작 대기에도 제한을 추가했다. 실패 gate 기록은 보존하며 수정 전 결과를 최종 성공으로 계산하지 않는다.

최종 동일 후보의 **단위 991개, 디자인 검사, 후보 빌드, Chrome 핵심 회귀 107회**가 통과했다. baseline v8의 110단계이며 전체 배포 매트릭스/실계정 시험이 아니다. [보고서](../verification/pre-release-2026-09-26T13-30-07-219Z/report.json)와 [자동 집계](../verification/analysis-checkpoint-status.json)를 남겼다. 현재 소스/테스트/공유 입력 해시도 보고서와 일치하며 quality:status는 45개 구현 항목의 현재 핵심 gate를 인정한다. 실모델 정확도는 미측정으로 유지하고 배포하지 않았다.

검사 종료 후 dist와 후보 ZIP 해시도 보고서와 재대조해 일치했다. 후보 ZIP SHA-256은 `a779e25ac15194cbc28421f01182c0ecbcc14781ede3147a5705e38f39549b98`이다. 기존 배포 ZIP을 교체하지 않았다.
