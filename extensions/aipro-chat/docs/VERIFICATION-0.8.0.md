CX 검사에 명시 색상/서체 위반이 없었고 360px/1100px 화면을 확인했습니다. 소스 배포 폴더의 npm ci와 재빌드 후 159개 배포 파일이 원본 빌드와 바이트 단위로 일치했습니다. ZIP 무결성과 실행기/라이선스 포함을 확인했습니다.

자동화는 홈페이지 링크로 새 탭을 열고, shadow DOM 제목과 별도 origin iframe 본문을 입력했습니다. 실제 이벤트, 입력 유지, 초안 상태, 비발송을 확인했습니다. 잘못된 Playwright locator의 오류를 다음 모델 응답에 전달한 뒤 수정 코드를 실행했습니다. PNG를 Qwen 형식 image_url로 전송하고 캡처 ID에 연결한 좌표 클릭을 확인했습니다. 중지는 대기 중인 스크립트를 종료하고 후속 동작을 막았습니다.

모델 응답과 계정 응답은 합성입니다. 자동화 테스트 복사본에는 fixture 사이트 접근 권한을 미리 부여했으므로 배포본의 최초 권한 허용 창을 검증한 결과는 아닙니다. 다른 채팅/사용량/접근성 테스트는 배포 manifest를 사용했습니다. 실제 회사 SSO/API, 실제 ChatGPT 계정 한도, 실제 Qwen 이미지 판단과 회사 메일 저장은 미검증입니다.
