# 브라우저 누비 품질 작업 목록

기준일: 2026-09-25. **현재 우선순위와 다음 작업은 이 문서에서 관리한다.** 개별 검토 문서는 당시 변경과 검증의 이력으로 보존한다. 과거의 완료 표시나 테스트 개수를 최신 후보의 품질로 합산하지 않는다.

## 진행 원칙

한 번에 한 항목을 진행한다. 재현/정답 → 작은 변경 → 해당 회귀 → 같은 후보의 핵심 회귀 → 근거 기록 순서다. 외부 조건 때문에 실행할 수 없는 항목은 대기로 남기고 다음 실행 가능한 항목으로 이동한다. 실패는 보존하고 원인 수정 없이 반복하여 통과로 바꾸지 않는다. 이미 검증한 변경은 새 실패나 입력 변경이 있을 때 다시 연다.

상태는 대기, 진행, 로컬 검증, 외부 조건 대기, 후순위로 구분한다. 로컬 검증은 실모델 정확도, 실제 계정, 설치 또는 배포 완료가 아니다. 재현되지 않은 우려는 결함으로 확정하지 않는다.

## 방법론과 오픈소스 선택

2026-09-24 공식 문서와 현재 실행 코드를 재확인했다.

- [Anthropic agent evals](https://www.anthropic.com/engineering/demystifying-evals-for-ai-agents)의 회귀/능력 평가 분리와 task/trial/독립 outcome grader를 적용한다. NQ-01과 NQ-02/03을 분리한 근거다. 방법론 참고이며 SDK 도입이 아니다.
- 기존 Playwright 1.62.1(Apache-2.0)과 Node test runner를 재사용한다. [확장 격리 프로필](https://playwright.dev/docs/chrome-extensions)과 `verify-browser.mjs`의 해시/중단/로그를 사용해 `verify:quality`를 추가한다. 별도 품질 서버나 프레임워크 의존성을 늘리지 않는다.
- 기존 DeepAgents 1.13.2, LangChain, MiniSearch 7.2.0(MIT)은 제품에서 사용 중이다. [DeepAgents 문맥 격리](https://docs.langchain.com/oss/javascript/deepagents/subagents)를 유지한다. 이번에는 교체하지 않고 정답/인용 품질을 NQ-03에서 비교한다.
- WebArena-Verified는 기존 공식 채점기를 유지한다. 실제 누비 실행 연결 없이 사례 점수만 가져오는 방식을 채택하지 않는다. 라이선스/고정 버전은 [기존 검토](PUBLIC-BENCHMARK-EVALUATION.md)를 따른다.

## NQ-01 실행 기록

초기 `verify:quality`는 고정 프로필 `quality-baseline-v1`을 기록했다. 현재는 새 회귀 4개를 추가한 `quality-baseline-v2`다. 환경의 `NUBI_TEST_SUITES`와 동시에 지정하면 조용히 축소하지 않고 거부한다. 기존 선택 실행도 빈 목록/중복/알 수 없는 이름을 거부한다. 이전에는 빈 문자열/쉼표만 전달하면 브라우저 0회로 게이트만 통과할 수 있었다.

기본 반복 횟수는 3회다. 개발 중 `NUBI_TEST_REPEATS=1`로 줄인 결과는 이 기준선 완료로 인정하지 않는다. 보고서의 `profile`, 선택 목록, 반복 횟수, 8개 영역의 누락 수와 원본 실행 상태를 함께 확인한다.

실행 환경은 기존 [개발 검증](../TESTING.md)을 따른다. 이번 검사는 `CHROME_BINARY`에 Playwright의 전체 Chromium 실행 파일을 지정하고 `NUBI_TEST_CONCURRENCY=2`로 실행했다. 개인 브라우저 프로필을 쓰지 않는다.

- [빈 선택 CLI 음성 검사](../verification/pre-release-2026-09-24T13-50-42-417Z/report.json): 의도한 실패, 게이트/브라우저 실행 0회. 이 실패를 회귀 성공 보고서에 합치지 않는다.
- [실모델 사전 조건 확인](../verification/agent-live-2026-09-24T13-43-51-349Z.json): `not_configured`, 모델/브라우저 실행 0회.
- [동일 후보 핵심 회귀](../verification/pre-release-2026-09-24T13-48-12-494Z/report.json), [영역별 결과](../verification/pre-release-2026-09-24T13-48-12-494Z/QUALITY.md): 단위 **694/694**, 브라우저 **61/61**, 디자인/후보 빌드 통과. 8개 영역 모두 누락/실패 0. `fullMatrix=false`, `actualModel=false`, `releaseApproved=false`를 유지한다.
- 빌드 트리 SHA-256: `dd1ae3052c161aea7c3b9e6dc9086ab6fc8f5409f2a194a64b57dce1759a2deb`.

- 신규 회귀 3개는 선택 목록의 빈 값/중복/알 수 없는 이름, 환경 필터 충돌, 고정 프로필의 필수 시나리오 누락을 검사한다. 실제 CLI 음성 검사도 별도 수행했다.
