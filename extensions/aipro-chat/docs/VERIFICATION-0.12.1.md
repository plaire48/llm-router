# 0.12.1 Plain Korean wordmark

검증일: 2026-09-21

누비의 이미지 글자를 로컬 Noto Sans KR 700 텍스트로 바꿨다. 상단 로고에 진한 청록 단색과 차분한 자간을 적용했다. 메인 제목 “웹을 누비는 AI Agent, 누비”는 이름까지 같은 스타일과 진한 청록 단색으로 한 줄에 표시한다. 빈 채팅의 질문은 진한 청록과 진한 블루의 그라데이션으로 강조하고 설명은 차분한 회색을 유지한다. 설명은 “작은 뱁새가 웹을 누비며 / 탐색부터 입력과 실행까지 대신합니다.” 두 줄로 다듬어 캐릭터가 사용자를 돕는 이야기를 살리고 로그인 화면의 반복 질문은 제거했다. 새 캐릭터와 모션, 사용자 말풍선과 Agent 본문 구조는 유지했다. 사용하지 않는 배포용 이미지 글자와 생성 경로를 제거했다.

- `npm run design:check`: 통과.
- `npm run build`: 0.12.1 설치 ZIP 생성.
- `tests/welcome-browser.mjs` 기반 화면 검증: 320/360/1100px 폭, 480px 높이를 포함한 로그인/채팅 배치, 모션 감소, 입력창 위치, 재진입 확인. 실제 계산된 로컬 폰트, 제목 한 줄과 동일 스타일, 짧은 설명, 반복 질문 제거를 추가 확인했다.
- `scripts/brand-preview.mjs`: 실제 확장 컴포넌트로 로그인 화면과 새 로고 PNG를 생성하고 시각 확인.

이 버전은 로고 서체, 첫 화면 문구와 색상 정리다. 인증과 하네스는 변경하지 않았으며 실제 계정/사내 API를 새로 검증하지 않았다. 이전 기능 검증은 [0.12.0 기록](VERIFICATION-0.12.0.md)을 따른다.
