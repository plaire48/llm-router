# nubi Beta 1.0.0 — beta29

표시 버전 **Beta 1.0.0**, Chrome 업데이트 번호 **1.4.32**.

## 변경

- 검토한 화면 지식을 저장하고 다시 찾는 내장 사이트 위키, 업무 스킬 생성과 ZIP 공유를 추가했습니다. 오래되거나 삭제한 지식을 새 작업의 근거로 잘못 사용하는 경우를 막았습니다.
- 실행 중 메시지 대기열과 순서 변경, 하위 분석 진행 표시, 긴 문서 분할 읽기, 지연된 조회와 모델 응답 복구를 보강했습니다.
- 모달과 펼친 문서의 폰트·색상·간격을 HTML 기준으로 맞췄습니다. 반복 설명을 줄이고 명확한 조작은 이름과 툴팁이 있는 아이콘으로 정리했습니다.
- 최종 검사에서 발견한 기본 브라우저 지침 중복을 제거했습니다. 긴 첨부 문서의 요청 크기 제한은 그대로 유지하며, 사용자 지정 스킬 지침과 승인·검증 규칙을 보존합니다.
- 연결된 OpenWiki 서버의 질문 기반 검색 소스와 의존성을 함께 반영했습니다. 기존 폴더 읽기 방식도 유지합니다.

## 검증

- 단위 검사 **581개**, 디자인 검사와 후보 빌드 통과.
- 실제 Chrome 회귀 **200회** 통과. 57개 핵심 흐름은 새 프로필로 각각 3회, 나머지 29개 화면/통합 흐름은 1회 확인했습니다. 창 포커스 복원도 세 번 확인했습니다.
- 이전 배포 beta14에서 업데이트 후 확장 ID·대화·초안·모델·작업 위치 유지와 새로고침 확인.
- 별도 체크아웃에서 의존성을 새로 설치한 빌드 **575개 파일 일치**. ZIP 무결성과 검사한 빌드의 일치 확인. 추가 권한 없음.
- 의존성 감사: 보고된 취약점 **0개**. OpenWiki 연결·검색 테스트 **11개**와 별도 빌드 통과.

## 설치

ZIP을 풀고 `chrome://extensions`에서 개발자 모드를 켠 뒤 **압축해제된 확장 프로그램 로드**로 선택합니다. 기존 사용자는 기존 설치 폴더의 파일을 교체하고 새로고침하세요. 웹 스토어 배포본은 아닙니다.

## 확인 범위

실제 Chrome과 합성 사이트·모델 응답을 검증했습니다. 실제 회사망 SSO/API, Qwen 판단 품질, 실제 JSM/MCP 업무와 Windows Chrome/Edge는 별도 확인 대상입니다. PC 실행기와 A2A는 포함하지 않습니다. 브라우저 강제 종료 후에는 체크포인트에서 재관찰하여 이어갑니다.
