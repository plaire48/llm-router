# 실행 단계의 브라우저 캡처

브라우저 캡처는 촬영한 실행 단계에서 펼친다. 단계 문장 오른쪽의 이미지와 펼치기 아이콘으로 내용을 예고하며, 평소에는 이미지를 접어 작업 흐름을 유지한다.

- 한 스크립트에서 여러 장을 촬영하면 같은 단계 아래에 촬영 순서대로 표시한다.
- 펼친 이미지에는 확대와 다운로드만 둔다. 호스트, 중복 제목과 안내 문장은 추가하지 않는다.
- 실제 캡처의 저장과 다운로드 경로, CX 확대 모달을 재사용한다. PNG 바이트는 IndexedDB에 남는다.
- 사용자가 펼친 단계는 최근 진행 목록이 바뀌거나 답변이 완료돼도 열려 있다. 새로고침하면 접힌 상태로 복원한다.
- 페이지에서 찾은 원본 이미지와 질문의 선택지는 기존 결과/질문 위치를 유지한다.

## 연결과 호환성

UI가 각 실행 단계의 UUID를 생성하고 상태 갱신 때 유지한다. `RUN_TOOL`의 표시용 메타데이터로만 전달하며, worker가 실제 촬영 콜백에서 캡처에 연결한다. 도구 인자, 모델 문맥이나 실행 권한으로 사용하지 않는다. 저장 시 UUID 형식만 허용한다.

도구명이 같아도 별도 실행의 캡처를 섞지 않는다. 저장된 단계가 없는 과거 캡처나 최근 32개 기록 밖의 캡처는 같은 실행 기록 안의 접힌 항목으로 보존한다. 시각이나 배열 순서로 관계를 추측하지 않는다.

## 기준과 선택

[HTML Standard의 details/summary](https://html.spec.whatwg.org/multipage/interactive-elements.html#the-details-element)를 사용한다. 키보드로 펼칠 수 있고 동시에 여러 캡처를 비교할 수 있도록 배타적인 아코디언 그룹을 만들지 않는다. 기존 CX에는 공개 아코디언 API가 없어 별도 라이브러리를 추가하지 않고 이미 사용 중인 disclosure와 CX 이미지 모달을 조합했다. `@e2e/cx-design-system@0.5.4`와 사용자 HTML의 색상/간격/모션 토큰을 유지한다. 실행 설명은 Noto Sans KR 14px/22px다.

## 검증

`captures-browser`는 실제 Chrome 탭과 네이티브 사이드 패널에서 촬영, 단계 연결, 기본 접힘, Enter/Space, 완료/새로고침/브라우저 재시작, 확대, 다운로드 바이트, 실패 복구와 과거 기록을 확인한다. 후보 검증에서는 새 프로필로 3회 반복한다. 이미지 선택 폼, 페이지 원본 이미지, 작업 계획과 공통 글꼴도 관련 회귀로 확인한다. 모델 응답과 사이트는 합성이며 실제 AI Pro 계정/모델 정확도를 검증한 것은 아니다.
