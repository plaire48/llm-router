# 실제 모델 평가

`npm run eval:agent`는 빌드된 확장을 별도 Chrome 프로필에서 실행하고 실제 AI Pro 모델을 호출한다. 개인 브라우저 프로필을 사용하지 않는다. 인증이 없으면 호출하지 않고 `not_configured`로 기록한다.

## 설정

Node 22.19 이상과 Playwright용 Chrome이 필요하다. 인증값은 로컬 환경변수 `NUBI_EVAL_TOKEN`으로 전달한다. 채팅이나 Git에 값을 넣지 않는다. `NUBI_EVAL_MODEL`은 실제 모델 이름이며 기본값은 `QWEN3.8-27B-FP8-256K`다. `CHROME_BINARY`는 테스트 브라우저 실행 파일 경로다. 환경변수를 설정한 터미널에서 `npm run eval:agent`를 실행한다. 회사 네트워크에서 AI Pro에 접근할 수 있어야 한다. `.env`를 자동으로 읽지는 않는다.

## 평가 항목

| 작업 | 실제 정답/상태 검사 |
| --- | --- |
| 페이지 읽기 | 마감일, 담당 팀, 장소를 모두 답하고 입력은 0회 |
| 긴 문단 | 문단 뒤쪽의 종료 시각을 정확히 답함 |
| 늦게 뜨는 결과 | 로딩 뒤 실제 표시되는 37건을 읽음 |
| 초안 입력 | 제목/본문 실제 값과 등록 0회, 제목 중복 입력 없음 |
| 필수 정보 누락 | 추측 입력 없이 사용자 질문 |
| 드래그 목적지 | 카드가 실제 보관함 안에 있음, 삭제 0회 |
| 호버 배치 이동 | 도움말이 닫힌 뒤 올바른 대상 1회 클릭, 아래 iframe 오작동 0회 |
| 이미 맞는 토글 | 켜진 상태 유지, 불필요한 토글 클릭 0회 |

모델은 합성 페이지를 실제로 읽고 도구를 고른다. 사용자/회사 페이지 내용은 사용하지 않는다. 테스트 프로필에만 사이트 권한을 부여하며 네트워크는 합성 페이지와 AI Pro로 제한한다. 각 사례의 180초/40요청 한도는 평가 자원 보호용이며 제품의 작업 횟수 제한이 아니다.

각 작업은 기본 3회 반복한다. `NUBI_EVAL_REPEATS`로 1~5회를 지정할 수 있다. 결과는 덮어쓰지 않는 `verification/agent-live-<실행시각>.json`에 남긴다. 누락되거나 중복된 trial이 있으면 종합 점수를 산출하지 않는다. 최종 답변, 실제 페이지 상태, 모델 요청 수와 소요 시간을 구분한다. 인증 헤더는 기록하지 않는다. 모든 사례 완료율, 잘못된 완료 선언, 중복 입력을 모델별로 비교한다. 제품 내부의 같은 모델 재검토와 독립적인 정답 검사는 별개다.

평가 탭은 현재 대화의 `browserContexts`/`browserWorkspaces`로 결정한다. 원본과 같은 URL인 과거 작업 탭으로 대체하지 않는다. 자식 창과 현재 탭 모드를 지원하고 별도 창 모드에서는 원본 페이지 값과 문서가 유지됐는지도 검사한다. 도구 관찰이 없으면 `target.observed=false`로 남기며 사용자 질문 이외의 브라우저 작업 성공으로 채점하지 않는다. [완료 판단 개선](COMPLETION-QUALITY.md)의 합성 Chrome 회귀와 실제 모델 평가를 구분한다.

## 이번 실행 범위

이번 개발 환경은 실제 평가용 인증이 없어 실모델 점수를 산출하지 않았다. 실제 Chrome + 합성 모델 응답으로 복구 흐름을 확인했으며, 실모델용 실행기의 실제 API 통신은 미검증이다. 평가에 통과해도 모든 사내 사이트나 모든 모델의 정확도를 보증하지 않는다.

반복 결과에는 pass@1(전체 시도 성공 비율), pass@k(한 번 이상 성공한 과제 비율), pass^k(k회 모두 성공한 과제 비율)를 따로 기록한다. 미완료/중복 회차가 있으면 모두 미산정이다. 이는 자체 합성 과제의 실모델 측정이며 WebArena 점수가 아니다. [공개 채점기 연결](PUBLIC-BENCHMARK-EVALUATION.md)은 별도로 관리한다.
