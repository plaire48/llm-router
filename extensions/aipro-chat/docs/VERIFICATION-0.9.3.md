# 0.9.3 검증 기록

첫 화면부터 입력창을 하단에 고정했습니다. 사용자 제공 agentfactorysdkdeck.html의 옅은 배경, 짧은 강조 제목과 부드러운 카드 구성을 CX 색상과 로컬 Noto Sans KR로 적용했습니다. 로그인, 첫 인사, 대화와 입력창을 함께 정리하고 공통 버튼 규격과 아이콘 조작을 유지했습니다.

첫 인사는 한글 글자 단위로 한 번 나타납니다. 문장 너비를 미리 확보해 타이핑 중 정렬이 바뀌지 않으며 스크린 리더에는 항상 전체 문장을 제공합니다. 입력창을 조작하면 즉시 완성하고 새 대화에서는 다시 타이핑하지 않습니다. 메인 로고의 부유와 빛 번짐은 4.8초 동안 한 번 재생하며 입력창 조작 중에는 멈춥니다. 모션 감소 설정은 정적 화면을 사용합니다.

2026-09-21 검증:

- 0.9.2의 360×800 빈 화면에서 입력창 하단이 502px인 기존 배치를 재현했습니다. 0.9.3은 788px로 하단 여백 12px를 유지합니다.
- Chrome 확장 화면의 360×800, 1100×850, 360×480에서 빈 대화, 여러 줄 입력, 첫 응답, 새 대화와 새로고침을 확인했습니다. 총 15개 배치 검사에서 하단 여백과 가로/문서 스크롤 넘침을 검사했습니다.
- 좁은 화면은 하단 여백 12px, 전체 화면은 16px를 유지합니다. 같은 크기의 로그인 화면도 확인했습니다.
- 실제 글자 증가, 타이핑 중 제목 너비 유지, 로고 transform 변화, 입력창 초점 시 정지, 인사 즉시 완성, 새 대화에서 인사 재생 방지와 모션 감소 설정을 확인했습니다. 브라우저 pageerror는 없었습니다.
- CX 디자인 검사와 빌드가 통과했습니다. 채팅/인증 로직은 변경하지 않았고 전체 단위 테스트는 다시 실행하지 않았습니다.

브라우저 검증은 격리된 Chrome for Testing과 합성 인증/모델 응답을 사용했습니다. 테스트 복사본에만 사이트 권한을 미리 부여했으며 배포 권한은 유지합니다. 실제 사내 SSO와 LLM 호출은 이번 검증 범위에 포함하지 않습니다.
