# 0.13.4 계정 버튼과 누비 표정

검증일: 2026-09-21

## 변경

- 상단 재생/정지 버튼과 예전 저장된 정지 설정을 제거했다. 운영체제 모션 감소 설정, 입력 중 정지, 모달과 숨겨진 탭의 정지는 유지한다.
- CX 로그인/로그아웃 아이콘을 상단 맨 오른쪽에 배치했다. 제공자 선택 초점, 툴팁과 접근 가능한 이름을 유지한다. 실행 중 로그아웃을 막고 로그아웃 전에 초안을 저장한다. 설정 안의 중복 계정 버튼은 제거했다.
- 대기 중 눈웃음, 20초 무활동 후 감은 눈과 호흡/Z, 완료 시 4.2초 눈웃음과 반짝임, 실패 시 눈물 맺힌 표정과 짧은 눈물 효과를 추가했다. 입력창 초점 때문에 완료 표정이 보이지 않던 문제를 정적 표정과 장식 움직임을 분리해 수정했다.
- 기존 청록색 부리 없는 캐릭터, 한글 로고, HTML의 옅은 색과 CX 버튼을 유지한다. 상단 캐릭터는 36px이며 320px 창에서도 조작이 한 줄에 들어간다. 새 슬픈 표정 원본과 생성 이력을 함께 보관한다.

## 확인

- `npm run design:check`, `npm run build` 통과.
- `tests/mascot-browser.mjs`: 격리한 Chrome 확장에서 실제 UI 상태 전환을 실행했다. 합성 인증과 모델 응답을 사용했다.
- 버튼 제거와 기존 정지 설정 해제, 로그인 시 제공자 선택 초점, 320/360/1100px에서 아이콘 위치와 가로 넘침 없음.
- 실제 20초 대기 후 수면 표정과 키보드 입력 후 복귀. 실행 중 로그아웃 비활성화, 완료 후 4.2초 표정 유지, 입력창 초점 상태에서 웃는 눈 표시, 새로고침 시 완료 효과 재생 없음.
- 합성 HTTP 502에서 슬픈 표정과 기존 오류 안내를 함께 표시. 모션 감소 설정에서는 표정을 유지하고 모든 장식 애니메이션을 정지.
- 초안 저장 대기 전에 로그아웃해도 초안 저장, 인증값 삭제, 새로고침 후 대화 유지, 재연결 후 초안 복원.
- `tests/welcome-browser.mjs`: 320~1100px 제공자 정렬, 낮은 창, 하단 입력창, 새 대화/새로고침, 타이핑과 모션 감소 확인.
- `tests/accessibility-browser.mjs`: 360/1100px 설정, 진단 복사, 모달 키보드/초점 복귀와 오른쪽 로그아웃 확인. 접근성 경고와 페이지 JavaScript 오류 없음.

로컬 결과는 `verification/mascot-browser.json`, `verification/composer-0.13.4.json`, `verification/accessibility-browser-results.json`에 있다. 로그인/수면/완료/실패와 좁은 창 화면도 같은 폴더에 저장했다.

실제 회사 SSO와 제공자 API는 이번 UI 검증에 사용하지 않았다. 인증 프로토콜과 모델 변환 계층은 변경하지 않았다. 웹 스토어 배포가 아닌 압축 해제 후 로드하는 개발자 모드 설치 ZIP이다.
