# 0.16.0 이미지 설명과 선택 질문

검증일: 2026-09-21

“가방 모양 아이콘”처럼 설명하면 현재 페이지의 실제 이미지/SVG 후보를 찾는다. 이미지 지원 모델에는 후보별 번호가 붙은 비교 PNG를 전달한다. 명확한 후보는 바로 첨부하고, 애매한 경우에만 실제 후보 2~4개를 선택지로 보여준다. 근거가 없으면 선택지를 만들지 않고 짧은 자유 입력 질문을 한다.

질문에는 이미지, 짧은 이름과 다운로드 아이콘을 사용한다. 직접 답변 아이콘은 기존 입력창에 초점을 옮긴다. 질문을 보관한 뒤 모델/도구 실행을 멈추고 다음 사용자 답변에서 재개한다. 이미지 선택으로 기존 초안을 지우지 않는다. 질문/파일은 새로고침과 대화 이력에 남으며, 오래되거나 다른 질문의 선택은 거부한다.

## 확인 결과

- 단위 테스트 195개 통과. 질문 저장 이후 추가 모델 호출/동작 차단, 실패 복구, 관찰된 파일만 선택지로 사용, 오래된 답변 거부, 질문 저장 직후 창 중단/재진입을 포함한다.
- `tests/image-choice-browser.mjs`의 5개 흐름 통과. 실제 Chrome DOM의 aria-hidden SVG 발견, 문자 일치 없는 후보 유지, 이미지 비교 전달, 질문 대기, 키보드 선택, 직접 입력, 초안 보존과 복원을 확인했다.
- 사이트의 `img-src 'self'` 정책 아래에서도 비교 이미지를 생성했다. 원본 바이트는 확장 내부에서만 처리하고 하나의 비교 PNG만 모델 문맥에 전달한다. 비교 이미지는 채팅 첨부나 클릭 좌표로 사용하지 않는다.
- SVG의 도형/색상과 다운로드를 확인했다. 로컬 sprite 참조를 해소하고 script/이벤트/foreignObject를 내보내지 않는다. 관찰 후 도형이 바뀌면 기존 참조를 거부한다.
- 기존 `tests/page-images-browser.mjs` 7개 흐름 통과. picture/currentSrc, CSS 배경, 교차 출처 캐시, frame/shadow root, PNG/WebP/JPEG/GIF/SVG, 다운로드 바이트와 재진입을 확인했다.
- 기존 `tests/browser.mjs`의 31개 흐름도 통과했다. 모델 목록, 초안, 대화 이력과 브라우저 재시작을 포함한다.
- 360×800, 1100×850 화면에서 선택 카드, 다운로드 버튼, 가로 넘침을 확인했다. CX 디자인 검사와 빌드 통과.

## 범위

실제 브라우저와 실제 이미지 파일을 사용했고, 모델 응답과 인증은 합성했다. 실제 회사망 AI Pro/Qwen의 의미 이해나 시각 인식 정확도는 검증하지 않았다. 선택지의 존재와 다운로드 가능 여부는 코드로 검증하며, 요청과 후보의 의미상 관련성은 모델 판단이므로 확률 수치를 만들지 않는다.

Qwen3.8 이미지 지원 연결에서 모양 비교를 제공한다. 텍스트 모델/FabriX는 이름과 문맥을 사용하고 이미지를 보았다고 주장하지 않는다. 지원하는 SVG 내보내기는 정적 도형과 로컬 참조 중심이며, canvas/아이콘 폰트/외부 SVG sprite를 원본 파일로 복원하는 기능은 포함하지 않는다. 내보낸 SVG는 페이지 DOM의 정적 파일이며 저장소의 원본 소스 파일이라고 표현하지 않는다.
