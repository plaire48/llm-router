## 변경과 검증 항목

1. 필요한 정보의 값/제목/단위/날짜/출처를 함께 보존하고 부족한 사실만 추가 조회한다. 사용자 필수 결과와 에이전트가 선택한 조사 방법을 구분한다.
2. 검증된 범위 교정을 실행 상태에 보존하고 계획 재작성으로 완료한 단계를 지우지 않도록 한다. 새 사용자 요구와 실제 관찰 변화는 별도 재검토한다. 자동으로 완료 처리하거나 원래 요구를 완화하지 않는다.
3. 현재 소유 탭의 PDF만 문서 동일성과 권한을 확인해 읽는다. 페이지별 원문 범위와 미열람/빈 페이지를 구분하고 이미지/도표 해석이나 양식 편집을 지원했다고 표시하지 않는다.
4. 계획 목록은 현재 내용으로 갱신하고 변경은 짧은 추가/제외/수정 아이콘으로 알린다. 접근성 이름과 설명을 유지한다. 전체 이력과 실행 진단은 저장되는 디버그 설정을 켰을 때만 표시하고 정상 진행/오류/승인은 기본 화면에 남긴다.

단위 검사, 실제 Chrome 합성 회귀, 화면 검토, 고정 후보의 실제 모델 결과를 각각 기록한다. 실행 중 후보는 변경하지 않는다. 배포는 이번 범위에 포함하지 않는다.

## 통합 전 확인

- UI는 계획 변경을 추가/제외/수정 아이콘으로 요약한다. 기본 화면은 현재 진행과 오류/질문/승인만 남기고 완료 도구 전체, 진단과 전체 계획 이력은 저장되는 디버그 모드에서만 표시한다. 360px와 1100px 화면 및 Chrome 재시작 후 설정 유지 검사 통과. [UI 검증](DEBUG-PROGRESS-UI-2026-09-28.md).
- 실제 API 경로를 포함한 계획/범위 관련 합성 회귀 129개 통과. 검증된 교정은 실행 상태로 보존하고 새 사용자 요구 때 초기화한다. 완료한 상태를 보존하는 것은 사실 검증이 아니며 독립 최종 검토와 사용자에게 전달된 답변을 계속 요구한다.
- 작은 모델 문맥 검사에서 중복 안내문 때문에 발생한 예산 초과를 안내 압축으로 수정했다. 기존 입력 한도와 원래 사용자 문장은 유지하고 관련 27개 검사를 통과했다.

- 평가 기록에는 입력 원문 대신 검증된 입력 영수증, PDF 원본 해시와 열람한 페이지 범위만 추가했다. 모델 판정과 독립 채점은 분리한다.
