# 워커 작업 조건과 진행 상태 인계

후속 구현과 현재 상태는 [출처 재연결과 긴 문서 작업 복원](RESEARCH-RESUME-2026-09-26.md)을 따른다. 아래 수치와 남은 범위는 첫 단계 당시 기록이다.

NQ-49의 첫 구현 단계다. **구현율은 45/51 = 88.2%로 유지**한다. 일반 역할 워커의 인계를 개선했지만 브라우저/프로젝트 출처 재연결과 DeepAgents 계층 워커까지 연결하지 않았으므로 전체 복원 항목을 완료로 올리지 않는다. 기존 비채택 5개는 분모에서 제외한다.

## 문제와 변경

표시용 trace는 작업 목적을 짧게 자르고 원래 제약과 문서 범위 전체를 저장하지 않는다. 그 표시 문구만으로 종료된 워커의 원래 작업을 복원하면 조건을 빠뜨릴 수 있다.

일반 `delegate_analysis` 워커는 시작 전에 원래 task/constraints/done_when/effort, 문서 ID와 해시, 담당 범위를 별도 인계 기록으로 저장한다. 저장 확인 전에는 하위 모델과 문서 조회를 시작하지 않는다. 저장 실패/취소는 워커 시작과 분리해 처리한다. 진행 중 읽은 구간, 미열람 구간과 부분 보고도 같은 기록에 갱신한다.

기록은 해당 제공자/대화/요청의 기존 Chrome 저장 경로를 사용한다. background worker capability만 새 기록을 제출할 수 있으며 일반 UI의 SAVE_CONTEXT 요청은 거부한다. 대화 저장/삭제/보존 정책을 그대로 따른다. 최대 12개, 전체 96,000자 이하로 제한하고 생략 수를 표시한다. 초기 저장 후 후속 저장 실패가 발생하면 하위 결과에 handoff_error를 남긴다. 실패한 저장이 실제 실행 결과나 완주를 무효화한 것으로 표시하지는 않는다.

재개 모델에는 짧은 인계 색인을 주고 `read_analysis_handoff`로 원래 조건과 부분 보고를 조회하게 한다. 색인은 매 모델 요청의 문맥 예산 검사 전에 다시 넣어 요약만으로 기록의 존재가 사라지지 않게 한다. 조회는 현재 첨부 문서 카탈로그와 ID/해시를 대조해 일치/변경/누락을 구분한다. 카탈로그 일치는 실제 원문 열람이나 내용 검증이 아니다. 실제 파일 권한/해시 확인은 기존 read_document 경로를 계속 거친다.

인계 데이터에는 원문 본문, 이미지, 실행 핸들, 승인이나 인증값을 넣지 않는다. 인용은 과거 source_key와 문서 위치로 보존하며 이전 ev_ID를 실행 근거로 재사용하지 않는다. 관찰 기록은 신뢰할 수 없는 과거 조언이다. 원래 조건과 현재 출처를 확인한 뒤 주 실행기가 다음 작업을 정한다. 취소 기록을 자동 시작하지 않고 미확정 쓰기를 재전송하지 않는다.

## 검사 범위

신규 단위 검사는 원래 제약/범위 보존, 현재 문서의 변경/누락, 결과 사본 격리, 크기 제한/생략, 인증 형태 마스킹, 시작 전 저장 확인, 실제 부분 읽기 범위, 저장 실패 시 모델 호출 0회, 저장 대기 취소를 다룬다. 기존 analysis-handoff 회귀 4개는 유지하고 새 검사는 analysis-durable-handoff 파일로 분리했다.

Chrome 검사에서는 격리된 후보 확장에 합성 worker capability를 연결해 실제 SAVE_CONTEXT 저장 권한 검사를 거친다. UI 위조 요청을 거부하고 Chrome 프로세스를 종료/재실행한 뒤 원래 조건/범위가 다음 START_CHAT에 전달되는지 확인한다. 새 카탈로그에서 없는 문서를 누락으로 표시하며 입력은 재전송하지 않는다. 실제 Chrome 저장/재시작 검사이며 실제 계정이나 모델의 판단을 검증한 것은 아니다.

검사 중 MV3 service worker에서 동적 import를 사용할 수 없다는 제약을 확인해 테스트 전용 조회 함수를 정적 import로 연결했다. 제품에는 동적 import 경로를 추가하지 않았다.

## 남은 범위

1. 브라우저/프로젝트 출처의 현재 관찰과 과거 locator를 안전하게 재연결한다. 현재 인계 조회는 해당 출처를 새로 확인해야 한다고 명시한다.
2. ask_documents/ask_openwiki의 DeepAgents 계획/하위 읽기/계층 합성 워커도 동일한 인계 계약에 연결한다. 이번 일반 역할 워커 저장을 그 기능의 전체 복원으로 표시하지 않는다.
3. 취소/부분 실패/출처 변경을 포함한 실제 모델 재개와 네이버 완주를 평가한다. 실제 모델 성능은 미측정이다.
