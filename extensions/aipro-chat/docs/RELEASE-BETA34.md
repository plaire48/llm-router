# nubi Beta 1.0.0 — beta34

표시 버전 **Beta 1.0.0**, Chrome 업데이트 번호 **1.4.37**.

## 개선

- 큰 첨부 문서를 같은 모델의 조사 워커 2개로 나누어 읽고, 미열람 구간 보완과 계층별 결과 통합을 수행합니다. 원문 해시와 출처를 압축 후에도 유지하고 최종 검토에서 실제 인용을 확인합니다.
- 분할, 담당 문서/구간, 조사, 누락 보완, 통합, 주 실행기 전달을 작업 진행에 표시합니다. 별도 전체 기록은 페이지별로 조회하며 취소나 보관 한도로 빠진 기록을 알립니다.
- 내장 위키와 선택한 OpenWiki 문서의 질문 위임, 긴 문서 분할 조회와 출처 검증을 보강했습니다. 같은 연결 모델을 사용하고 위키별 문맥을 구분합니다.
- Pi 실행기를 0.87.1로 갱신하고 질문/승인 대기, 하위 분석 결과 보존, 원래 요구사항과 단계별 결과 검증을 보강했습니다.
- 정책 조회가 지연돼도 화면은 응답하며 정책 확인 전 자동화를 차단합니다. 기본 확인창을 기다리는 동안 화면 조회가 막히던 대기열 경합도 수정했습니다.
- 응답을 잃은 입력은 실제 대상과 값을 다시 확인합니다. worker 재시작과 반복 실패에서 미확정 변경을 자동 재전송하지 않습니다.
- 업로드 승인, 다운로드 상태 추적, 작업 알림, 검토 후 절차 재사용, Chrome 실행 중 예약과 조직 정책을 추가했습니다. 파일 선택은 서버 업로드 완료와 구분합니다.
- 모든 모달의 HTML 아이덴티티를 유지하고 핵심 구절만 색상과 볼드로 강조했습니다. 반복 설명을 줄이고 명확한 조작은 이름/툴팁이 있는 아이콘으로 표시합니다.

## 설치와 업데이트

설치 ZIP을 풀고 `chrome://extensions`에서 개발자 모드를 켠 뒤 **압축해제된 확장 프로그램 로드**로 선택합니다. 기존 사용자는 같은 설치 폴더의 파일을 갱신하고 확장을 새로고침하세요. Chrome Web Store 배포본은 아닙니다.

추가 필수 권한은 없습니다. 다운로드 상태와 OS 알림은 설정에서 선택 권한을 허용할 때 사용합니다. 예약은 Chrome이 열려 있어야 하며 제출/업로드의 기존 승인을 유지합니다.

## 확인 범위

같은 후보에서 단위 **836/836**, Chrome **228/228**가 통과했습니다. 핵심 63종은 새 프로필로 3회, 별도 39종은 1회 실행했습니다. 디자인 검사, 화면 26종, 이전 beta29 업데이트, 독립 빌드 700개 파일 비교와 ZIP 무결성도 확인했습니다. 알려진 의존성 취약점은 0건입니다.

[전체 회귀](verification/beta34-browser.json), [화면 검사](verification/beta34-identity.json), [업데이트](verification/beta34-upgrade.json), [빌드 비교](verification/beta34-build-comparison.json), [패키지 검사](verification/beta34-package.json).

실제 Chrome과 합성 사이트/모델 응답의 회귀, 기존 설치본 업데이트, 독립 빌드와 ZIP 무결성을 확인합니다. 실제 회사망 SSO/API, Qwen 업무 정확도, Windows Chrome/Edge, OS 알림 표시와 조직 배포는 별도 확인 대상입니다. PC 실행기와 A2A는 포함하지 않습니다.

첨부 한도는 메시지당 4개/8 MiB, 문서당 400만 자, 조사당 총 800만 자, PDF 2,000쪽입니다. PDF/Word는 텍스트 조사이며 이미지·레이아웃·OCR은 포함하지 않습니다. 전체 기록은 실행당 10,000개, 총 50,000개, 512개 실행까지 보관합니다.
