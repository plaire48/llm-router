## 다음 후보의 변경

1. 검토 범위 감사: 비완료 검토의 조건이 실제 사용자 요청, 현재 단계, 후보 답변의 주장 중 어디서 왔는지 별도로 확인한다. 실제 사이트의 필수 입력, 승인, 미확정 쓰기 보호는 제거 대상이 아니다. 모호하거나 감사 형식이 잘못되면 기존 비완료 결과를 보존한다. 범위 오류는 같은 원문 근거로 검토기만 한 번 교정하며 자동 완료로 바꾸지 않는다. 기존 Pi 제공자 호출에 구현했다. 감사가 불명확하거나 실패하면 기존 비완료 검토를 유지하고 취소/인증 오류는 즉시 전달한다.
