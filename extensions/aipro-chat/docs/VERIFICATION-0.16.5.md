# 0.16.5 긴 본문 작성과 출력 중단 복구

검증일: 2026-09-21

## 변경

- 긴 페이지 작성은 계획, 짧은 본문 입력, 이어쓰기, 전체 검증으로 나눠 진행하도록 실행 지침을 보강했다. 사용자에게 질문을 나누라고 넘기던 오류 안내도 정리했다.
- 한 번의 모델 응답이 출력 한도에 닿으면 완료된 도구 결과를 유지한 채 더 작은 다음 단계를 요청한다. 사용자에게 보이는 답변은 끝부분을 전달해 이어 쓰고 겹치는 문장은 제거한다. 잘린 도구 호출은 JSON이 완전해 보여도 폐기하며, 부분 코드를 연결하거나 실행하지 않는다.
- `appendText`는 실제 브라우저 입력 이벤트로 한 절을 추가한다. 앞선 입력 길이와 선택적 SHA-256이 다르면 실행하지 않으며 기존 본문과 서식을 다시 쓰지 않는다. 입력 후 유지 여부를 확인하고 다음 단계에 사용할 길이와 digest를 반환한다.
- `field_digest`로 16,000자를 넘는 전체 입력을 검증하고 `field_contains`로 요청한 내용을 확인한다. digest는 입력 유지의 증거이며, 내용의 적합성이나 서버 저장의 증거로 취급하지 않는다. 페이지의 저장 표시와 전체 요구사항 검증은 별도로 진행한다.
- 최종 요구사항 검토 자체가 출력 한도로 잘리면 같은 증거로 간결한 JSON 검토를 다시 요청한다. 이 과정에서 페이지 작업을 재실행하지 않는다. 검토를 완료하지 못하면 성공으로 처리하지 않는다.

## 검증

- `npm test`: 226개 통과. AI Pro JSON/SSE, ChatGPT SDK 응답과 FabriX 도구 envelope의 출력 중단을 합성 응답으로 확인했다. 완성된 것처럼 보이는 잘린 호출 폐기, 이어쓰기, 사용량 중복 방지, 취소/통신 실패의 비재시도와 검토 재시도를 포함한다.
- `output-recovery-browser`: 실제 Chromium 확장에서 8개 통과. 한 사용자 요청으로 빈 출력과 잘린 스크립트를 복구하고 21,796자 본문을 여섯 절로 입력했다. 14회 모델 요청의 사용량을 각각 한 번 기록하고 원문 전체, 요청한 마지막 절, 화면의 저장 상태와 최종 요구사항 검토를 확인했다.
- 위 브라우저 검사에서 중복 삽입 없음, 신뢰된 입력 이벤트, 새로고침 후 대화 유지, 이전 길이로 재실행 차단, 같은 길이의 변경도 digest로 차단, 비밀 입력란 차단과 기존 서식/줄바꿈 보존을 확인했다. 본문 대조는 브라우저의 실제 선택 텍스트를 사용했다.
- `browser-agent-browser`: 기존 16개 통과. 자연어 페이지 분석, 새 탭/iframe/Shadow DOM 입력, 생성 코드 수정, 캡처/좌표 조작, 취소와 연결 정리를 확인했다.
- `context-browser`: 기존 5개 통과. 대화 압축, 사용량, 복원과 체크포인트, 명시적 이어가기를 확인했다.
- `npm run design:check`: 문제 없음. 기존 CX 레이아웃과 컴포넌트를 유지했다.
- `npm run build`: 0.16.5 설치 폴더와 ZIP 생성. 기존 Vite 청크 크기 안내는 남아 있다.

## 범위

모델 응답과 업무 페이지는 합성 fixture이며 브라우저 입력은 실제 Chromium/Playwright 실행이다. 회사망의 실제 모델이 스스로 나누어 작성하는 품질과 사용자 업무 사이트의 실제 저장은 이번 검사에 포함하지 않았다.

진행하는 작업에 총 단계 수 제한을 추가하지 않았다. 진행 없는 출력 실패가 세 번 연속 발생하면 기존 작업을 보존하고 중단한다. 요청 10분, 스크립트 60초와 메모리/권한/취소 경계는 유지한다. 일반 통신 오류를 출력 중단으로 취급해 자동 재실행하지 않는다. `contenteditable`의 불필요한 `innerText` 줄바꿈을 피하기 위해 선택 텍스트를 잠깐 읽고 선택/포커스를 복원하며 클립보드는 사용하지 않는다. 해당 텍스트의 non-breaking space는 일반 공백으로 정규화한다.
