# 0.9.1 검증 기록

로그인 버튼은 AI Pro와 ChatGPT 이름만 표시합니다. 제공자 로고와 이름을 함께 중앙 정렬하고, 기존 CX 버튼색을 유지하며 로고 배경은 투명하게 처리했습니다. 설정에서 AI Pro 연결 설정, 인증 방식 선택과 인증값 직접 입력을 제거했습니다. 연결 진단과 데이터 보관만 남기고, 연결 해제는 진단 안의 아이콘으로 이동했습니다. CX의 기존 모달, 버튼, 서체와 토큰을 사용합니다.

2026-09-21, Chrome for Testing 149.0.7827.55의 격리된 프로필에서 설치한 확장으로 확인했습니다.

- 단위 테스트 125개 통과
- CX 디자인 검사와 설치 ZIP 빌드 통과
- 360px/1100px에서 두 제공자 로고 로딩과 중앙 정렬, 두 설정 항목, 키보드 조작, 초점 복귀, 새로고침 후 유지 확인
- 진단 안의 연결 해제로 SSO 화면 복귀 확인
- 진단 복사 호출의 payload에서 인증값 제외 확인
- 접근성 경고와 페이지 JavaScript 오류 없음

브라우저 검증은 합성 인증/모델 응답을 사용했습니다. OS 클립보드를 바꾸지 않도록 복사 함수는 테스트 대역을 사용했습니다. 실제 사내 SSO/API나 실제 계정 로그인은 이번 UI 변경에서 검증하지 않았습니다.
