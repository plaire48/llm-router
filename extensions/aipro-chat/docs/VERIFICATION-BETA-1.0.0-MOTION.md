# Beta 1.0.0 캐릭터 움직임 복구

표시 버전은 **Beta 1.0.0**, Chrome 업데이트 번호는 **1.4.5**다.

## 원인과 수정

기존 캐릭터와 날갯짓 프레임은 삭제되지 않았다. 입력창에 초점이 있으면 배경과 캐릭터를 함께 정지시키는 CSS가 원인이었다. 1.4.4 설치본에서 입력 전에는 애니메이션 시간이 흐르고, 입력창을 누른 뒤에는 같은 시간에 멈추는 것을 재현했다.

입력 중에는 배경 장식만 잠시 멈춘다. 로고와 메인 캐릭터의 날갯짓, 떠오름, 표정은 이어진다. 호버 인사는 1.8초 후 기본 움직임으로 돌아오므로 마우스를 올려둔 채로도 멈추지 않는다. 재생/정지 버튼은 추가하지 않았다. 모달, 숨겨진 탭과 운영체제 모션 감소 처리는 유지한다.

## 확인 결과

단위 검사 **285개**, 디자인 검사, 빌드와 관련 브라우저 **8개 스위트**가 통과했다. 전체 기능 검사를 다시 수행한 결과는 아니다. Chrome에 확장을 설치한 검증이며 계정과 모델 응답은 합성 데이터를 사용했다.

- 큰 화면(1100px)과 좁은 화면(360px)에서 입력창 초점을 유지한 채 8.2초 동안 실제 프레임을 수집했다. 날개 표시가 0부터 0.99 이상까지 변하고 몸이 약 9px 떠올랐다.
- 응답 대기 중에도 3초 동안 날갯짓과 약 6px 떠오름을 확인했다. 완료 표정과 오류 표정도 유지된다.
- 호버 후 자동 복귀, 잠듦과 키보드로 깨우기, 이전 정지 설정 제거, 모션 감소, 새로고침 후 상태와 초안 보존을 검사했다.
- 실제 사이드 패널, 환영 화면, UI, 피드백, 접근성, 채팅과 이전 CSP 수정도 통과했다.
