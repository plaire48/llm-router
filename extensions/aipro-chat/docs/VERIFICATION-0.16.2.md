# 0.16.2 로고와 공통 화면

검증일: 2026-09-21

한글 누비를 좌우 폭과 자간이 좁은 이미지 워드마크로 교체했다. 캐릭터 32px, 글자 42×24px, 간격 4px다. 로고 묶음은 마우스를 올려도 투명하며 배경 박스나 그림자가 없다. 키보드 초점 표시는 유지한다. 클릭하면 기존 NEW_CHAT 경로로 대화와 초안을 보관하고 새 채팅 입력창을 연다. 실행 중이나 인증 중에는 전환을 막는다.

모달 제목은 16px/24px, 본문과 데스크톱 입력은 14px/22px, 입력 이름은 13px로 맞췄다. 좁은 데스크톱 사이드 패널을 휴대폰 글자 크기로 확대하지 않는다. coarse 포인터용 입력 16px/44px 토큰은 유지한다. 제공자와 사용량 탭은 같은 CX 탭 기반의 옅은 색면과 움직이는 선택 배경을 공유한다.

설정 모달 하단에 실제 manifest.version을 12px로 표시한다. 애니메이션의 상시 재생/멈춤 버튼은 없으며 운영체제 모션 감소 설정과 입력/화면 숨김 상태를 따른다. 예전 localStorage 정지 설정도 초기화된다.

## 검증

- CX 디자인 검사와 0.16.2 설치 ZIP 빌드 통과.
- `ui-simplicity-browser`: 320/360/1100px에서 FabriX, 설정, 도움말, 모델, 스킬/편집, 컨텍스트, 사용량, 이력의 제목 16px/24px와 표시되는 입력 14px를 확인했다. 화면 넘침, 모달 불투명도, 아이콘 이름, 키보드 닫기/복귀 검사 통과.
- `provider-switch-browser`: 세 제공자 전환, 로그인 취소/복구, 색면 탭 이동, 방향키와 모션 감소, 재시작 검증 7개 항목 통과. 합성 인증 서버를 사용했다.
- `conversations-browser`: 로고 클릭으로 즉시 초안을 보관하고 새 대화를 열었다. 이력 재선택/새로고침 후 메시지와 초안을 복원하고, 검색/삭제/다른 제공자 이력까지 7개 항목 통과.
- `usage-browser`: 오늘/전체 탭, 사용량과 잔여 한도, 새로고침/실패 복구 5개 항목 통과.
- `captures-browser`: 사이드 패널과 전체 화면의 이미지 확대, 다운로드, 키보드/초점 복귀와 보관 11개 항목 통과.
- `accessibility-browser`: 3개 항목 통과. aria-hidden 경고와 페이지 오류 없음.
- 설치한 확장에서 한글 이미지 로드, 42×24px 크기, hover 포함 투명 배경, 320/360/1100px 화면 넘침 없음, 설정 버전과 OS 모션 감소 반영을 추가 확인했다.

이번 검증의 인증/모델/계정 응답은 합성 데이터다. 실제 회사망 인증이나 모델 서비스 응답을 다시 검증한 결과는 아니다.
