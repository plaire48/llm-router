# 0.14.0 제공자와 모델 전환

검증일: 2026-09-21

## 변경

- 입력창의 모델 이름을 누르면 AI Pro, ChatGPT, FabriX 로고 탭과 모델 목록이 한 창에 열린다. 연결하지 않은 제공자는 같은 자리에서 로그인하며 FabriX는 기존 연결 테스트 모달로 이어진다.
- 연결된 탭은 재로그인 없이 해당 제공자의 모델, 대화와 초안을 복원한다. 다른 제공자의 대화 내용과 페이지 연결을 다음 요청에 섞지 않는다.
- 오른쪽 끝 로그아웃은 현재 제공자만 해제하고 모델 창을 연다. 모델 창에서도 만료되거나 거부된 연결을 포함해 해당 제공자만 해제할 수 있다.
- 새 로그인 취소, 실패, 취소 이후 늦게 도착한 응답은 기존 연결을 덮어쓰지 않는다. 응답 생성 중에는 UI와 백그라운드 모두 전환과 로그아웃을 막는다.
- 인증값은 신뢰된 확장 컨텍스트만 읽는 `chrome.storage.session`에 보관한다. 비활성 제공자만 따로 저장하며 현재 인증값을 중복 보관하지 않는다. 화면 상태 응답에는 제공자별 연결 여부만 포함하고, 브라우저를 종료하면 모든 인증값이 사라진다. 대화 이력은 남는다.
- CX 아이콘 탭에 기존 HTML의 옅은 색면과 그림자를 적용한다. 선택 배경의 400ms 이동/색상 전환, 로고의 짧은 떠오름과 목록 등장을 사용하며 모션 감소에서는 즉시 표시한다. 키보드 전환 후 탭이 다시 활성화된 시점에 초점을 복원한다.

## 확인

- `npm test`: 190개 통과. 인증 수명 주기, 제공자별 세션 복원, 만료와 거부 상태, 로그아웃 격리, 저장 실패 시 기존 대화와 초안 복구를 포함한다.
- `npm run design:check`, `npm run build` 통과.
- `tests/provider-switch-browser.mjs`: 실제 격리 Chrome 확장에서 세 제공자의 로그인과 채팅, 재로그인 없는 전환, 초안과 모델 복원, 로그인 취소/실패와 늦은 응답, FabriX 취소/테스트/연결, 개별 로그아웃, 만료 연결 해제, 실행 중 전환 차단을 확인했다.
- 같은 브라우저 검증에서 320/360/1100px의 아이콘 탭 정렬과 가로 넘침, 키보드 방향키/Home/End와 초점 복귀, 새로고침 후 연결 유지, 브라우저 재시작 후 인증 삭제와 대화 보존을 확인했다. 화면 상태와 로컬 저장소에 인증값이 없는지도 확인했다.
- 선택 배경의 이동 중간 프레임과 제공자 변경 전후 창 위치/높이를 검사했다. 모션 감소에서는 체감 가능한 전환과 목록 애니메이션이 없고 선택 상태는 유지된다.
- `tests/chatgpt-browser.mjs`: PKCE 교환, 스트리밍, 사용량, 모델 변경, 새로고침, 토큰 갱신, 페이지 도구, 계정 모델 제한과 잘못된 OAuth state 거부의 7개 검증을 통과했다.
- `tests/conversations-browser.mjs`: 이력 검색/이름 변경/삭제, 대화와 초안 복원, 제공자별 분리, 재시작, 긴 목록의 좁은 창 배치를 통과했다.
- `tests/browser.mjs`: AI Pro 콜백의 기존 헤더/JSON/form/원문 계약, 취소, 권한 오류 후 재연결, 스트리밍 사용량, 컨텍스트, 모델 오류 복구, 새로고침과 재시작을 통과했다.
- `tests/accessibility-browser.mjs`: 좁은/넓은 창의 설정, 진단 복사, 키보드/초점 복귀와 로그아웃을 확인했다. 접근성 경고와 페이지 오류는 없었다.

결과와 화면은 로컬 `verification/provider-switch-browser.json`, `verification/provider-models-*.png` 및 각 브라우저 검증 결과에 저장했다.

네트워크 인증과 모델 응답은 합성 데이터다. 실제 회사 SSO, ChatGPT 계정과 FabriX 회사망 연결 성공을 의미하지 않는다. 기존 인증 프로토콜과 제공자 API 변환 방식은 변경하지 않았다. 설치 파일은 웹 스토어 배포본이 아닌 개발자 모드 설치 ZIP이다.
