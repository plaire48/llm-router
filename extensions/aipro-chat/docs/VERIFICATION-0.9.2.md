# 0.9.2 검증 기록

일반 채팅에서도 모델이 브라우저 도구를 선택할 수 있도록 변경했습니다. 링크나 스킬을 선택할 필요 없이 첫 페이지 도구에서 전송 당시의 대상 탭을 연결합니다. 일반 텍스트 대화는 페이지를 조회하거나 제목/주소를 모델에 보내지 않습니다. 기존 링크 아이콘과 명시적으로 선택한 스킬의 권한은 유지합니다.

전체 화면 채팅 탭의 URL이 Chrome 탭 조회에서 생략될 때, 확장 탭 자체를 대상으로 잡던 오류도 수정했습니다. 원래 웹 탭 연결을 유지합니다. 소개 문구는 브라우저 업무와 AI Pro/ChatGPT 지원 중심으로 정리했습니다.

2026-09-21 검증:

- 단위 테스트 130개 통과: 메시지 소유자/도구 권한, 전송 당시 탭 고정, 대상 없음/로그인 페이지 제한, 취소 중 연결, 일반 대화 재시도 포함
- 실제 Chrome에서 브라우저 통합 검사 14개 통과
- 일반 대화의 페이지 미조회, 자연어 페이지 분석, 연결 해제 후 재요청, 페이지 이동과 채팅 새로고침, 기존 링크 버튼 확인
- 메일 초안 입력, 클릭, iframe/shadow DOM, 탭 이동, Playwright 코드 오류 수정, PNG 전달/좌표 클릭과 중지 회귀 확인
- 실제 응답 usage의 요청별 누적과 마지막 요청 기준 컨텍스트 확인
- 360px/1100px CX 화면 확인, 디자인 검사와 빌드 통과

브라우저 검증은 격리된 Chrome for Testing 149.0.7827.55, 합성 인증/모델 응답과 테스트 페이지를 사용했습니다. 테스트용 manifest에 사이트 권한을 미리 부여했으며 배포 manifest의 optional_host_permissions는 유지합니다. 실제 사내 SSO/LLM/메일이나 실제 모델의 자연어 판단 품질, 사이트 권한 팝업 클릭은 이번 검증에 포함하지 않습니다.

사용자가 보고한 `sinternet is not defined`는 기존 소스/배포본에 해당 호출이 없고 새 Chrome 환경에서 재현되지 않아 원인 미확인 상태입니다. 이 릴리스가 해당 오류를 해결했다고 주장하지 않습니다.
