# 0.10.1 검증 기록

## 변경

- 사용자 HTML을 [지속적인 시각 기준](VISUAL-STANDARD.md)으로 기록하고 옅은 블루/보라/민트 배경, 부유 아이콘, 시간차 등장, 부드러운 카드/모달/버튼 반응을 적용했습니다. 장식 일시정지, 선호 저장, 입력 시 정지, 모션 감소를 지원합니다.
- 로그인 버튼은 48px로 늘리고 로고/글자를 세로 중앙에 정렬했습니다. AI Pro는 옅은 블루/보라, ChatGPT는 밝은 회색, FabriX는 옅은 청록으로 구분하며 원색으로 채우지 않습니다.
- 답변/코드/진단 복사에 체크 표시와 CX 토스트를 연결했습니다. 비동기 완료 전 성공을 표시하지 않으며 실패 후 재시도 안내를 유지합니다. 응답 완료가 다른 조작의 초점을 빼앗지 않도록 조정했습니다.
- 모델 변경, 스킬 저장/삭제, 페이지 연결/해제와 목록 새로고침에 결과 알림을 추가했습니다. 선택/진행 상태는 옅은 배경, 아이콘과 텍스트로 구분합니다.

## 수행 결과

`npm test`: 145개 통과. `npm run design:check`: 소비 화면의 색상/서체/공통 컴포넌트 검사 통과. 공유 서비스 토큰은 HTML 대조와 실제 계산 스타일로 검증했습니다. `npm run build`: 성공, 기존 Vite 번들 크기 경고는 남아 있습니다.

실제 Chrome for Testing에 빌드한 확장을 설치했습니다. 인증/모델 서버는 합성 응답이며 테스트용 사이트 접근은 임시 manifest에 미리 허용했습니다.

| --- | --- |

FabriX 회귀 검증은 합성 모델 응답으로 실제 Pi/Playwright를 실행해 팝업 이동, 교차 출처 iframe 입력과 테스트 페이지의 초안 저장 결과를 확인했습니다. 메일 발송은 수행하지 않았습니다. UI 검증의 작업 이력 샘플 자체는 도구 실행의 증명이 아닙니다.

## 검증 경계

실제 회사망 AI Pro SSO/API, 실제 ChatGPT 계정 로그인/한도, 실제 FabriX 계정과 사내 메일은 이번 검증에 포함하지 않았습니다. 배포 ZIP과 소스 커밋/업로드는 별도로 확인합니다. 보고된 `sinternet is not defined` 오류를 실제 사내 환경에서 재현한 것은 아닙니다.
