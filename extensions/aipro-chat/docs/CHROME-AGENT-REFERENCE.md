# Chrome 탭 실행과 진행 표시

확인일: 2026-09-22. 누비는 **실제 탭에서 실행하고 그 결과를 채팅에 표시하는 방식**을 유지한다. 기존 Pi와 Playwright CRX가 실행을 담당하며, AI Pro, ChatGPT, FabriX 연결은 그대로 사용한다.

[Claude Code의 Chrome 연동 문서](https://code.claude.com/docs/en/chrome)는 로그인된 브라우저의 보이는 탭에서 동작하고, 세션에 연결된 탭 그룹을 사용한다고 설명한다. [Claude 확장 권한 문서](https://support.claude.com/en/articles/12012173-get-started-with-claude-in-chrome)는 `debugger`를 클릭/입력/캡처에, `tabGroups`를 작업 탭 구분에 사용한다고 명시한다. 이는 참고 사례이며 Claude 확장 내부 구현을 확인하거나 누비에 가져온 것은 아니다.

| 항목 | 누비의 현재 처리 |
| --- | --- |
| 실제 탭 조작 | Playwright CRX가 Chrome 디버거에 연결해 입력과 클릭을 실행한다. DOM 값뿐 아니라 trusted 입력 이벤트와 화면 결과를 검사한다. |
| 새 탭과 창 | 실제 동작에서 생긴 탭과 opener를 추적한다. 팝업 닫힘 뒤에는 부모를 다시 확인하며, 이전 문서의 요소 참조를 재사용하지 않는다. |
| 결과 표시 | 도구 시작/종료 이벤트가 진행 기록을 갱신한다. 단계 완료는 모델의 계획 갱신에 따르되 전체 완료는 실행 종료와 별도 요구사항 검토가 모두 통과해야 표시한다. |
| 종료와 취소 | 완료, 중지, Chrome의 사용자 취소 이벤트에 연결을 해제한다. 취소한 요청은 자동으로 다시 연결하지 않는다. |
| 로그인과 단순 읽기 | 로그인은 리디렉션 수신, 페이지 읽기는 콘텐츠 스크립트로 처리한다. 이 경로에는 디버거를 연결하지 않는다. |
| 작업 탭 그룹 | 아직 구현하지 않았다. 기존 탭/문서 소유권 검사를 시각적 그룹으로 대체하지 않는다. |
| 콘솔/네트워크 진단 도구 | 범용 수집 도구는 아직 공개하지 않았다. 테스트 실행기는 자체 오류와 네트워크 fixture를 확인한다. |

디버거 연결은 개발자 도구 창을 띄우는 것과 다르다. [Chrome 공식 API](https://developer.chrome.com/docs/extensions/reference/api/debugger)는 탭별 CDP 명령과 연결 종료 이벤트를 제공한다. 작업 중 Chrome이 표시하는 디버깅 안내를 숨기는 플래그는 배포본에 넣지 않는다.

검증은 실제 Chrome 입력/클릭/새 탭 전환과 종료 후 연결 해제로 판정한다. 모델 응답과 사이트는 합성이므로 실제 사내 모델의 자율 판단 품질이나 회사 사이트 성공률과 구분한다. 세부 결과는 [진행 표시 검증](VERIFICATION-BETA-1.0.0-PROGRESS.md)에 기록한다.
