# 캡처 범위와 구간 이동 개선

2026-09-23. 전체 페이지 캡처 이후 남은 내부 스크롤, 지연 로딩, 잘못된 완료 판단을 보완했다.

## 확인한 부족한 점과 반영

| 이전 동작 | 변경 |
|---|---|
| 스크롤 영역의 크기는 읽지만 일반 div에는 실행용 ref가 없음 | 기존 관찰기에 스크롤 메타데이터와 최신 ref를 함께 제공. iframe/open shadow root도 같은 참조 계약 사용 |
| 고정 600px 이동으로 작은 목록에서 중간 내용을 건너뜀 | 실제 보이는 영역의 75%를 한 번 이동해 겹치는 구간 확보. 화면보다 큰 영역은 보이는 높이로 제한 |
| 마우스의 이전 위치에 따라 다른 영역이 이동 | 해당 영역이 wheel을 받는 지점을 확인. 안쪽 목록이 겹치면 외부 영역을 가리키는 지점을 선택 |
| wheel 반환을 이동 성공으로 간주 | 이동 전후 위치와 범위를 비교. 이동, 현재 경계, 이동 차단을 구분하고 새 관찰 반환 |
| 끝에서 추가 스크롤이 바깥 페이지로 전파 | 확인한 경계에서는 wheel 미발행 |
| 전체 PNG만 보고 모든 내용을 확인했다고 판단 가능 | 촬영 사각형, 문서 크기, 내부 영역, 로딩/실패 이미지, 관찰 생략을 구조화하여 반환. `allContentVerified`는 항상 false |

`scroll_page`와 격리된 `browser.scroll(direction, ref)`는 같은 실행기를 사용한다. 한 번 이동한 결과를 모델이 확인한 후 다음 도구를 선택한다. 페이지/영역 크기를 강제로 바꾸거나 무한 스크롤을 한 호출에서 끝까지 실행하지 않는다. 지연 로딩으로 범위가 늘면 `extentChanged`로 알린다. 막힘은 `scroll_not_moved`로 분류하고 현재 관찰을 기반으로 다른 영역/가림/대상을 확인하게 한다.

이미지의 현재 ref는 모델 도구 결과에만 전달하며 저장 이미지에 실행 참조를 추가하지 않는다. 기존 단계별 첨부, 마스크, PNG 다운로드, 확대 UI, 좌표 만료, 제공자 분리와 저장 한도를 유지한다.

## BP와 오픈소스 선택

- 실제 적용: 기존 Apache-2.0 `@playwright-repl/playwright-crx` 1.21.4의 Playwright `mouse.wheel`, 요소 handle, screenshot을 재사용한다. [Playwright 공식 스크롤 방식](https://playwright.dev/docs/input#scrolling)은 관찰한 요소를 가리킨 뒤 wheel을 보내는 방법을 제공한다. Nubi에서는 이동 결과까지 대조한다.
- [Playwright screenshot 문서](https://playwright.dev/docs/screenshots)와 [locator screenshot의 한계](https://playwright.dev/docs/api/class-locator#locator-screenshot)를 확인했다. 요소 캡처도 현재 스크롤된 내용만 보이며 가려진 요소를 자동 복원하지 않는다. 따라서 내부 영역의 높이를 바꾸거나 이미지 이어 붙이기로 모든 내용을 읽었다고 표시하지 않는다.
- 기존 `dom-accessibility-api` 관찰과 fresh ref를 확장했다. 이름만으로 스크롤 대상을 다시 추측하지 않는다. 별도 자동화 엔진이나 로컬 서버를 추가하지 않았다.
- 미채택: DOM을 복제해 이미지로 바꾸는 라이브러리와 자동 이어 붙이기. 실제 브라우저의 고정 요소, 가상 목록, iframe, 보안 마스크와 다른 그림을 만들 수 있고 이번 요구에는 기존 PNG/구간 방식으로 충분하다. 특정 대체 패키지 성능을 검증했다는 의미는 아니다.

75% 겹침은 누비의 로컬 설계 선택이며 공식 문서의 표준 수치가 아니다. 모델 누적 작업 수를 제한하지 않고 각 행동의 결과를 확인한다.

## 검증과 남은 범위

`tests/capture-coverage-browser.mjs`는 실제 Chrome 확장에서 일반 div/iframe 참조, 세로/가로 이동, 지연 증가, 가상 행 표시, 로딩/실패 이미지 구분, wheel 차단, 경계 전파 방지, stale ref, 큰 페이지의 viewport 대안과 중지를 검사한다. 기존 캡처 저장/다운로드/새로고침/모델 전환도 별도 회귀로 확인한다.

확인한 경계는 그 순간의 렌더링 범위다. 가상 목록의 전체 데이터, 접힌 패널, 늦게 나타나는 콘텐츠와 고객 인수 조건의 충족은 별도로 확인해야 한다. 모델에게 coverage를 제공하는 것 자체가 정확도를 보증하지는 않는다. 실제 Qwen/회사 사이트에서의 완료율과 Office 문서 이미지 삽입은 이번 합성 브라우저 검사 범위가 아니다.
