# nubi Beta 1.0.0 전체 검증

2026-09-22. 현재 구현한 누비 확장의 전체 회귀와 주요 상태 전환을 검사했다. **자동 검사는 통과했지만 브라우저 기본 확인창과 지속 실행 등 미지원 범위는 남아 있다.** 실제 계정과 회사망의 업무 성공률을 검증한 결과는 아니다.

## 변경과 확인

- 상단 한글 누비 로고 오른쪽에 공통 보조 글꼴의 작은 `beta`를 추가했다. 표시 버전은 Beta 1.0.0, Chrome 내부 업데이트 번호는 1.4.2다.
- 320px에서 로그아웃 버튼이 잘리는 문제를 재현하고 상단 간격을 수정했다. 터치 화면은 버튼 크기를 유지하며 줄을 나눈다. 모든 상단 버튼의 가시 영역 검사를 기존 UI 회귀에 추가했다.
- 로그인 전후 320/360/1100px, 일반/터치 포인터 12개 상태를 확인했다. 작은/큰 화면 이미지를 직접 확인했다. [320px](images/beta-1.0.0-full/beta-header-chat-320.png), [큰 화면](images/beta-1.0.0-full/beta-header-chat-1100.png).
- 이전 Beta 내부 1.4.1을 설치한 동일 Chrome 프로필/경로에 1.4.2를 교체하고 재시작했다. 확장 ID, 대화, 이력, 초안, 설정과 제공자별 대화가 유지됐다. 새 프로필 검사와 구분되는 실제 업데이트 검사다.
- OpenWiki 연결의 오래된 CSP 설명을 현재의 읽기 연결 구현에 맞춰 정정했다.

## 보완 우선순위

1. **브라우저 기본 확인창 처리.** 합성 페이지의 `confirm()`을 실제 Chrome에서 호출하면 현재 자동 취소된다. 클릭 호출은 반환되지만 확인창 이벤트는 모델에 전달되지 않으며, 별도 결과 검증은 예상 결과가 없어 실패한다. 따라서 명령 반환을 작업 성공으로 해석하면 안 된다. DOM 모달과 새 탭 지원만으로 이 흐름이 해결되지는 않는다. 확인창 관찰과 사용자 승인에 묶인 처리가 필요하다. [재현 기록](evidence/beta-1.0.0-full/native-dialog-audit.json).
2. **창 종료 후 지속 실행.** 현재는 체크포인트/대화 복원과 명시적 이어가기를 제공한다. UI가 사라져도 모델/도구 루프가 계속 실행되는 기능은 없다. 승인 편집 중의 미반영 수정도 페이지 새로고침까지 보존하지 않는다.
3. **미지원 작업 범위.** 파일 업로드/드래그앤드롭, PC 파일 생성/빌드/미리보기, 외부 MCP와 Python/Node 실행형 스킬은 미구현이다. 현재 Playwright facade를 전체 컴퓨터 조작 지원으로 표현할 수 없다.
4. **실환경 검증.** 회사망 AI Pro/FabriX, ChatGPT 실제 계정/한도, 실제 모델의 자율 과제 성공률, Windows/Edge, OS 파일/폴더 선택과 실제 클립보드는 별도 확인해야 한다. OpenWiki 폴더 재시작 검사는 실제 IndexedDB/디렉토리 핸들을 사용하지만 디렉토리 fixture는 OPFS이며 OS 디스크 권한 지속성 검사는 아니다. 과거 `sinternet` 오류의 회사 브라우저 원인 해결도 이번 결과로 단정하지 않는다.

AI Pro/FabriX의 계정 잔여 한도는 확인된 API가 없어 연결하지 않았다. 응답 usage 집계와 별개다. 일반 Playwright 조작의 디버깅 표시줄은 남으며, 로그인과 수동 DOM 관찰에서의 디버거 미사용과 구분한다. 세부 범위는 [구현 목표](IMPLEMENTATION-GOALS.md)에 유지한다.

[전체 실행 기록](evidence/beta-1.0.0-full/report.json), [추가 검사 요약](evidence/beta-1.0.0-full/summary.json). 전체 검사 중 183개 소스/테스트/패키지 파일의 해시가 바뀌지 않았고 최종 dist 해시도 일치했다. 개별 실행 로그와 고정 후보 ZIP은 `verification/pre-release-2026-09-22T00-58-34-895Z/`에 있다.
