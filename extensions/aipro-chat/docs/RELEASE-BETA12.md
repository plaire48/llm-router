# nubi Beta 1.0.0 — beta12

2026-09-23. Chrome 업데이트 번호는 1.4.15입니다.

## 변경

- 작업 위치를 **별도 창에서 작업 / 이 탭에서 작업**으로 구분하고 현재 화면에 미치는 영향만 짧게 설명합니다. OS 마우스는 이동하지 않습니다.
- 자동 압축은 실제 선택된 도구와 최신 계획까지 계산합니다. 이전 사용자 요청을 제한된 예산 안에서 원문으로 보존하며 오래된 도구 근거는 필요할 때 조회합니다. 최신 수정과 실행 영수증이 요약보다 우선합니다.
- HTTP/HTTPS MCP를 등록하고 사용자 지정 헤더로 연결 테스트할 수 있습니다. 원격 도구 실행은 도구와 인자가 표시된 일회성 승인을 받습니다.
- SKILL.md 폴더의 scripts/*.browser.js를 기존 브라우저 VM에서 실행합니다. PC의 Python/Node 실행이나 라이브러리 설치는 포함하지 않습니다.
- JSM 티켓의 보이는 본문과 출처를 수집하고 검색하며 선택한 폴더에 개정별로 보관합니다. 같은 사이트의 제한된 첨부 다운로드를 지원합니다. 사용자 수정 파일은 덮어쓰지 않습니다.

## 검증

- 단위 검사 489개 통과, CX 디자인 검사와 후보 빌드 통과.
- 실제 Chrome 테스트 180회 통과. 회귀 대상은 새 프로필로 3회 반복했습니다.
- 두 경로에서 따로 빌드한 dist 559개 파일이 동일했습니다.
- 처음 접근성 검사는 새 설정 메뉴가 기대 목록에 없어 실패했습니다. 제품 코드는 바꾸지 않고 해당 검사에 두 메뉴와 키보드 검증을 추가했습니다. 같은 빌드와 변경 없는 3회 회귀 기록에 통합 검사 재실행을 합친 결과이며 최초 실패 기록도 보존합니다.
- [전체 검사 기록](verification/beta12-browser.json), [Qwen 실모델 평가 상태](verification/beta12-live-model.json).
- 배포 ZIP SHA-256: `d1fc1aa6cdd375ab4444e28d246ec2469981003bcde9fb4f687557f6075e9e53`

압축 검사는 의도적으로 부정확한 요약을 반환해도 이전 요청이 보존되는지, 새로고침과 반복 압축 후에도 유지되는지, 중복 입력 없이 계속하는지를 확인합니다. 모든 역사적 조건을 원문으로 유지하는 것은 아니며 생략 개수를 표시합니다.

## 확인 범위

실제 Chrome과 합성 제공자/업무 사이트를 사용했습니다. 회사 AI Pro/FabriX/ChatGPT 계정, 실제 JSM/MCP 서버 및 Qwen의 요약 정확도는 이번 검사로 확인하지 않았습니다. 폴더 쓰기는 OPFS의 실제 directory handle로 확인했으며 OS의 폴더 선택 승인 화면은 별도 확인 대상입니다.

화면에 렌더되지 않은 댓글이나 가상 스크롤 전체까지 수집한 것으로 표시하지 않습니다. 첨부 바이트 보관은 문서 해석과 다릅니다. MCP는 Streamable HTTP이며 OAuth 자동 탐색, stdio와 구형 SSE는 포함하지 않습니다. A2A와 Desktop 자동 동기화는 보류합니다.
