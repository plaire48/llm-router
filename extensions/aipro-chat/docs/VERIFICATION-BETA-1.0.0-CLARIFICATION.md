# Beta 1.0.0 질문 후 작업 재개

표시 버전은 **Beta 1.0.0**, Chrome 업데이트 번호는 **1.4.7**이다.

## 변경

진행 방법, 대상이나 필수 정보가 불명확하면 추측 실행 전에 질문한다. 실제 근거가 있는 선택지를 우선하고 직접 답변도 받는다. 안전한 페이지 조회로 알 수 있는 사실은 확인하되, 불명확하면 질문하고 답변을 기다린다.

- 질문을 모든 스킬에 제공한다. 텍스트 스킬에 브라우저 실행 권한을 추가하지 않는다.
- 한 모델 응답에 질문과 입력·클릭이 섞이면 질문만 실행한다.
- 결과 검토에서 사용자 정보가 필요하면 오류로 종료하지 않고 질문 카드로 연결한다. 질문 저장 실패 시 후속 실행을 막는다.
- 질문 전에 원래 목표를 보관한다. 새로고침 후 답변해도 원래 요청을 이어서 처리한다.
- 등록·전송 등 최종 실행 승인은 기존 승인 절차로 분리한다.

기존 CX 질문 폼, 선택지, 직접 입력과 답변 초안 복원을 사용한다.

## 검증

단위 검사 **288개**, 디자인 검사, 빌드와 관련 브라우저 **10개 스위트 16회**를 확인했다. 질문, 질문 폼, 실행·검증 하네스는 새 프로필에서 각 3회 검사했다. 승인, 이미지 선택, 스킬, ChatGPT, FabriX, 컨텍스트 압축과 OpenWiki 연동도 검사했다.

실제 Chrome에서 질문 전 입력·이동 0회, 새로고침 후 질문 유지, 답변 후 입력 1회와 검증 완료를 확인했다. 결과 검토가 만든 질문도 같은 흐름을 통과했다. 텍스트 스킬과 읽기 전용 스킬의 질문 도구 제공 범위도 확인했다.

처음 OpenWiki 검사는 격리된 체크아웃에 서버 빌드가 없어 시작하지 못했다. 빌드 후 통과했다. 질문 화면 캡처는 폰트와 등장 애니메이션 완료를 기다리도록 보완하고 3회 다시 확인했다. 초기 컨텍스트 검사에서는 늘어난 프롬프트로 테스트 자료가 입력 한도를 넘었으므로, 기존 검사의 의도인 ‘요약 실패 후 원본으로 계속하기’를 유지하도록 테스트 자료를 44K자에서 42K자로 조정했다. 실제 컨텍스트 한도는 변경하지 않았다.

[통합 결과](evidence/beta-1.0.0-clarification/report.json), [첫 실행](evidence/beta-1.0.0-clarification/initial-report.json), [보완 후 실행](evidence/beta-1.0.0-clarification/final-report.json), [질문 흐름](evidence/beta-1.0.0-clarification/clarification-browser.json).
