# 누비 브라우저 가독성 재점검

## 반영

| 화면 | 확인한 문제 | 반영 |
| --- | --- | --- |
| 연결된 빈 채팅 | 로그인 소개와 질문을 다시 보여 핵심 요청이 아래로 밀림 | 캐릭터와 한 줄 질문만 표시. 질문은 단일 `h1`; 로그인 소개는 유지 |
| 프롬프트 바로가기 | 안내가 길고 저장한 본문이 한 줄에서 잘림 | 안내를 한 줄로 줄임. 이름 다음에 본문 두 줄, 명령은 마지막에 표시. 전체 내용은 편집에서 확인 가능 |
| 작업 녹화 | 시작 안내 두 문단과 한 줄로 잘리는 저장 작업명 | 시작 방법과 입력값 비저장 조건을 한 문단으로 합침. 저장 작업명은 두 줄, 전체 이름은 툴팁과 조작 이름에 보존 |
| 파일 도움말 | 128 KB·4만 자·PDF 150쪽이라는 오래된 한도 | 실제 `ATTACHMENT_LIMITS`에서 파일·본문·쪽수 한도를 가져와 화면 도움말과 배포 `GUIDE.md`를 함께 생성 |

본문 14/22px, 모달 제목 16/24px, 날짜·명령 같은 보조 정보 12/16px와 기존 HTML 색상 토큰을 유지했다. 확인한 글자색 대비는 `#4E5968`/흰색 7.11:1, 같은 글자/`#F1F7FE` 6.60:1, 진한 블루 `#1B64DA`/흰색 5.41:1이다. 대비 실패가 확인되지 않은 색을 임의로 바꾸지 않았다. 아이콘은 현재 CX 컴포넌트를 재사용하고 편집·삭제에 접근성 이름을 유지했다. 저장, 승인, 오류와 입력 이름은 뜻을 잃지 않도록 글자를 남겼다.

## 방법과 선택

[W3C WCAG 2.2의 텍스트 대비](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)와 [입력 이름·안내](https://www.w3.org/WAI/WCAG22/Understanding/labels-or-instructions.html)를 기준으로 계산 스타일과 화면 캡처를 함께 확인했다. 설치된 CX 0.5.4, Deck 컴포넌트, 로컬 Noto Sans KR와 의미 토큰으로 해결되어 새 UI 라이브러리는 도입하지 않았다. 과거 캡처에서 길어 보였던 녹화 단계 URL은 현재 코드가 이미 호스트명으로 줄여 표시하므로 다시 변경하지 않았다.

## 검증 범위

- [아이덴티티 게이트](../verification/pre-release-2026-09-25T11-37-23-192Z/report.json): 단위 868건, 디자인 검사, 후보 빌드, 브라우저 30단계 통과(전체 33단계).
- [현재 후보 전체 품질 게이트](../verification/pre-release-2026-09-25T11-48-00-111Z/report.json): 같은 후보의 87/87단계 통과. 반복 대상은 새 Chrome 프로필로 3회 검사했고 단위 868건, 디자인, 빌드와 바로가기 검사를 포함한다. [영역별 회귀 결과](../verification/pre-release-2026-09-25T11-48-00-111Z/QUALITY.md)는 실모델 점수가 아니다.
- 별도 바로가기 브라우저 검사: 선택은 초안만 채우고, 저장·편집·삭제·재열기와 360/1000px를 확인했다. 저장 완료 대기 조건을 검사에 추가했다.
- 직접 확인한 화면: [연결된 320px 빈 채팅](../verification/readability-followup-2026-09-25/connected-320.png), [360px 바로가기 설정](../verification/readability-followup-2026-09-25/shortcuts-360.png), [360px 녹화 검토](../verification/readability-followup-2026-09-25/recording-360.png). 빈 채팅은 소개 0개, `h1` 1개, 가로 넘침 없음으로 확인했다.

이 검사는 Chrome과 합성 사이트·응답 기반이다. 실계정 모델의 업무 정확도와 실서비스 저장·배포 성공을 뜻하지 않는다.
현재 `quality:status`는 구현 25건을 해당 후보에서 검증하고, 실 Qwen 평가·대표 사이트 서버 영수증·Windows/Edge 실계정·공식 WebArena 4건을 외부 검증으로 남긴다. `releaseApproved=false`이며 릴리스는 업로드하지 않았다.
