# 0.15.1 전체 화면 스크롤 위치

검증일: 2026-09-21

대화 본문의 최대 폭을 적용하던 영역에 스크롤바도 함께 묶여 있었다. 1440px 화면에서 스크롤 영역의 오른쪽 좌표가 1104px로 측정되어 사용자 증상을 재현했다.

스크롤 영역은 창 전체 너비로 넓히고, 안쪽 본문에만 기존 최대 폭을 적용했다. 입력창과 알림은 가운데에 유지하며 하단 입력창은 대화와 함께 움직이지 않는다. 기존 CX 폰트, 색상, 간격과 최신 답변 이동 동작을 유지했다. 인증과 API 경로는 변경하지 않았다.

## 확인 결과

- 360, 800, 1100, 1440, 1920px에서 스크롤 영역의 오른쪽 끝이 창 너비와 일치했다. 가로 넘침과 이중 세로 스크롤이 없었다.
- 12쌍의 합성 대화로 양옆 여백에서 휠 스크롤, 최신 답변 이동, 입력창 하단 위치와 초안 유지를 확인했다.
- 1440px에서 입력창은 변경 전후 모두 x=336, 너비=768px를 유지했다. 스크롤 영역만 x=0부터 x=1440까지 확장했다.
- `npm run design:check`, `npm run build` 통과. `tests/browser.mjs`의 31개 기존 흐름도 통과했다. 빈 대화, 긴 대화, 모델 선택, 설정, 이력과 재진입을 포함한다.

격리 Chrome과 합성 대화/인증 응답으로 확인했다. 운영체제의 기본 스크롤바 표시 설정을 바꾸거나 자체 스크롤바를 추가하지 않았다.
