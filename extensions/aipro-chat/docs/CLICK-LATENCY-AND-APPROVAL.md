# 클릭 대기와 승인 문구

2026-09-23. Qwen 3.8 27B 기준의 누비 브라우저 실행 경로. 실제 AI Pro 모델 정확도와 로컬 합성 응답 검증은 구분한다.

## 재현

- `신청서 제출`, `신청하기`를 모두 `등록`으로 분류했다. 버튼으로 만든 `등록 화면 열기`는 준비 단계인데도 승인을 요구했다.
- 팝업 감지기가 모든 클릭 뒤 최대 7초 동안 새 탭을 조회했다. 로컬 테스트의 토글과 페이지 내부 링크는 각각 7,466ms, 7,387ms였다. 클릭 자체는 한 번이었다.
- 이전의 링크 hit area와 호버 개선은 유지한다. 이번 지연의 주원인은 클릭 방법의 개수가 아니라 클릭 뒤의 불필요한 대기였다.

## 적용

승인 분류는 등록, 제출, 신청, 삭제, 발송을 구분한다. `신청 내역 삭제`의 마지막 동작을 읽고 실제 대상의 짧은 이름을 승인 버튼에 표시한다. 예를 들어 제목은 `제출할까요?`, 버튼은 `신청서 제출`이다. 긴 이름은 짧은 동작 이름을 사용하며 대상 원문은 상세에서 확인한다. 페이지 버튼 자체의 이름은 변경하지 않는다.

분명한 양식 열기와 내역 조회는 링크와 일반 버튼 모두 준비 단계로 취급한다. 실제 form submit, 최종 제출, 복합 동작은 승인 보호를 유지한다. 분류는 DOM에 기반한 보조 규칙이며 사이트의 의도를 완벽하게 판정하지 않는다. 모델도 현재 맥락을 보고 최종 행위 전에 `request_approval`을 사용한다. 대상이 불명확하면 질문한다.

제출/저장 단축키는 입력란 이름보다 먼저 분류한다. 예를 들어 `등록 화면 열기`라는 필드에서 Ctrl/Command+Enter를 보내도 제출 승인이 필요하다. 단축키 승인 버튼에는 필드 이름을 쓰지 않고 `제출`이나 `저장`을 표시한다.

승인에는 기존의 실제 노드, 문서, 초안 지문, 계정, 대화, 일회성 권한을 그대로 사용한다. 편집 가능한 초안이 없는 동작은 연필과 `초안 보기`를 표시하지 않는다. 취소 시 없는 초안을 보존했다고 안내하지 않는다. Noto Sans KR 14px와 deck 색상/여백, CX 버튼과 키보드 동작을 유지하며 긴 버튼은 좁은 화면에서 줄바꿈한다.

팝업은 클릭 전에 감지한다. 대상 상태나 화면 텍스트의 변화가 확인되면 현재 관찰을 빠르게 반환한다. 변화 비교는 최대 48,000자의 일시적 해시와 제어 상태만 사용하며 페이지 원문/값/해시는 진단과 모델에 전달하지 않는다. 이 변화는 완료 증거가 아니다. `verify_page`와 최종 요구사항 검증은 별도로 유지한다.

반환 후에도 원래의 7초 범위에서 팝업 이벤트를 감지한다. 이때 반복 조회는 하지 않는다. 늦게 나타난 자식은 다음 도구 진입점에서 처리하고 최신 화면을 반환한다. 그 요청의 쓰기는 실행하지 않아 이전 화면의 ref나 스크립트가 새 화면에서 실행되는 것을 막는다. 동일 자식을 중복 감지한 관찰자는 함께 정리한다. 종료, 취소, 제한 시간 뒤에는 이벤트 구독을 해제한다. 이미 수신한 살아 있는 자식은 다음 도구까지 유지하고 닫힌 자식은 버린다.

명시적인 `_blank`/이름 있는 대상, 실제 생성된 빈 팝업, 변화가 없는 클릭은 기존 제한 시간 내에서 기다린다. 1.4초 뒤 생성, 빈 창의 지연 이동, 이름 있는 창 재사용, 여러 창 선택을 계속 지원한다. 제한 시간 밖의 팝업이나 채팅 실행 종료 뒤의 자동 지속은 보장하지 않는다. 작업 창의 네이티브 팝업 초점 복원 한계도 별도 배포 차단 항목으로 남아 있다.

Stagehand는 MIT이며 브라우저 확장 구현도 공개되어 있다. 이번에는 코드를 복사하거나 런타임을 추가하지 않았다. 기존 Playwright CRX와 Pi에 필요한 패턴을 적용해 패키지 크기, 두 번째 브라우저 실행기, 도구 계약과 승인 체계의 재통합 비용을 피했다. Stagehand 전체 도입 성능이나 실제 Qwen 정확도가 좋아졌다고 주장하지 않는다.

## 검증

- `click-feedback-browser`: 실제 신뢰된 클릭 1회, 변경 관찰 지연, 잘못된 등록 승인, 제출/신청/삭제/발송 보호, 지연 팝업과 다음 쓰기 보류.
- `approval-labels-browser`: 합성 Qwen 도구 응답으로 실제 저장된 승인 질문을 UI에서 확인. 320/420/1100px, 글꼴, 긴 이름, 취소, 불필요한 초안 편집 제거.
- 기존 popup/approval/workspace/link/hover 회귀와 단위 테스트를 함께 실행한다. 배포 검증 결과와 후보 ZIP은 `verification`에 분리한다.
