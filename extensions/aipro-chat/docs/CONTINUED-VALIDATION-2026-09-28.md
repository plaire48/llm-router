# 중단 이후 실측과 완료 화면 검증

사용자의 재개 요청에 따라 실제 검증과 보완을 계속했다. 기존 검토·표 출처 후보와 이번 변경을 구분하며, 배포하지 않았다.

## E-08 실제 재시험

동일 후보 A(`7b1621037553b9d317073c0025c810e266000d1fe6a55470d3c98dd9521808fc`)를 기존 전용 평가 프로필에서 GPT-5.6 Luna로 실행했다. 다른 프로필의 인증을 복사하지 않았다. 정상 로그인 후 2026-09-28 04:38:15 UTC에 시작해 **16회 호출, 79,217ms**로 답변이 저장됐다. 원래 중단된 실행을 덮어쓰지 않은 별도 trial이다.

- 보고서: `verification/naver-sso-luna-2026-09-28T04-34-36-887Z.json`
- trial ID: `dea7f583-003e-42cc-b141-5bc86cfe5047`
- 원래 기준선: 32회 호출, 192,119ms, 최종 답변 없음. 이번 한 번의 경로 차이를 코드 변경의 인과적 개선이나 새 전체 성공률로 해석하지 않는다.
- 독립 채점: 선수 식별과 현재 계약 미확인 표시는 충족, **소속의 출처 시점 누락**으로 전체 과제는 미통과다. 경력 시작 `2022.01`은 출처의 시점이 아니다. 관찰 시각과 네이버 `본인참여 2025.02.06`을 구분해야 하며 후자를 최종 갱신일이나 현재 계약 증명으로 바꾸지 않는다.

보고서의 최초 화면 검사는 저장 완료와 불일치했다. 저장된 계획은 3/3, task는 done인데 DOM에는 계획 1/3·spinner 1·답변 미표시가 기록됐다. 별도 재진입에서 같은 대화와 요청, 실제 최종 답변 본문 및 계획 3/3·spinner 0을 확인했다. `delivery-reentry.json`과 `delivery-direct-body.json`에 재진입 관찰을 따로 남겼으며 원래 시간/화면 기록을 교체하지 않았다. 원래 전체 5개 실행의 E-08 중단도 그대로 유지한다.

## 실모델 비교와 철회한 변경

제목과 규칙 경계 검토 지침을 강화한 실험을 수행했다. 공개 저장 근거로 재구성한 5개 축소 사례를 수정 전/후 각각 3회, 총 **30회** Luna에 보냈다. 인증은 방금 정상 로그인한 평가 확장 자체 어댑터로만 사용했다. 이전 창의 인증이 처음 조회에서는 보였으나 실행 전 재확인에서 사라져 그 경로는 모델 호출 없이 중단했다. 인증 소실의 원인은 확인하지 못했다.

| 축소 사례 | 기존 지침의 기대 판정 일치 | 실험 지침의 기대 판정 일치 |
|---|---:|---:|
| 제목 대신 사이트명 | 1/3 | 2/3 |
| 올바른 개별 결과 제목 | 2/3 | 1/3 |
| 읽지 않은 규칙 경계 | 3/3 | 3/3 |
| 텍스트와 도해를 함께 준 올바른 설명 | 0/3 | 0/3 |
| 해당 조문만 인용하라는 제한된 요청 | 3/3 | 3/3 |

합계는 양쪽 모두 9/15였다. 파서에 거절된 형식 오류도 불일치로 남겼다. 이 값은 축소 입력의 기대 판정 일치이며 제품 정확도나 과제 성공률이 아니다. E-01의 입력/순위 조건은 이 실험에서 제외됐고 광고/부분 범위가 여전히 일부 판정에 영향을 주었다. E-04는 원래 페이지 33 이미지 입력을 완전히 복원한 것이 아니다.

도해만으로 판단한 모델이 손을 유효면에 포함시키거나 올바른 제외 설명을 거절했다. 영국펜싱협회 FAQ의 손 제외를 명시한 실제 원문을 보완한 별도 대조에서는 기존 지침 **3/3**, 실험 지침 **1/3**이 통과했다. 입력 근거와 답변이 달라졌으므로 첫 실험과 동일 입력 A/B로 합치지 않는다. **검토 지침의 실험 변경은 철회했다.** 원래 금지 조건, 문맥 예산과 엄격한 판정 파서는 유지했다.

실행 안내에는 제목과 링크의 실제 대응, 규칙의 조건·참조 도해·이어지는 본문 또는 충분한 대체 출처 확인을 짧게 반영했다. 특정 종목의 정답이나 특정 PDF를 하드코딩하지 않았다. 이 안내 자체의 새 전체 실모델 성능은 아직 측정하지 않았다.

## 실제 반영한 완료 화면 검사

- 누비 메시지에 실제 메시지 ID를 DOM 속성으로 연결한다. 사용자 문구나 화면 배치는 바꾸지 않는다.
- 평가기는 해당 대화의 **현재 요청 ID가 같은 마지막 답변의 직접 자식 본문**만 검사한다. 중첩된 진행 Markdown이나 이전 답변을 최종 답변으로 세지 않는다.
- 화면을 전면으로 가져온 뒤 답변 표시, 계획 완료 수, spinner 없음이 함께 맞을 때까지 제한된 시간 동안 관찰한다. 저장 상태만으로 표시 완료를 추정하지 않는다.
- 오래된 고정 후보에 메시지 ID 속성이 없으면 새 검사 계약 미지원으로 남긴다. 이를 자동 통과나 새 실패로 바꾸지 않는다.
- 재진입 성공을 원래 캡처 시점의 성공으로 소급하지 않는다.

최종 자동 검사 **1,354/1,354**, 완료 처리 Chrome 7개, 새 표시 검사 Chrome 4개가 통과했다. 문맥 예산을 깨뜨린 중간 변경은 축소하고 관련 31개 검사도 통과했다. 후보 빌드와 디자인 검사는 로그를 보관했다. Chrome 검사는 실제 브라우저의 합성 입력 검사이며 실서비스 모델 성공과 별개다.

## 방법과 남은 범위

[Anthropic 평가 방법](https://www.anthropic.com/engineering/demystifying-evals-for-ai-agents)의 실행 기록과 실제 결과 구분, 기존 Codex식 도구 계약 검사, [agent-browser](https://github.com/vercel-labs/agent-browser)의 관찰 정체성 보존 검토를 재사용했다. 기능 추가보다 판정 오류 재현과 반례 비교를 우선했고, 효과가 없거나 잘못된 답변 교정을 유발한 지침은 채택하지 않았다. 새 의존성이나 Claude 배포 코드는 도입하지 않았다.

`verification/semantic-review-2026-09-28/`에 입력, 전후 프롬프트 해시, 전체 공개 판정, 오류, 추가 원문, 테스트와 후보 ZIP을 보관한다. 공개 내용만 비교했고 모델의 비공개 추론이나 인증값은 기록하지 않았다. 최신 후보의 전체 5개 실측은 남아 있으며, 기존 미완료 전체 점수에 이번 집중 실험을 끼워 넣지 않는다.
