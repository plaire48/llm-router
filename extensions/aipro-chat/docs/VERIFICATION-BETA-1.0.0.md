# nubi Beta 1.0.0

2026-09-22. 제품과 앞으로의 배포 이름을 nubi로 통일하고 표시 버전을 Beta 1.0.0으로 지정했다. 한글 누비 로고와 기존 CX 화면은 유지한다.

## 변경

- Chrome 확장 이름은 `nubi`, 탭 제목은 `nubi — 브라우저 AI Agent`다.
- 설정 하단에는 `Beta 1.0.0`을 표시한다. 연결 진단에도 제품 이름과 표시 버전을 기록한다.
- npm 패키지는 `nubi@1.0.0-beta.0`, 설치 ZIP은 `nubi-beta-1.0.0.zip`이다. 패키징과 검증은 공통 릴리스 메타데이터 함수를 사용한다.
- 새 스킬 파일은 `nubi-browser-skill` 형식으로 내보낸다. 이전 `aipro-browser-skill`도 불러올 수 있다.
- AI Pro는 제공자 이름으로 유지한다. 기존 대화/설정 저장소, 인증 API와 설치 경로의 식별자를 일괄 치환하지 않는다. 과거 배포 파일과 검증 기록도 원래 이름을 유지한다.

## 버전과 업데이트

Chrome은 숫자 `version`으로 업데이트 순서를 비교하고 `version_name`을 표시용으로 제공한다. 기존 1.4.0 설치보다 높은 내부 번호 `1.4.1`과 표시 이름 `Beta 1.0.0`을 함께 사용한다. 이후 제품의 Beta 버전과 내부 업데이트 번호를 각각 올린다. [Chrome 공식 버전 규칙](https://developer.chrome.com/docs/extensions/reference/manifest/version).

기존 설치 폴더의 파일을 교체하고 확장 관리에서 새로고침한다. unpacked 설치의 경로를 임의로 바꿔 새 확장으로 로드하지 않는다. 새 설치는 ZIP을 원하는 폴더에 풀고 해당 폴더를 로드한다.

## 검증

단위 테스트 **285개**, CX 디자인 검사와 후보 빌드가 통과했다. Chrome의 대화 이력, 화면/설정, 진단 복사/피드백, 페이지 스킬 공유 4개 스위트가 통과했다. 설정 버전을 320/360/1100px에서 확인하고 새 스킬 형식의 내보내기/가져오기와 이전 형식 가져오기 호환성을 검사했다. [검증 기록](evidence/beta-1.0.0-report.json).

이전 스킬 형식을 기대한 브라우저 검사 1회는 제외하고 해당 기대값을 수정한 뒤 선택한 4개 스위트를 모두 재실행했다. 제외 기록을 증거에 남겼다.
