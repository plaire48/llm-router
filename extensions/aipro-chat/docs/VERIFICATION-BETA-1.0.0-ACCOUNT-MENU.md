# 계정 메뉴 이동 검증

2026-09-22. 표시 버전은 Beta 1.0.0, 내부 업데이트 번호는 1.4.3이다.

상단 로그인/로그아웃 아이콘을 `…` 설정 모달의 계정 행으로 옮겼다. 연결 중에는 제공자 이름과 로그아웃 아이콘, 미연결 시 계정과 로그인 아이콘을 표시한다. 기존 이력, 새 대화, 창 확대와 사용량은 유지한다. 도움말도 새 경로로 수정했다.

로그아웃 시 초안을 저장한 뒤 제공자 선택창을 연다. 설정과 선택창을 겹쳐 띄우지 않으며 선택창을 닫으면 상단 설정 버튼으로 초점을 돌린다. 응답 실행 중에는 계정 작업을 막는다.

- 단위 검사 285개, 디자인 검사와 후보 빌드 통과.
- 실제 Chrome for Testing에서 관련 6개 스위트 8회 통과. 제공자 전환은 새 프로필에서 3회 반복했다.
- 320px/360px/1100px 화면, 모달 글꼴과 가독성, 로그인 진입, 초안 보존, 제공자 전환, 재시작과 키보드 초점 복귀를 확인했다.
- 공급자 응답과 인증은 합성 fixture다. 사내 SSO/실계정 검증이나 스토어/GitHub 게시를 뜻하지 않는다. 이전 전체 기능 검증과 이번 변경 범위의 검사를 구분한다.
