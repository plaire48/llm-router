# nubi

**Beta 1.0.0** — 웹을 누비는 AI Agent. AI Pro, ChatGPT, FabriX를 연결해 사용합니다.

[nubi Beta 1.0.0 설치 ZIP](https://github.com/plaire48/ai_workspace/releases/download/nubi-v1.0.0-beta.35/nubi-beta-1.0.0.zip)과 [배포 검증](docs/RELEASE-BETA35.md).

도구 결과를 확인한 뒤 다음 행동을 선택합니다. 페이지를 바꾼 단계는 검증 후 완료로 표시하며, 필요한 정보는 질문으로 받고 최종 반영은 승인을 기다립니다. [모델 목록과 이미지 자동 전환](docs/VERIFICATION-BETA-1.0.0-MODEL-ROUTING.md)도 유지합니다.

한글 로고는 누비로 유지합니다. 기존 설치 폴더에 압축을 풀어 덮어쓴 뒤 확장 관리에서 새로고침하세요.

설정의 도움말 아이콘에서 기능별 안내를 확인합니다. [사용 안내](GUIDE.md)는 ZIP에도 포함됩니다.

## 설치

1. ZIP을 압축 해제합니다.
2. `chrome://extensions`에서 개발자 모드를 켜고 **압축해제된 확장 프로그램 로드**로 `manifest.json`이 있는 폴더를 선택합니다.
3. 확장 아이콘을 누르고 사용할 제공자를 선택합니다.

업데이트는 기존 폴더의 파일을 교체한 뒤 확장 관리에서 **새로고침**합니다. 웹 스토어 배포본이 아닌 개발자 모드 설치용입니다. AI Pro, ChatGPT 로그인과 FabriX 연결, 기본 페이지 읽기는 디버거 없이 처리합니다. 실제 Playwright 조작, 캡처와 이미지 도구는 작업 중 디버거를 사용합니다.

입력창의 **모델 이름 → 제공자 아이콘 탭**에서 AI Pro, ChatGPT, FabriX를 전환하세요. 연결이 없으면 그 자리에서 로그인합니다. 이미 연결했다면 재로그인 없이 대화와 모델을 복원합니다. 제공자별 대화와 초안은 분리하며 인증값은 브라우저 세션 동안만 보관합니다.

로그아웃은 **… → 설정의 계정 아이콘**이나 모델 창의 로그아웃 아이콘으로 합니다. 선택한 제공자만 연결을 해제하며 다른 연결, 대화와 초안은 남습니다. 로그아웃 직후 같은 모델 창에서 다른 제공자를 고를 수 있습니다.

**가방 모양 아이콘을 다운로드하고 싶어**처럼 설명하면 현재 페이지에서 찾아 보여줍니다. 이미지 지원 모델은 실제 후보의 모양도 비교합니다. 애매하면 이미지로 선택하고, 없으면 직접 설명할 수 있습니다. 카드 오른쪽 아이콘으로 다운로드하세요.

캡처한 브라우저 화면은 해당 진행 단계에서 펼쳐 봅니다. 눌러서 확대하거나 다운로드 아이콘으로 원본 PNG를 저장하세요. 캡처는 대화 이력에 함께 남으며 해당 대화를 삭제할 때 지워집니다.

부리 없는 청록색 새 캐릭터가 짧게 날갯짓하며 떠오르고 눈을 깜빡입니다. 작업 중에는 작게 움직이고 완료되면 잠깐 눈웃음을 짓습니다. 제품 이름은 누비(Nubi)이며 로고 글자는 정갈한 한글 서체로 표시합니다.

사용자 메시지만 말풍선으로 표시하며 누비 답변은 박스 없이 이어집니다. 두 본문은 같은 글자색을 사용합니다.

복사하면 체크 아이콘과 완료 알림이 표시됩니다. 누비는 대기 중 눈웃음을 짓고, 잠시 쉬면 눈을 감습니다. 완료와 오류도 표정으로 알려주며 운영체제의 모션 감소 설정을 따릅니다.

## FabriX 연결

**FabriX → Endpoint, Client Key, API Token 입력 → 연결 테스트 → 연결** 순서로 진행합니다. 모델 목록을 자동으로 가져오며, 입력창 아래에서 한국어 모델명을 선택합니다. 연결을 바꾸려면 **모델 이름 → FabriX 탭 → 연필 아이콘**을 누르세요.

기존 라우터의 FabriX API를 확장 내부에서 OpenAI Chat Completions 형식으로 변환합니다. DOM 읽기, 입력, 클릭, 페이지 이동과 Playwright 스크립트를 기존 에이전트에서 실행합니다. 텍스트 응답을 검증한 뒤 전달하므로 답변은 한 번에 표시됩니다. 이미지 입력은 지원하지 않습니다. 연결 테스트는 모델 목록 접근을 확인합니다. 실제 응답과 도구 실행은 대화에서 확인하세요.

도구 응답 형식이 잘못되면 한 번 자동 교정합니다. 계속 실패하면 설정의 연결 진단에서 사유를 확인하세요. 실제 HTTP 502와 응답 형식 오류는 구분해 기록합니다.

## 사용량

상단 **막대그래프 아이콘**에서 제공자별 오늘/전체 토큰을 확인합니다. 도구 실행 중 모델 호출도 포함하며, 사용량이 없는 응답은 미집계로 표시합니다. 이 확장에서 기록한 사용량을 집계합니다.

ChatGPT 로그인 시 계정 잔여 비율과 초기화 시간을 조회합니다. AI Pro와 FabriX 계정 한도는 조회 API가 확인되지 않아 제공하지 않습니다. 입력창의 원형 아이콘에서는 마지막 요청의 컨텍스트를 확인합니다.

## 대화와 작업 이어가기

작업 계획과 현재 실행을 채팅에서 확인합니다. 읽기, 입력, 검증이 끝나면 진행 중 표시가 완료 기록으로 바뀝니다. 실행 중에는 최근 기록을 펼치고, 끝나면 접어 둡니다. 계획과 기록은 대화 이력에 남습니다. 큰 첨부와 Wiki 조사는 담당별 문서 구간, 누락 보완, 결과 통합과 최종 전달을 표시합니다. 전체 기록은 페이지별로 조회하며 보관 한도나 저장 누락을 알립니다. [문서 분업과 진행 기록](docs/MULTIAGENT-PROGRESS-2026-09-25.md)을 참고하세요.

각 도구의 결과를 확인한 뒤 다음 행동을 정합니다. 새 페이지나 팝업을 열면 바뀐 화면부터 확인하고, 앞서 마친 입력은 반복하지 않습니다. 이미 확인한 입력란들은 함께 작성할 수 있습니다.

진행 방법이나 필요한 정보가 불명확하면 먼저 질문합니다. 선택하거나 직접 답변하면 원래 요청을 이어서 처리합니다. 답변 전에는 입력과 클릭을 실행하지 않습니다.

상단 **이력 아이콘**에서 이전 대화를 검색하고 선택해 이어갑니다. 이름 변경과 삭제도 여기서 합니다. **새 대화**는 기존 대화, 초안, 모델과 첨부 이미지를 보관합니다. 새로고침하거나 브라우저를 다시 열면 마지막 대화를 복원합니다.

대화는 이 브라우저에 저장되며 계정이나 다른 기기와 동기화되지 않습니다. 브라우저 종료 후에도 이력은 볼 수 있고, 이어서 보내려면 해당 제공자로 다시 연결합니다.

대화가 길어지면 이전 내용을 자동 요약하고 최근 지시는 그대로 유지합니다. 원본 대화는 남습니다. 입력창의 원형 아이콘에서 기억한 내용을 보고 압축 아이콘으로 직접 정리할 수도 있습니다. 요약에 사용한 토큰도 집계합니다.

브라우저 작업이 중단되면 답변 아래 **이어가기 아이콘**을 누르세요. 현재 페이지와 이전 작업 결과를 다시 확인합니다. 창을 다시 여는 것만으로 작업을 재실행하지 않습니다.

## 페이지 작업

채팅에 **현재 페이지 분석해줘**처럼 요청하세요. 필요한 경우 현재 탭을 자동으로 연결해 읽습니다. 첫 요청에서 Chrome이 사이트 접근 권한을 물으면 허용하세요. 일반 대화에서는 페이지 내용을 읽지 않습니다.

입력창의 링크 아이콘으로 직접 연결할 수도 있습니다. 스킬은 작업별 지침이 필요할 때 선택합니다.

> 홈페이지에서 메일을 열고 받는 사람, 제목, 본문을 입력해줘. 발송하지 마.

모델이 필요한 도구를 선택하고 페이지를 읽어 작업한 뒤, 입력값과 화면의 결과를 다시 확인합니다. 별도 검토에서 요청한 항목이 빠졌는지 확인하고 누락된 부분을 보완합니다. 검증이 남으면 완료로 표시하지 않고 현재 상태에서 이어갈 수 있습니다. 오류가 나면 현재 상태를 보고 코드를 수정합니다. 탭 이동, 클릭, 입력, 선택, 스크롤, iframe과 open shadow DOM을 지원합니다. AI Pro의 Qwen3.8 모델에서는 화면 이미지를 읽는 경로와 좌표 클릭도 사용할 수 있습니다.

기본 페이지 읽기와 탭 목록 조회는 디버거를 연결하지 않습니다. Playwright 조작, 화면 캡처와 이미지 도구에는 크롬의 디버깅 표시줄이 나타나며 완료하거나 중지하면 해제됩니다. 표시줄에서 취소해도 실행을 중단합니다. 스킬은 지침과 실행 권한을 파일로 공유합니다. Python이나 로컬 프로그램 실행은 포함하지 않습니다.

## 개발

Node.js 22.19 이상에서 실행합니다.

```sh
npm ci
npm test
npm run design:check
npm run build
```

빌드 폴더는 `dist/`, 설치 ZIP은 `releases/`입니다. CX 패키지는 `vendor/`에 포함되어 있습니다.

## 검증

단위 테스트와 설치한 Chrome 확장에서 사용량, 채팅, 사이드 패널, 접근성, 브라우저 코드 실행을 검증합니다. 네트워크와 모델 판단은 합성 응답입니다. 실제 회사 메일의 초안 저장과 실제 모델의 화면 판단 성능은 별도 검증이 필요합니다.

실제 ChatGPT 계정의 로그인/한도 조회와 회사망 AI Pro 성공은 미검증입니다. ChatGPT 모델 목록은 Pi 0.87.1 지원 목록이며 계정의 실제 접근 권한과 다를 수 있습니다. 인증은 Pi의 공개 구현을 적용한 것으로 OpenAI의 범용 OAuth 연동 지원을 보증하지 않습니다.

## 사이트 위키

`/wiki`로 현재 화면의 문서 초안을 만들고 검토 후 저장합니다. 작업 완료 뒤에도 위키 저장을 선택할 수 있습니다. 문서는 브라우저 내부에 보관하며 다음 작업에서 관련 부분을 검색합니다. ZIP/Markdown으로 내보내고 기존 외부 OpenWiki의 참고 문서로 활용할 수 있습니다. 코드 저장소나 PC 실행기는 필요하지 않습니다. 내장 문서와 선택한 외부 문서는 각각 독립된 OpenWiki 조회 실행기에 위임합니다. 확장에 포함된 DeepAgents 코어가 현재 선택한 같은 모델로 검색과 하위 분석을 수행합니다. [위키별 실행 구조와 검증](docs/OPENWIKI-AGENT-DELEGATION.md)을 참고하세요. [근거 관리와 검증 범위](docs/BROWSER-SITE-WIKI.md)를 참고하세요.
