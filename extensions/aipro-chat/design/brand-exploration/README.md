첫 추천은 탭루다. 실제 확장 아이콘은 16/32px에서도 선명하도록 접힌 모서리와 음영을 줄인 평면형으로 다듬고, 첫 화면에서만 부드러운 입체감과 눈 깜빡임/작은 기울임을 사용한다. 대기/작업/완료를 과도한 장식 없이 구별하며 모션 감소 설정을 유지한다. AI Pro, ChatGPT, FabriX 공식 로고는 연결 선택 영역에서만 사용한다.

공개 웹 검색은 짧은 중복 탐색으로만 수행했다. 동일 이름의 제품이 없다는 증거로 사용하지 않는다. 곁은 [동명 동행 서비스](https://winnersyun.github.io/)가 검색되었다. 초기 검토에서 제외한 모아루는 [Moaru AI-native fund](https://moaru.ai/), 누비는 [누비 월드](https://nubiworld.co.kr/) 등 AI 관련 사용례가 있었다.

## 시안

`browser-agent-concepts.png`는 내장 image_gen으로 생성한 비교 이미지다. 최종 SVG, 16/32px 픽셀 검증 또는 애니메이션 구현 산출물이 아니다. 생성 프롬프트와 밝은 배경 보정 프롬프트는 `prompts.md`에 기록했다.

시각 기준: `../agent-deck.css`, `../../docs/VISUAL-STANDARD.md`와 사용자가 제공한 HTML. 제품 코드는 변경하지 않았다.
