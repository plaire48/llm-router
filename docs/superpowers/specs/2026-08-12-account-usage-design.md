# 계정 사용량 패널 설계 — 개인 계정 전용

이 문서는 초기의 조직/Enterprise 관제 가정을 폐기하고 현재 요구사항을 기록한다.

- 사용자는 관리자 대시보드를 원하지 않으며, 사용량은 데스크톱 콘솔의 별도 대시보드 메뉴에서 본다.
- 브라우저로 로그인한 본인의 Claude 계정과 OpenAI 계정만 표시한다.
- Claude는 공식 Claude Code 로그인과 라우터의 로컬 사용량을 사용하고, OpenAI는 Codex app-server 계정 사용량을 읽는다.
- 일별 토큰은 OpenAI가 제공하는 계정 버킷과 llm-router의 로컬 호출 기록을 사용한다.
- Admin key, 조직 구성원 목록, 다른 사용자의 비용·토큰, 한도 변경 기능은 구현하지 않는다.

상세 화면·API 계약은 `2026-08-12-control-panel-design.md`를 따른다.
