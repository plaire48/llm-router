# Local Python document-authoring skills

1. Read this reference and the relevant task requirements. Prefer existing native tools for Office reads and writes.
2. Use prepare_python with requirementsPath pointing to this skill's references/python-requirements.json, or a JSON draft of exact package==version entries. Inspect the environment receipt. Missing Python and approved dependencies install locally through bundled uv into a Nubi-only venv. Never run shell/pip commands or modify system Python.
3. Read this skill's scripts/report.py example. Write or edit a draft/*.py file defining def transform(input) returning finite JSON. The script receives only explicit JSON input and must return at most 24000 characters. Use installed packages for data preparation. No Office/NASCA file paths, credentials, subprocesses, or direct Office automation. Code and input need a fresh user approval for each execution. Python has local user permissions: a venv is not an OS sandbox.
4. Call run_script with the .py path and exactly one of input (JSON string) or inputPath (workspace JSON). Read the receipt/resultPath, compare source values and repair errors before continuing. Installation/execution are visible tool steps, never document completion.
5. Keep prior accepted work. Missing modules: identify the actual PyPI distribution and exact version, prepare the revised requirements after approval, then request a new execution. Syntax/runtime errors: inspect the named error and line, read/edit the script, then execute the new code. Timeouts/termination can leave side effects; do not blindly replay.
6. Feed verified JSON to the existing guarded Excel/Word/PowerPoint authoring tools. Office owns original-file open/save and NASCA handling. Native fingerprint/readback, requirement review and final save HITL remain required. Python-generated external document files are not automatically imported or treated as verified Office artifacts.

Installation needs access to Astral Python downloads and PyPI. Only binary wheels are installed; source builds, URL/Git/editable dependencies and custom package indexes are unsupported. Corporate download failures must stay visible; never disable TLS validation.
