# Word 2016 authoring

Organize the requested document into a title, purpose, evidence, findings and next actions when appropriate to the user's task. Match existing styles rather than recreating the original layout.
Use append_paragraph and append_table only in an agent-created native draft. Existing template edits target observed editable items only. fill_field is limited to native-confirmed editable plain controls.
Do not replace complex fields, mapped controls, embedded objects or rich text using plain text operations. Unsupported requirements require a clear limitation or question.
Readback, source fingerprint validation, independent requirements review and final save approval determine completion. An in-memory script or its proposed result does not prove any native effect.
