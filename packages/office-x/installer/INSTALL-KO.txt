누비 Office X Beta 0.4.0

Excel, Word, PowerPoint 2016을 닫고 설치하세요.
설치 후 각 앱의 누비 Agent 탭에서 작업창을 여세요.
기존 누비 메뉴는 이전 추가 기능입니다. 새 누비 Agent 메뉴를 사용하세요.
사용할 모델에 로그인하면 같은 누비 채팅창에서 요청할 수 있습니다.

요청과 선택한 문서 내용은 연결한 모델 서비스로 전달됩니다.
변경 전후를 승인해야 적용하며, 파일 저장은 직접 합니다.

Excel: 선택한 표 읽기와 빈 셀의 곱셈 수식
Word: 문서 개요, 여러 문단 교정과 번역
PowerPoint: 발표 개요, 여러 텍스트 상자의 제목과 본문 수정
한 번에 문단 30개와 8,000자까지 수정합니다. 복잡한 서식은 읽기만 지원합니다.

관리자 권한과 Windows 10 이상이 필요합니다.
Node 런타임은 포함되어 있습니다. WebView2가 없으면 인터넷으로 설치합니다.
Claude는 별도의 Claude Code 로그인이 필요합니다.
Beta 설치 파일은 배포용 코드 서명이 없습니다.
실제 Office 2016 동작과 실제 모델 연결은 사용자 PC에서 확인해야 합니다.
