누비 Office X Beta 0.7.0

Excel, Word, PowerPoint를 닫고 설치하세요.
각 앱의 누비 Agent 탭에서 작업창을 열고 사용할 모델에 로그인하세요.
기존 누비 메뉴는 이전 추가 기능입니다. 새 누비 Agent 메뉴를 사용하세요.

필요한 내용을 읽고 문서에 직접 작성하거나 수정할 수 있습니다.
새 보고서, 발표자료, 통합문서 생성과 서식 작업을 요청하세요.
선택한 한 셀이나 editable=false는 문서 전체의 작업 제한이 아닙니다.
변경안을 확인하면 실제 Office에 적용하고 결과를 다시 읽습니다.
저장 또는 PDF 출력을 요청하면 Windows 저장 창에서 위치를 정합니다.
웹 검색, 이미지 생성, 발표자료 렌더링과 문서 복원을 지원합니다.
검색과 이미지 설정에서 이미지 서비스와 모델을 연결하세요.
복원은 전체 스냅샷을 새 창에 엽니다. 현재 문서는 유지됩니다.
복원 지점 목록은 현재 Office 작업창 세션에서 사용할 수 있습니다.

요청과 필요한 문서 내용은 연결한 모델 서비스로 전달됩니다.

Windows 10 이상, Office 2016, 관리자 권한이 필요합니다.
Node는 포함되어 있으며 WebView2가 없으면 인터넷으로 설치합니다.
Claude는 Claude Code 로그인이 필요합니다.
Beta 설치 파일은 배포용 코드 서명이 없습니다.
실제 Office 실행 검사는 설치 폴더의 Test-OfficeRuntime.ps1을 사용하세요.

GenOffice 편집기 전체
Windows x64에는 별도 편집기 6종을 함께 설치합니다. 시작 메뉴의 누비 GenOffice 또는 Office 작업창의 외부 편집기 버튼으로 여세요. 상단 누비 버튼에서 계정·모델·검색·이미지를 연결합니다. Office와 같은 암호화 계정 저장소를 사용합니다.
별도 편집기에 열리는 Office 스냅샷은 사본입니다. 현재 Office 창에 변경이 자동 반영되지는 않습니다. 현재 Office 문서 수정은 Office 작업창에서 요청하세요.
