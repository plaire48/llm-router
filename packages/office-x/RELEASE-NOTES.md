# Nubi Office X 0.7.0 Beta 1

Excel·Word·PowerPoint 추가 기능과 GenOffice 원본 편집기 6종을 하나의 Windows 설치 파일로 제공합니다.

- 별도 편집기: 문서, 시트, 슬라이드, PDF, HTML, Markdown. 원본의 도구·리본·변환·OCR·미디어·발표자료 생성·작업 복원·로컬 프로젝트·MCP·통합 설정 실행 경로를 포함합니다. 유료 서비스와 계정 기능은 해당 연결이 필요합니다.
- Office 작업창에서 별도 편집기를 열 수 있고, 시작 메뉴에서도 바로 실행할 수 있습니다.
- 별도 편집기의 누비 연결 화면에서 AI Pro, ChatGPT, FabriX, Claude를 연결하고 모델을 선택합니다. Office와 같은 DPAPI 연결 저장소를 사용합니다. 검색·이미지 설정도 공유하며, 누비 사용을 끄면 원본 서비스 설정을 사용합니다.
- 누비의 폰트 스택과 파란 포인트색을 편집기 UI에 적용합니다. 문서에 저장된 글꼴과 서식은 문서의 설정을 따릅니다.
- 모델 선택은 누비 워크플로우 폼의 CX로 통일했습니다. 계정과 모델을 선택한 뒤 적용하며, 검색·새로고침·로그인·연결 해제·키보드 선택을 지원합니다.
- Office Agent에도 원본 Word 편집기와 XLSX DSL의 작업 목록·읽기·파일 사본 편집 도구를 추가했습니다. 현재 Office 문서 수정과 별도 파일 사본의 편집 결과를 구분합니다.

원본 commit: 438d9c65709952490c970beaa2599ef45e74431f. 보존한 원본 4,582개 파일과 누비 88개 파일은 해시로 검사합니다. 별도 편집기에 필요한 수정은 준비 스크립트와 adaptations.json으로 기록합니다.

Windows 10 이상. Office 추가 기능은 Office 2016의 32·64비트를 지원합니다. 별도 편집기는 Windows x64에 포함합니다. 설치 파일은 서명되지 않은 Beta이며 실제 Office 2016의 COM·VSTO 창과 실제 LLM 계정은 이 빌드에서 검증하지 않았습니다. 원본 기능을 포함한 사실과 기능별 실환경 성공을 동일하게 취급하지 않습니다.
