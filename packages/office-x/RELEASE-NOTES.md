# Nubi Office X 0.8.0 Beta 1

Excel·Word·PowerPoint VSTO Agent 안에서 GenOffice 기능을 사용합니다. 별도 편집기를 설치하는 경로를 제거했습니다.

- 별도 GenOffice 실행 파일, 설치 구성요소, 시작 메뉴와 Agent 실행 도구 제거. 업그레이드 시 이전 편집기 설치 폴더와 바로가기 정리.
- 새 대화·대화 이력 UI 제외. 이미지 검색·생성·삽입·미디어 분석 도구와 연결 설정 제거. 발표자료 생성에서도 자동 이미지 검색을 사용하지 않음.
- GenOffice AgentLoop, Word/XLSX 원본 엔진, PPTX 생성·편집·레이아웃 검사, 웹 검색, PDF 변환, 문서 렌더링·복원 유지.
- 채팅창에서 작업 중에도 다음 요청을 입력 가능. 시작 오류 뒤 남는 작업 잠금 해제. 모델 창은 열어서 확인 가능하며 실행 중 모델 변경은 잠금 유지.
- 화면이 표시된 뒤 로딩 레이어 제거와 WebView 포커스 전달 보완. 호스트 연결 오류를 화면 렌더 오류와 분리.
- 모델·검색·연결·대상 선택·복원 폼에 누비 Workspace 폰트, 색감과 강조 사용.

Windows CI에서 설치·재설치·삭제, 이전 편집기 정리, 실제 WebView2의 마우스 클릭·키보드 입력, 네이티브 직렬화 및 화면 복구를 검사합니다. Office 2016 프로그램 내부와 실제 모델 계정의 작업 완료는 별도 실환경 확인이 필요합니다. 실제 문서의 새 파일 생성과 전체 스냅샷 복원은 대상 선택·승인을 거치는 Office 문서 작업입니다.

## 확인한 결과

Windows CI [38353145206](https://github.com/plaire48/llm-router/actions/runs/38353145206)가 통과했습니다. 설치된 UI에서 Excel·Word·PowerPoint 계약 3종, 실제 Windows 마우스 클릭·키보드 입력, 오류 후 화면 복구를 확인했습니다. 설치 9.10초, 재설치 5.28초, 삭제 1.57초는 Windows CI 측정값입니다. 이전 편집기 설치 폴더와 바로가기 정리도 검사했습니다.

설치 파일 124,568,322바이트(약125MB). 이전0.7.1의367,112,484바이트보다 약66% 줄었습니다. 실행 파일 SHA-256: `c9af984ff6c97d7c6fe5304871e48afc055ddcf577a07c933fb4508b6e1c2f7c`. 빌드와 배포 소스 기준 커밋은 `5cad64a878f50507265c0b05521d4370263e7078`입니다. 소스 ZIP의 GenOffice4,582개·누비88개 파일 해시와 별도 편집기 제품 파일 제외를 재확인했습니다.

CI에는 Office 프로그램과 실제 모델 계정이 없습니다. 설치·WebView2·네이티브 호출 검사 결과를 Office2016 내부의 문서 수정 성공으로 해석하지 않습니다.
