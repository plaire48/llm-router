# Nubi Office X 0.8.2 Beta 1

Excel 작성 경로에 남아 있던 타입 라이브러리 기반 호출을 직접 IDispatch 호출로 변경했습니다. 새 통합문서와 워크시트 생성, 셀 값 입력과 읽기 확인, 변경 전 복원용 사본, 파일 열기와 저장에 적용됩니다. 큰 정수 입력에서 발생하던 32비트 변환 오류도 수정했습니다.

실행 오류는 실패한 멤버, HRESULT와 단계가 유지되며 문서 데이터나 예외 원문을 포함하지 않습니다. 새 대화·히스토리·이미지 도구와 별도 GenOffice 편집기는 포함되지 않습니다.

Windows COM 재현 검사는 타입 라이브러리가 고장 난 Excel 모양의 네이티브 객체로 기존 호출 실패와 수정 후 셀 값 읽기를 확인합니다. 실제 설치된 Office 2016 및 로그인한 모델을 통한 작성 결과는 별도 검증 대상입니다.

Office 앱을 모두 종료하고 EXE를 실행하세요.
