세 앱에서 같은 누비 Agent를 여는 0.4.0 Beta입니다. 이전 `누비 / Nubi` 메뉴와 새 GenOffice 추가 기능을 혼동하던 문제를 줄이기 위해 Excel, Word, PowerPoint의 리본과 작업창 이름을 **누비 Agent**로 통일했습니다.

## 설치와 실행

`Nubi-Office-X-0.4.0-Setup.exe`를 실행한 뒤 **누비 Agent → 누비 Agent 열기**를 선택하세요. 설치 전에 Office 앱을 닫아 주세요.

- Office X 0.3.0을 같은 설치 경로에서 업데이트합니다.
- 기존 `누비 / Nubi` 메뉴는 이전 추가 기능입니다. 새 버전은 **누비 Agent** 메뉴를 사용하세요.
- Node 포함 단일 EXE. Windows 10 이상, Office 2016, 관리자 권한이 필요합니다. WebView2가 없으면 인터넷으로 설치합니다.
- Beta EXE에는 배포용 코드 서명이 없습니다. VSTO manifest는 미리보기 서명입니다.

## 같은 화면과 확장한 기능

Excel의 누비 폰트, 글자 크기, 굵기, 색감, Claude 모델 선택, 채팅 입력창을 세 앱에서 함께 사용합니다. 세 앱의 새 리본에는 같은 누비 새 아이콘을 사용합니다. 로그인 도움말과 연결 설정 버튼의 설명에서 앱과 버전을 확인할 수 있습니다.

- Word: 여러 문단 다듬기, 맞춤법 교정, 번역, 문서 개요 요약
- PowerPoint: 여러 텍스트 상자의 제목과 본문 수정, 발표 흐름 점검, 채팅에서 발표 대본 초안
- Excel: 셀 하나만 선택해도 주변 표와 같은 시트의 다른 범위를 읽을 수 있습니다. 선택 범위는 수정 대상으로만 사용하며, 주변에서 읽은 숫자를 이용해 선택한 빈 셀에 곱셈 수식을 적용할 수 있습니다.
- 문단별 변경 전후를 한 번에 승인하고, 원문과 서식 및 변경하지 않은 문단까지 다시 확인합니다. 부분 실패를 자동 재실행하지 않으며 자동 저장하지 않습니다.

문단 수정은 한 번에 최대 30개, 8,000자입니다. 문단 경계는 유지합니다. 복잡하거나 혼합된 서식과 자동 크기 텍스트 상자는 읽기만 지원할 수 있습니다. Word 개요는 최대 200문단, 발표 개요는 최대 60슬라이드 및 총 12,000자이며 일부만 읽으면 이를 표시합니다. 문서/슬라이드 생성은 이번 범위에 포함하지 않습니다.

## 검증 범위

Excel을 기준으로 Word/PowerPoint의 화면 속성 77개를 12개 브라우저 조건에서 비교했습니다. 기존 Excel 14개 흐름과 두 앱의 다중 문단 승인 화면, 문서 실행기 49개 및 Agent 연결 22개 테스트를 확인했습니다. 브라우저와 문서 테스트는 모의 환경입니다.

Windows 빌드와 설치 검사의 실제 결과는 첨부 `installer-build.json`, `install-smoke.json`을 확인하세요. 실제 Office 2016 내부 실행과 실제 모델 계정은 아직 검증되지 않았습니다.
