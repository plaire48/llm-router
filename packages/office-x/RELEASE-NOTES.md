누비 Agent Office 0.5.0 Beta입니다. 문서 작업을 선택 영역과 단순 문장 교체에 가두던 구조를 확장했습니다.

## 달라진 점

- 선택한 한 셀이나 `editable=false`를 이유로 문서 전체 작업을 거절하지 않습니다. 문서 전체의 Office 개체를 읽고 수정하는 도구를 추가했습니다.
- Excel: 기존 값과 일반 수식, 여러 시트, 표, 서식, 차트와 피벗을 Office 개체 모델로 조작하는 실행 경로를 제공합니다.
- Word: 혼합 서식과 빈 문단의 문장 교체를 허용하며, 표·제목·목록·머리말·꼬리말·주석·변경 추적·페이지 설정은 공통 Office 도구로 처리합니다.
- PowerPoint: 자동 크기 텍스트 상자와 혼합 서식의 문장 교체를 허용하며, 다른 슬라이드 읽기, 슬라이드·텍스트·도형·표·서식 작업은 공통 Office 도구로 처리합니다.
- 실제 새 Word 문서, PowerPoint 발표자료, Excel 통합문서를 만듭니다. 새 문서에 대한 후속 읽기와 수정도 연결했습니다.
- 성공한 수정 뒤에 계속 작업할 수 있습니다. 수정 전에 읽은 값을 다시 검사하고 변경 후 결과를 재조회합니다.
- 요청 시 Office 저장 또는 PDF 내보내기를 수행합니다. 저장 위치는 Windows 저장 창에서 정합니다.
- GenOffice 원본 Agent 엔진을 유지하고, 원본 시트·슬라이드 가이드 14개를 추가했습니다. 누비 Workspace의 로그인, Claude, 폰트와 색감을 세 앱에서 공유합니다.

## 설치

Office 앱을 닫고 `Nubi-Office-X-0.5.0-Setup.exe`를 실행하세요. 기존 Office X 설치를 업데이트합니다. 각 앱의 **누비 Agent → 누비 Agent 열기**를 사용하세요. 이전 `누비 / Nubi` 메뉴는 별도 추가 기능입니다.

Node 포함 단일 EXE입니다. Windows 10 이상, Office 2016, 관리자 권한이 필요합니다. WebView2가 없으면 인터넷으로 설치합니다. Beta EXE는 배포용 코드 서명이 없으며 VSTO manifest는 미리보기 서명입니다.

## 검증 범위

실행기 64개, Agent·UI 관련 단위 테스트 45개가 통과했습니다. 새 생성·수정 화면 6개, 기존 채팅 14개, Word/PowerPoint 문단 변경 2개 흐름을 브라우저 모의 호스트에서 확인했습니다. 세 앱의 공통 화면 스타일은 12개 조건에서 77개 속성이 일치합니다.

Windows 빌드·설치 결과는 첨부 `installer-build.json`, `install-smoke.json`에 기록합니다. 실제 Office 2016 COM 실행과 실제 모델 계정은 이 빌드 환경에서 검증하지 못했습니다. 설치 폴더의 `Test-OfficeRuntime.ps1`은 Office가 설치된 PC에서 새 임시 문서를 만들어 실제 실행기를 검사합니다.

이 릴리스는 문서 조작 범위를 확장한 버전이며 **GenOffice 전체 제품과의 기능 동등성 검증 완료를 뜻하지 않습니다.** GenOffice 전용 웹 검색·이미지 생성·PDF 변환·별도 편집기 렌더링 및 전체 문서 롤백은 아직 연결되지 않았습니다. 문서 작업 범위, 원본 기능 대응과 검증 경계는 소스의 `docs/genoffice-capabilities.md`에 명시했습니다.
