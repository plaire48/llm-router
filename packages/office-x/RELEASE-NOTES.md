# Nubi Office X 0.8.14 Beta 1

문서 변경 결과가 불확실하면 작업을 종료하지 않고, 채팅 안에서 사용자 확인을 기다립니다.

- 현재 문서를 다시 읽고 ‘현재 상태에서 이어가기 / 다시 확인 / 여기서 마치기’를 표시합니다. Office와 Agent가 열려 있는 동안 확인 대기에 시간 제한을 두지 않습니다.
- 이어가기 전에 문서와 내용을 재확인합니다. 대기 중 내용이 달라지면 다시 확인받습니다. 이전 변경안과 예약된 호출은 재실행하지 않고 남은 작업의 새 변경안을 확인받습니다.
- Excel의 쓰기 차단도 사용자 확인 후 정상적으로 재개합니다. Word·PowerPoint는 기존 선택 영역을 다시 잡지 않고 연결된 문서 작업으로 이어갑니다.
- 복원 사본·원시 오류·이전 검증 정보는 ‘작업 상세’로 모았습니다. 확인 중에는 중복 경고 대신 카드 하나만 표시합니다. 복원 사본 없이 적용할 때의 사전 안내는 유지합니다.

GenOffice 기반을 유지하며 외부 실행 프레임워크는 추가하지 않았습니다. Office 종료·프로세스 장애 이후 재개는 지원하지 않습니다. 실제 Office 2016 및 실계정 Claude/ChatGPT 환경은 연결되지 않아 직접 검증하지 못했습니다.

Windows 빌드 및 32·64비트 COM 회귀 검증을 통과했습니다. 코어 135개 테스트, 실제 Windows WebView2 클릭·입력, 설치 9.00초·재설치 6.36초·제거 1.43초, 설치된 변환 런타임 검증을 확인했습니다. HITL 버튼과 대기·재개는 별도의 모의 Office/브라우저 테스트로 검증했습니다.
