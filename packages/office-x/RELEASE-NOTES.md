# Nubi Office X 0.8.17 Beta 1

열린 Office 문서의 양식을 먼저 읽고 편집하도록 연결하고, 권한 선택과 채팅 화면을 간소화했습니다.

- Excel 빈칸·수식·병합·숫자 서식, Word 문단·표 셀과 서식, PowerPoint 빈 텍스트 상자·위치를 읽는 `read_template`을 추가했습니다. 실제 Office 관찰 ID와 대상 핸들을 사용하며 범위를 나눠 읽습니다. 이 양식 지도는 전체 복원 사본이 아니며 SaveCopyAs를 호출하지 않습니다.
- GenOffice 가이드를 로드할 때 Windows Office 2016의 실행 계약을 함께 제공합니다. 편집기 ID·픽셀 좌표·전용 스크립트를 COM 멤버로 전달하지 않도록 실제 Office 도구와 단위를 명시했습니다.
- Word·PowerPoint 콘텐츠 가져오기의 백업을 승인 전에 준비하고 결과를 전달합니다. 승인 뒤 같은 백업을 다시 시도하며 중단되던 경로를 수정했습니다. 지원되지 않는 가져오기 멤버는 기존 내용을 지우기 전에 검사합니다.
- 파일 엔진으로 보내는 문서 복사는 한 번만 수행하고 그 사본에서 원본 상태를 계산합니다. 불필요한 두 번째 SaveCopyAs를 제거했습니다.
- 하단 토큰 수와 `% 남음`을 제거하고 `자동 승인 / 매번 확인 / 읽기 전용` 권한 선택을 유지했습니다. 상세 사용량은 원형 사용량 버튼에서 확인합니다.
- Agent 표시는 마스코트로 통일하고 적용·저장 결과와 보조 작업을 아이콘 중심으로 줄였습니다. 대화와 입력창, 불확실한 결과 표시는 유지합니다.

실제 Windows Office 2016과 Windows 실계정 Claude/ChatGPT는 연결 가능한 PC가 없어 직접 검증하지 못했습니다. 모든 SaveCopyAs 실패가 해결됐다고 주장하지 않습니다. 양식 읽기와 복원 백업을 구분하고, 백업 실패가 실제 편집 실패로 잘못 전파되는 경로를 수정했습니다.

Windows 검사 182개, 코어 검사 141개, 32·64비트 COM 모의 객체 검사를 통과했습니다. 설치된 실제 WinForms WebView2 화면에서 세 앱의 입력·승인, 권한 전환 6회, 토큰 하단 표시 제거와 화면 복구를 확인했습니다. 설치 8.06초, 재설치 6.43초, 제거 1.61초였으며 설치된 문서 변환·한국어 OCR도 통과했습니다.
