# Nubi Office X 0.8.11 Beta 1

Excel, Word, PowerPoint의 VSTO Agent에 Workspace 추론 설정과 문맥 사용량·대화 요약·오류 복구 흐름을 연결했습니다.

- 웹 검색 설정, 검색·페이지 수집 도구와 서비스 실행을 제거했습니다.
- 사용한 토큰 수, 남은 문맥 비율, 실측/추정 구분을 표시합니다. 이는 모델 문맥 한도이며 계정 이용 한도가 아닙니다.
- 수동 요약과 Workspace 정책의 자동 요약을 연결했습니다. 화면의 대화와 최근 요청은 유지하며 요약 실패·취소 시 원래 문맥을 보존합니다.
- 같은 문서에서 선택 범위나 시트를 바꿔도 요청 문맥을 유지합니다.
- 지원 멤버·가이드·재조회로 작업 방법을 조정합니다. 반복 오류가 해결되지 않으면 확인된 변경과 남은 작업을 정리하고 이어서 요청할 수 있습니다.
- 모델 응답 오류는 한 번 복구하며 확인된 쓰기를 반복하지 않습니다. 불확실한 쓰기는 실제 값 확인 없이 재실행하지 않습니다.
- 입력창 하단의 모델·추론은 왼쪽, 문맥·보내기는 오른쪽에 배치하고 토큰 정보는 별도 줄에 표시합니다.
- 승인과 오류 안내를 채팅 흐름에 넣어 입력창이 답변을 덮지 않도록 했습니다. 입력창 크기가 바뀌어도 최신 답변을 따라가며 이전 답변을 읽는 중에는 위치를 유지합니다.
- 모델 선택은 연결 계정 한 줄과 모델 목록을 먼저 보여 줍니다. 계정 선택은 변경할 때 펼치며 긴 모델 이름·문맥 정보·하단 버튼이 겹치지 않도록 합니다.
- 원시 오류 상세는 펼쳐 볼 수 있습니다. 요약 모달의 큰 숫자와 긴 상세 값도 정상 줄바꿈됩니다.

원본 GenOffice AgentLoop와 DOCX/XLSX/PPTX 엔진, 발표자료 생성·고급 편집·렌더링·문서 변환·복원 경로를 유지합니다. 사용자가 제외한 새 대화, 이력, 이미지, 별도 편집기는 추가하지 않았습니다.

검증: 소스/타입 검사, 실제 worker 프로세스의 사용량·수동 요약·후속 대화 검사, 세 앱 공통 모의 WebView의 요약/취소/복구와 36개 모달 상태, 긴 답변·표·코드·초안·승인 카드의 9개 화면 상태를 검사했습니다. Windows 빌드·설치 결과는 릴리즈 증빙에 기록합니다.

실제 Windows Office 2016 환경과 사용자 계정의 Claude/ChatGPT 연결은 접근 가능한 기기가 없어 확인하지 못했습니다. 모의 COM과 설치된 WebView2 검사를 실제 Office 실사용 증빙으로 제시하지 않습니다.

[Windows 빌드와 검사](https://github.com/plaire48/llm-router/actions/runs/38437718492) 통과: 소스 138개, 코어 132개, x86/x64 COM 모의 검사, 설치된 세 앱 채팅창 클릭/입력 검사. Office가 없는 Windows VM에서 설치 9.76초, 재설치 5.52초입니다. 실제 Office 내부 실사용 증빙은 아닙니다.
