# Nubi Office X 0.8.15 Beta 1

새 문서 창에서도 연결한 모델을 유지하고, 토큰 표시 옆에서 편집 권한을 선택할 수 있습니다.

- Excel·Word·PowerPoint의 여러 창이 같은 앱 프로세스 안에서 하나의 로그인 연결을 사용합니다. 창을 추가하거나 문서 작성이 끝나도 모델·추론 설정·Agent 대화 저장소가 초기화되지 않습니다. 마지막 창을 닫거나 Office를 종료하면 연결은 종료되며, 다음 실행의 로그인은 사용자가 시작합니다.
- 모델·계정·문서 대상 폼을 iOS 스타일로 간소화했습니다. 설정·복원·새로고침은 아이콘으로, 선택된 항목과 적용 버튼만 강조색으로 표시합니다. 좁은 화면의 글자 겹침·가로 넘침과 키보드 이동을 확인했습니다.
- 토큰 표시 옆에 읽기 전용 / 매번 확인 / 자동 적용 목록을 추가했습니다. 자동 적용은 일반 편집마다 확인을 반복하지 않습니다. 문서 재읽기와 결과 검증은 유지하고, 복원·외부 파일 덮어쓰기·불확실한 변경 결과는 별도 확인합니다. 권한은 현재 앱 세션에서 유지되며 기본값은 매번 확인입니다.
- 여러 창의 작업 대상은 분리하고 동시에 실행하지 않습니다. 실행 중인 창을 닫으면 그 작업을 취소하고 다른 창의 로그인 연결은 유지합니다.
- Word·PowerPoint가 편집 가이드만 읽고 끝내면 실제 문서 읽기·편집·검증을 이어가는 보정 단계를 추가했습니다. 재개는 한 번으로 제한하고, 읽기 전용·설명 요청·취소·이미 시도한 변경에는 적용하지 않습니다.
- PowerPoint·Word 창 핸들 조회에서 Office 전용 COM 인터페이스 캐스팅을 제거했습니다. Office 2016 호환 PIA의 HWND 식별자로 기본 IDispatch를 호출하며, 원본 창·문서 일치 검사는 유지합니다.

GenOffice 원본 기반과 기존 Nubi UI 구성요소를 유지합니다. 실제 Office 2016 및 실계정 Claude/ChatGPT를 실행할 Windows PC에는 연결되지 않아 직접 검증하지 못했습니다. 자동 테스트·COM 모의 객체·설치 검증은 실제 Office 사용 검증과 구분합니다.
