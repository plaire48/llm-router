# Nubi Office X 0.8.5 Beta 1

일반 셀 입력을 `write_cells` 도구로 연결하고 `set_formula`의 곱셈·빈 셀·선택 범위 제한을 제거했습니다. 문자열·숫자·참/거짓·빈 값과 SUM/IF 등 Excel 2016 수식을 지원합니다. 문자열은 =로 시작해도 문자로 보존하며 기존 표시 형식을 복원합니다. 승인 전 대상 셀을 읽고 변경 직전 비교한 뒤 값·수식 여부·서식을 다시 확인합니다. 확인되지 않은 쓰기는 재실행하지 않습니다. 수식 입력 확인과 계산 결과 정확성은 별도입니다.

명시적 체크포인트 도구가 SaveCopyAs 0x800A03EC를 반복 작업 실패로 처리하던 경로를 수정했습니다. 사본 없음 경고를 반환하고 동일 문서·동일 실행에서 실패한 사본 호출을 반복하지 않습니다. 셀 입력·일반 Office 변경과 문장 변경은 승인 화면에서 **복원 사본 없이 적용**을 선택한 경우에만 계속합니다. 전체 백업이 필요한 파일 변환·사본 내보내기는 여전히 실패를 정확히 보고합니다. 사용자의 실제 Office가 SaveCopyAs를 거부하는 근본 원인은 미확인입니다.

현재 문서 대상으로 새 문서 도구가 호출되면 작성 위치를 선택할 수 있습니다. 새 문서 생성 후 Agent의 문서 식별자와 대상을 갱신하여 이후 셀 입력·일반 변경·저장은 생성된 문서로 이어집니다. 현재 문서를 선택하면 셀 입력 또는 일반 변경 도구로 안내합니다.

연결 버튼 오류는 네트워크·인증서·인증·Claude CLI 오류를 구분합니다. 임시 네트워크 장애의 모델 목록 조회만 한 번 재시도하고, 보관한 연결을 복원할 때 임시 실패로 새 로그인을 시작하지 않습니다. 자동 로그인은 하지 않습니다. 모델 폼의 자동 목록 갱신 실패는 기존 연결과 목록을 유지하며 폼 안에 표시합니다.

Office 앱을 모두 종료한 뒤 EXE를 실행하세요. 별도 편집기·새 대화/히스토리·이미지 기능은 포함하지 않습니다. 실제 사용자 Windows Office 2016 및 Windows Claude/ChatGPT 계정에는 접근할 수 없어 직접 검증하지 못했습니다. 검사 범위와 설치 파일 해시는 첨부 검증 자료를 참고하세요.
