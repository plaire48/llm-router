# Nubi Office X 0.8.1 Beta 1

문서 도구 오류가 이어지는 실행 흐름을 보완했습니다. 실제 사용자 PC의 오류 원인은 해당 오류 정보로 별도 확인해야 합니다.

- Item, Range 등 읽기 호출을 문서 수정으로 집계하던 오류를 수정했습니다. 읽기만 수행한 뒤 멤버 조회가 실패하면 완료한 쓰기를 0으로 보고하고 새 관측값으로 계획을 고칠 수 있습니다.
- UI 동기화 컨텍스트가 없는 동기 실행에서 Task.Yield가 COM 호출을 다른 스레드로 넘기던 오류를 수정했습니다. VSTO 메시지와 승인 후 실행은 Windows Forms UI 컨텍스트를 유지합니다.
- 읽기 전용 Item/Range 호출은 속성 조회와 메서드의 차이를 처리합니다. 수정 호출은 자동 재실행하지 않습니다.
- 같은 네이티브 오류가 세 번 반복되면 Agent를 중단합니다. 중간에 안내를 읽어도 동일한 실패를 무한 재시도하지 않습니다. 확인된 문서 변경은 별도로 유지합니다.
- 채팅의 실행 오류 정보에서 실패 도구, 멤버, 코드, 버전과 진단 ID를 복사할 수 있습니다. 정상 반환 형태의 실패도 로컬 진단 로그에 기록합니다.
- 별도 GenOffice 편집기, 새 대화, 히스토리, 이미지 기능 제외는 유지합니다.

기존 코드에서 실패하던 두 회귀를 재현했고 수정 후 네이티브 계약 76개가 통과했습니다. Windows 검사는 실제 IDispatch, STA 호출, 설치된 WebView2 마우스 클릭과 키보드 입력을 포함합니다. CI에는 Office 프로그램과 실제 모델 계정이 없으므로 사용자 Office 2016의 요청 성공으로 해석하지 않습니다.
