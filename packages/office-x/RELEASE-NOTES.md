# Nubi Office X 0.8.10 Beta 1

누비 Workspace의 현재 공통 모달·질문 폼 구현을 기준으로 Excel, Word, PowerPoint의 모델 선택, 웹 검색 연결, FabriX 연결, 문서 대상 선택, 복원 화면을 통일했습니다.

- Workspace 폰트 체인, 본문 15px·제목 18px·보조 14px, 글자 굵기 400/500/600과 공통 간격·모서리·면 색상 토큰을 사용합니다.
- 제목과 선택 상태, 적용·저장·연결 버튼에 파란 포인트를 모으고 미선택 항목과 보조 동작의 강조를 줄였습니다.
- 모델 번호를 선택 표시로 바꾸고 긴 이름과 문맥 정보를 두 줄로 읽을 수 있게 했습니다.
- 검색과 FabriX 설정 버튼을 공통 하단에 배치했습니다. 짧은 창에서도 내용만 스크롤하고 주요 동작에 접근할 수 있습니다.
- 모달 CSS 충돌로 주요 버튼이 보조 버튼처럼 표시되던 문제와 280px 창의 문서 대상 설명 잘림을 수정했습니다.
- 모델 선택은 적용 버튼을 누를 때 반영합니다. 계정 연결은 직접 눌러 시작하고 연결 중에는 폼 닫기를 막습니다.

GenOffice 문서 도구와 VSTO 실행 구조를 유지합니다. 사용자가 제외한 별도 편집기, 대화 이력, 새 대화, 이미지 기능은 추가하지 않았습니다.

검증 범위: 현재 Workspace CSS 참조와 공통 모달 스타일 비교, 세 앱의 5종 모달과 280/320/420px 폭 및 짧은 창, 키보드 이동·포커스 복귀, 모델 선택 지연 적용, 검색/FabriX 하단 폼 제출, 연결 중 닫기 방지를 모의 WebView 호스트에서 검사했습니다. 소스 테스트와 Windows 빌드·설치 검증 결과는 릴리즈 증빙에 기록합니다.

실제 Windows Office 2016 환경에 접근할 수 없어 VSTO 안의 실사용과 사용자 계정의 Claude/ChatGPT 연결은 확인하지 못했습니다. 이 릴리즈는 해당 검증을 완료했다고 주장하지 않습니다.

[Windows 빌드와 검사](https://github.com/plaire48/llm-router/actions/runs/38425932270) 통과: 소스 127개, 코어 132개, x86/x64 COM 모의 검사, 설치된 세 앱 채팅창 클릭/입력 검사. Office가 없는 Windows VM에서 설치 8.06초, 재설치 5.3초입니다. 실제 Office 내부 실사용 증빙은 아닙니다.
