# Nubi Office X 0.8.4 Beta 1

Excel 작성 도구가 줄바꿈·탭이 있는 셀과 행마다 열 수가 다른 표를 document_content_invalid로 거절하던 검증을 수정했습니다. 짧은 행은 가장 긴 행에 맞춰 빈 뒷칸만 채웁니다. 입력 내용을 자르거나 바꾸지 않으며, 승인 화면과 실제 읽기 검증은 같은 정규화된 표를 사용합니다.

잘못된 시트 이름·중복 이름·범위 제한·지원하지 않는 문자는 변경 전에 정확한 위치와 사유를 반환합니다. 모델은 그 정보를 이용해 작성안을 수정할 수 있고 채팅에도 사유가 표시됩니다. Word 표의 안내 스키마를 네이티브 제한에 맞췄습니다.

수정 전 복원 사본의 중복 SaveCopyAs 호출을 제거했습니다. Office가 SaveCopyAs를 거부한 경우 기존 승인 화면에 사본 없음 안내와 **복원 사본 없이 적용** 버튼을 표시합니다. 선택하면 기존 원본 비교와 실제 입력 결과 읽기 검증을 거쳐 작업합니다. 그 변경의 전체 문서 롤백을 지원한다고 표시하지 않습니다. 정상 사본 생성과 암호화 복원 기능은 유지합니다. Office가 사본 생성을 거부하는 사용자 환경의 근본 원인은 아직 직접 확인하지 못했습니다.

상단 초록색 누비 Agent 문구를 제거했습니다. 누비 아이콘과 모델·복원 버튼, 리본 탭은 유지합니다. 자동 로그인 제거, GenOffice 문서 기능, 누비 Workspace 모델 선택과 Claude 연결은 기존대로 유지하며 별도 편집기·히스토리·이미지 기능은 포함하지 않습니다.

Office 앱을 모두 종료한 뒤 EXE를 실행하세요. Windows 빌드·설치, COM 테스트 객체 및 WebView2 입력 검사는 실제 사용자 Office 2016 문서 작성이나 Windows Claude/ChatGPT 로그인을 대신하지 않습니다. 해당 실제 환경에는 접근할 수 없어 확인하지 못했습니다.
