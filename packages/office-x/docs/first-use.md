# 첫 실행

1. Excel, Word, PowerPoint를 닫고 `Nubi-Office-X-0.4.0-Setup.exe`를 실행한다.
2. 설치할 앱을 선택하고 설치한다. Node는 별도 설치하지 않는다.
3. 앱을 열고 **누비 Agent → 누비 Agent 열기**를 누른다.
4. 사용할 모델에 로그인하고 문서에서 작업할 부분을 선택한다.

| 앱 | 첫 요청 | 확인할 결과 |
| --- | --- | --- |
| Excel | 수량과 단가를 곱해서 빈 금액 열을 채워줘 | 승인한 빈 셀만 변경, 수식과 계산값 확인 |
| Word | 선택한 문장을 간결하게 다듬어줘 | 변경 전후 승인, 선택한 문장만 변경 |
| PowerPoint | 선택한 텍스트 상자를 짧게 다듬어줘 | 변경 전후 승인, 해당 상자의 텍스트만 변경 |

기존 누비 메뉴는 이전 추가 기능이다. 새 버전은 누비 Agent 메뉴로 연다.

Word와 PowerPoint는 선택한 내용이나 문서 전체의 개체를 읽고 수정할 수 있다. 새 문서를 만들 때 선택 영역은 필요 없다. 혼합 서식·표·자동 크기 상자는 공통 Office 개체 도구로 다루며 문서 자체의 보호·잠금은 실제 Office 상태를 따른다.

Excel은 셀 하나만 선택하고 “주변 표를 요약해줘”라고 요청할 수 있다. 필요한 범위는 같은 시트에서 나눠 읽으며, 수정할 셀만 원래 선택 범위 안에 있어야 한다.

먼저 사본에서 확인한다. 승인 대기 중 원문을 바꾸면 적용을 중단해야 한다. 적용 안 함과 중지도 확인한다. 결과가 맞으면 Office의 저장 명령을 사용하고 다시 열어 확인한다.

Claude는 Windows 터미널에서 `claude --version`이 실행되는 설치를 자동으로 탐지한다. 공식 설치, npm 설치, 사용자 지정 npm 경로, PowerShell 스크립트·별칭·프로필 함수 경로를 확인하고 실행 가능한 후보를 사용한다. Office가 열린 뒤 설치했다면 연결할 때 현재 사용자 PATH도 다시 확인한다. 설치 방식을 바꾸거나 npm 설치를 다시 할 필요는 없다. 채팅창의 Claude 연결이 CLI 인증을 시작한다. CLI 버전이 오래되어 필요한 기능이 없으면 업데이트 안내가 나오며, 로그인 상태는 별도로 확인한다. 설치/로그인 성공, 실제 모델 답변, Office 문서 변경은 각각 확인한다.

추가 기능이 보이지 않으면 Office의 COM 추가 기능 목록과 로드 오류를 확인한다. 채팅창이 비어 있으면 WebView2 설치 상태를 확인한다. 작업창의 모델 없이 도구 확인은 Word와 PowerPoint에서 선택 텍스트를 읽기만 한다.

현재 자동화 검사는 실제 Office가 없는 Windows 빌드 환경과 모의 문서/모델을 포함한다. 실제 Office 2016 동작을 검증한 것으로 간주하지 않는다.
