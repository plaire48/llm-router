# Excel 첫 구현 및 검증 계획

상태: 첫 VSTO·GenOffice 연결 소스 구현. 공통 로직과 모의 연결 검증은 [구현 결과](implementation-status.md)에 기록했다. 아래 Windows·NASCA 실환경 시나리오는 아직 미실행이다.

대상 환경: Office 2016 · Windows. Excel부터 시작하며 누비 Workspace와 A2A로 작업을 연결하는 방향이다.

## 목표 시나리오

사용자가 `내역` 시트의 C1:E4를 선택하고 “수량과 단가를 곱해서 금액 열을 채워줘”라고 요청한다.

| 행 | C: 수량 | D: 단가 | E: 금액 |
| --- | --- | --- | --- |
| 2 | 2 | 1500 | 비어 있음 |
| 3 | 3 | 2000 | 비어 있음 |
| 4 | 0 | 500 | 비어 있음 |

완료 조건: E2:E4에 각각 `=C2*D2`, `=C3*D3`, `=C4*D4`가 들어가고 결과가 3000, 6000, 0이다. 대상 이외의 셀은 수정하지 않으며 저장 후 재개방해도 수식과 값이 유지된다.

## 구현 순서

| 단계 | 산출물 | 통과 기준 |
| --- | --- | --- |
| 1. 환경과 호스트 | Windows VSTO 솔루션, 리본, 작업창 | 사용자가 연 Excel에서 추가 기능이 로드되고 창이 열린다 |
| 2. 읽기 | read_selection, read_range, 문서 세션 식별 | 지정한 문서의 값·수식·주소를 정확히 읽고 대상 전환을 구분한다 |
| 3. 적용과 검증 | 결정된 수정 명령, 사전조건 검사, set_formula, calculate_and_read | 예제 수식과 기대값을 실제 Excel에서 재확인한다 |
| 4. 보호 문서 | 허용된 NASCA 테스트 문서, 수동 저장·재개방 기록 | 읽기·수정·저장·재개방 각각의 실제 결과를 기록한다 |
| 5. Agent 연결 | 모델 provider, 도구 호출 루프, 변경안·진행·결과 UI | 자연어 요청으로 동일 시나리오를 완료하고 도구 결과를 근거로 보고한다 |
| 6. 누비 연결 | 기존 A2A 계약 검토, 작업 수신·진행·취소·결과 전달 | Workspace에서 위임한 요청이 같은 Office 실행·검증 경로로 완료된다 |
| 7. 확장 | 값·서식 도구, 더 큰 범위, 앱별 어댑터 | 기존 성공·충돌·부분 실패 검증을 유지한다 |

모델 없이 고정 명령으로 단계 3까지 먼저 확인한다. NASCA와 모델 전달 조건을 확인한 뒤 실제 문서에 모델을 연결한다. 합성 데이터로 하는 Agent 개발은 병행할 수 있다.

## 실행 상태

`요청 → 맥락 읽기 → 계획 → 변경안 확인 → 사전조건 재검사 → 적용 → 계산·재조회 → 완료`

변경안에는 대상 문서·시트·범위, 덮어쓰기 여부, 적용할 수식이 보인다. 첫 PoC는 적용 버튼으로 실행한다. 충돌 시 새 상태로 다시 계획하고, 부분 실패 시 실제 적용된 셀과 미실행 셀을 표시한다. Agent 반복 횟수와 시간에 상한을 두며 상한 도달을 완료로 표현하지 않는다.

## 필수 검증

| 검증 상황 | 기대 동작 |
| --- | --- |
| 기본 예제 | 수식 3개와 계산값이 일치한다 |
| 모델 대기 중 다른 통합문서로 이동 | 원래 문서만 대상으로 유지한다 |
| 입력 C2 또는 대상 E2를 사용자가 수정 | 기존 계획을 충돌로 처리하고 덮어쓰지 않는다 |
| 대상 문서를 닫거나 시트를 삭제 | 실행 전 대상 없음으로 중단한다 |
| 보호된 셀, 병합 영역, 여러 선택 영역 | 미지원 또는 편집 불가 사유를 표시한다 |
| 적용 도중 실패 또는 취소 | 셀별 적용 내역을 보존하고 전체 성공으로 표시하지 않는다 |
| 같은 실행 명령이 재전달 | 중복 적용하지 않는다 |
| A2A 결과 전달 중 연결 끊김 | 같은 작업 ID로 상태를 조회하며 문서 수정을 재실행하지 않는다 |
| 누비에서 위임한 작업 | 대상 문서와 실행 ID가 연결되고 실제 재조회 증거가 반환된다 |
| 계산 오류 또는 계산 미완료 | 적용 성공과 검증 실패·대기를 구분한다 |
| 실제 모델 통신 중 Office 조작 | 작업창과 Excel이 응답하고 취소할 수 있다 |
| 저장 후 Excel을 닫고 재개방 | 수식·값·관련 문서 상태 유지 여부를 확인한다 |

## 검증 기록 양식

각 실행은 OS·Office 빌드와 비트수, 추가 기능 빌드, NASCA 환경 식별, 시나리오, 전후 수식·값, 적용·검증·저장 결과를 기록한다. 보호 문서의 원문은 일반 로그에 남기지 않는다.

결과는 `미실행 / 통과 / 실패 / 환경 차단`으로 기록한다. 공통 로직 테스트, Windows 빌드 성공, 실제 Excel 동작, NASCA 보호 문서 동작, 실제 모델 연결은 서로 다른 증거다.

현재 작업 환경은 macOS다. 여기서는 계약·공통 로직·문서를 준비할 수 있지만, 이 계획의 VSTO 로드와 Windows Office·NASCA 통과 판정은 실제 Windows 환경에서 수행해야 한다.
