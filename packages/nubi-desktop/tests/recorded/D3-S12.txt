회사 프록시나 사내 게이트웨이를 거쳐 호출하려면 **제공자별 Base URL 환경 변수**를 설정하라고 되어 있습니다.

일반 제공자:
- OpenAI: `OPENAI_BASE_URL`
- Anthropic: `ANTHROPIC_BASE_URL`
- Baseten: `BASETEN_BASE_URL`
- Fireworks: `FIREWORKS_BASE_URL`
- NVIDIA: `NVIDIA_BASE_URL`
- Copilot: `COPILOT_BASE_URL`

OpenAI 호환 게이트웨이:
```bash
OPENWIKI_PROVIDER=openai-compatible
OPENAI_COMPATIBLE_BASE_URL=https://회사-게이트웨이/v1
OPENAI_COMPATIBLE_API_KEY=토큰
OPENWIKI_MODEL_ID=모델-ID
```

ENTERPRISE.md의 AI Pro CLI 방식:
```bash
OPENWIKI_PROVIDER=aipro-cli
AIPRO_CLI_BASE_URL=https://회사-게이트웨이/v1
AIPRO_CLI_TOKEN=토큰
OPENWIKI_MODEL_ID=모델-ID
```

회사 CA 인증서가 필요하면 추가로 설정합니다:
```bash
NODE_EXTRA_CA_CERTS=/path/to/company-ca.pem
```

**핵심은 일반 HTTP 프록시 변수(`HTTP_PROXY`, `HTTPS_PROXY`)가 아니라, 모델 제공자의 `*_BASE_URL`을 회사 게이트웨이 주소로 지정하는 방식**입니다. 두 문서의 확인 범위에서는 `HTTP_PROXY`나 `HTTPS_PROXY`를 설정하라는 안내는 없습니다. TLS 검증을 끄지 말라고도 명시되어 있습니다.
