# 주문 상태

| 상태 | 코드 값 | 다음에 갈 수 있는 상태 |
|---|---|---|
| 접수 | `received` | 결제 완료, 취소 |
| 결제 완료 | `paid` | 출고, 취소 |
| 출고 | `shipped` | 배송 완료 |
| 배송 완료 | `delivered` | 없음 |
| 취소 | `cancelled` | 없음 |

취소는 출고 전까지만 할 수 있다. 출고한 주문은 취소하지 않고 반품 절차를 따른다. 반품 절차는 이 서비스의 범위가 아니다.

상태 이동은 `src/status.mjs`의 `move`가 검사한다. 허용하지 않은 이동은 `invalid_transition` 오류를 낸다.
