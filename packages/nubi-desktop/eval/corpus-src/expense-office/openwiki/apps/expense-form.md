# 경비 신청 화면

| 칸 또는 버튼 | 뜻 |
|---|---|
| 신청자 | 경비를 쓴 사람 |
| 부서 | 예산을 쓰는 부서. 영업팀, 개발팀, 운영팀 중에서 고른다 |
| 금액(원) | 숫자만 적는다 |
| 사용일 | 경비를 쓴 날 |
| 영수증 첨부 | 영수증 파일을 함께 올렸는지 |
| 긴급 처리 | 결재를 앞당길지 |
| 메모 | 경비의 분류, 목적지, 사유 |
| 결재 비밀번호 | 신청자 본인만 입력한다. 대신 입력하지 않는다 |
| 문서 번호 | 앱이 정한다. 바꿀 수 없다 |
| 임시 저장 | 제출하지 않고 저장한다 |
| 제출 | 결재로 보낸다 |
| 삭제 | 신청서를 지운다 |
