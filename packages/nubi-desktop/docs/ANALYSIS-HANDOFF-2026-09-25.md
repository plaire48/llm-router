# 하위 분석 수집과 최종 검토

2026-09-25. Desktop의 기존 Pi 실행기와 OpenWiki-SDS 문서 조사 위에 적용한 개선이다.

## 확인한 문제와 변경

1. 하위 분석의 요약만 진행 기록에 남고 미확인 항목과 다음 확인 방법이 빠졌다. 공통 Pi coordinator의 공개 이벤트에 검증된 uncertainties, nextStep과 제한된 오류 코드를 추가했다. 화면의 ‘결과 수집됨’은 주 실행기에 전달할 결과를 수집했다는 뜻이며 실제 모델의 검토 완료가 아니다.
2. 독립 최종 검토가 하위 분석의 미해결 항목과 실패한 분담을 직접 받지 못했다. 현재 실행의 최대 12개 분담을 별도 advisoryHandoffs로 전달한다. 미해결 분담을 먼저 선택하고 남은 자리에 최근 완료 응답을 넣는다. 원래 요청과 사용자 답변, 호스트 기록, 주 실행기 근거를 먼저 보존하고 남은 예산에 요약을 넣는다. 생략 수와 제외된 미해결 수를 기록하며 원문과 같은 실행 근거로 승격하지 않는다. 실패한 분담은 보고서가 없어도 포함 대상이다.
3. 최근 trace 또는 첫 페이지 밖의 역할 분담이 실행 중 상태로 남을 수 있었다. 현재 화면에 불러온 기록 중 최대 20개를 작업 ID 범위에서 다시 읽는다. 실행 중 기록을 우선하고 페이지 커서를 유지한다. 이 조회는 모델 호출이나 앱 조작을 재실행하지 않는다.
4. 최종 검토도 실제 시작과 응답을 SQLite에 기록한다. ‘근거 확인’, ‘승인 또는 진행 대기’, ‘미확인’을 구분하고 검토 도중 재시작은 ‘중단’으로 보존한다. ready는 응답 검토 상태이며 업무 완료 판정이 아니다. 종료된 세부 사항은 접어두고 핵심 미확인 항목을 먼저 표시한다.

## 벤치마킹과 도입 판단

| 근거 | 적용 |
| --- | --- |
| [Anthropic multi-agent research](https://www.anthropic.com/engineering/multi-agent-research-system) | 역할별 목표와 출처를 분리하고 주 실행기가 결과와 남은 확인을 통합한다. 이번 변경은 수집 과정에서 빠지는 불확실성과 실패 상태를 보존한다. 에이전트 수 증가 자체를 품질 개선으로 간주하지 않는다. |
| [DeepAgents subagents](https://docs.langchain.com/oss/javascript/deepagents/subagents) | 독립 문맥과 제한된 보고서 반환을 유지한다. 이미 적용한 OpenWiki-SDS 읽기 전용 조사 코어의 분할/누락 보완/계층 합성을 재사용한다. |
| OpenCode/Codex 공개 실행 코어와 Claude subagents | [기존 실제 소스 검토](AGENT-BENCHMARK-2026-09-25.md)의 작업 경계, 문맥 축약, 원문 재조회 결정을 유지한다. 상용 데스크톱 전체 구현을 분석하거나 Claude Code 런타임을 복사했다는 뜻이 아니다. |

추가 패키지는 없다. 기존 Pi Agent Core, p-limit, SQLite와 Ajv를 재사용한다. 다른 오케스트레이터를 중복 도입하는 것보다 현재 실행과 이력의 누락을 보완하는 편이 비용과 유지보수 측면에서 적합했다. 기존 라이선스와 고정 버전은 변경하지 않았다.

## 검증 범위

- 실제 공유 Pi 루프와 지정된 모델 응답을 연결해 두 하위 조사 결과의 미확인 항목이 독립 검토에 도달하는지 확인한다.
- 하위 분석 ID를 supported의 실행 근거로 인용하면 거부한다. 이미지와 임의 필드는 검토 요약에서 제외한다.
- 실패한 분담 보존, 재시작 중단 처리, 다른 작업 이력 접근 차단, 첫 페이지 밖의 갱신을 검사한다.
- 브라우저에서 오래된 워커의 running → partial, 결과 수집 표시, 남은 확인과 검토 누락을 확인한다. 공개 진행 상태만 표시하며 모델의 비공개 추론은 노출하지 않는다.
- 기존 Windows UIA와 화면 캡처, 동작별 HITL, 문서 근거 재검증을 유지한다. 이번 수정은 새로운 Windows 입력 방식이나 A2A를 추가하지 않는다.

테스트 응답은 합성이다. 실제 Windows 11 업무 앱, 실계정 모델의 과제 성공률이나 성능 향상은 이번 검사로 입증하지 않는다. PDF/OCR 추출이나 설치 파일 배포도 이번 변경 범위가 아니다. 로그와 검사 대상은 `verification/analysis-handoff-20260925`에 보관한다.
