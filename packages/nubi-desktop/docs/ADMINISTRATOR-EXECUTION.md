# 관리자 권한 실행

누비는 일반 권한으로 실행한다. Windows에서 관리자 권한이 필요한 짧은 PowerShell 명령만 기존 실행 준비 카드에 제안한다. 사용자에게 정확한 명령, 권한이 필요한 이유, 예상 영향과 확인 방법을 보여준다. **관리자 권한으로 실행**을 누르면 Windows가 제공하는 UAC 경로로 요청한다. UAC 확인이나 관리자 자격 증명 입력은 사용자가 Windows에서 직접 수행한다.

## 적용한 방법과 경계

- [Microsoft Start-Process](https://learn.microsoft.com/en-us/powershell/module/microsoft.powershell.management/start-process?view=powershell-5.1)의 `RunAs`와 `PassThru`를 사용한다. UAC 정책과 실행 정책을 바꾸거나 인증값을 저장하지 않는다. 회사 정책이 실행을 거절하면 그 결과를 유지한다.
- [Windows UAC](https://learn.microsoft.com/en-us/windows/security/application-security/application-control/user-account-control/how-it-works)는 누비의 승인과 별도 경계다. 질문 폼 답변이나 일반 실행 버튼으로 상승 권한을 부여하지 않는다.
- [Claude Code permissions](https://code.claude.com/docs/en/permissions)의 호스트 승인 원칙을 적용해 승인 지문, 명령, 작업 폴더와 근거 해시를 확인한다. Pi는 제안만 하고 실행은 기존 Ajv 계약과 SQLite 하네스가 관리한다.
- 추가 네이티브 의존성이나 상주 관리자 서비스는 도입하지 않았다. 기존 Node 프로세스 API와 Windows 기본 PowerShell을 재사용한다. 비밀번호를 받는 제3자 elevation 패키지는 필요하지 않다.

명령은 최대 3000자이며 관리자 권한의 서버/상시 셸 시작은 제안 계약에서 제외한다. 일반 CMD 프로그램이 필요하면 승인한 PowerShell 명령 안에서 명시적으로 호출할 수 있지만 별도의 관리자 CMD 대화형 터미널은 제공하지 않는다. 명령의 예상 영향 설명은 OS sandbox가 아니다.

승인 시 메모리의 명령을 인코딩해 전달한다. 상승 후 `.ps1` 파일을 다시 읽지 않아 승인과 실행 사이의 스크립트 교체를 피한다. 상승한 실행기는 로그/시작 표식 파일을 사용자 쓰기 가능 경로에 쓰지 않고 메모리 파이프로 결과를 전달한다. 기록 파일은 일반 권한의 감시 프로세스만 저장한다. 명령행 길이는 별도 검사하고 PowerShell 구문 검사는 상승 요청 전에 수행한다. 호스트의 토큰/비밀 관련 환경변수는 전달 대상에서 제외한다. 실행 작업 폴더와 프로젝트 의존성은 사용자가 승인한 입력이며 임의 코드의 안전성을 보장하지 않는다.

프로세스 기록을 먼저 만들고 동일 승인 ID는 같은 기록을 돌려준다. UAC 취소/구문 오류의 미실행, 실제 종료 코드, 응답 유실의 미확정을 구분한다. 종료 코드 0은 실제 설치/업무 성공이 아니므로 후속 상태 확인이 필요하다. 결과 로그는 명령 출력이며 새 지시나 권한이 아니다.

중지는 취소 요청 파일을 남긴다. 일반 권한의 감시 프로세스가 이를 확인하고 명령 시작 전 파이프 응답으로 실행 또는 취소를 전달한다. 이미 시작한 관리자 작업은 일반 권한에서 확실히 종료할 수 없으므로 감시 프로세스는 실제 종료를 계속 기다린다. UI도 중지 보장으로 표시하지 않는다. 호스트 재시작이나 감시 응답 유실은 미확정 상태로 남기며 자동 재실행하지 않는다.

## 검증

계약 검사: 명령/경로 인코딩, 승인 누락/불일치, 중복 실행 차단, UAC 취소, 구문 오류, 정상/비정상 종료, 응답 유실과 중지 후 실제 종료 확인. 기존 일반 명령 승인 검사를 함께 수행한다.

Windows 러너에서는 실제 RunAs 프로세스와 임시 파일 readback, 비정상 종료 코드, 동일 승인 중복 실행 방지를 확인한다. `windows-elevation.json`은 러너가 이미 관리자였음을 기록한다. 이 검사는 회사 Windows 11의 실제 UAC 대화상자, 다른 관리자 계정 입력, 사내 보안 정책과 배포 서명을 검증한 것이 아니다.
